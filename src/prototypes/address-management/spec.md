# 地址管理 (Address Management)

## 📋 功能说明

### 1.1 核心目标
查看同步后的地址信息，作为基础数据供其他模块（如站点、停靠点）引用。

### 1.2 使用角色
- 配置人员
- 系统管理员

## 📊 业务规则/约束

### 2.1 业务规则
- **列表展示**：
  - 字段：地址名称、纬度、经度、创建时间、更新时间。
  - 排序：默认按“地址名称”排序（或创建时间倒序，根据通用习惯暂定名称排序）。
- **只读性质**：地址数据主要通过同步获取，本页面主要用于查看。

### 2.2 操作说明

- **列表操作**：
  - 无新增、编辑、删除操作（数据源于同步）。
  - 支持按地址名称模糊搜索（通用功能）。

### 2.3 界面默认情况
- 默认展示所有地址列表。
- 采用暗色系 UI 风格，与其他管理模块保持一致。

## 🎨 视觉规范

### 3.1 主题
- **风格**：暗色科技风 (Dark Tech)。
- **背景**：深蓝色/星空背景。
- **高亮色**：青色 (Cyan/Teal)。

## 📝 数据结构 (参考)

| 字段名 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| id | string | 唯一标识 | "addr-001" |
| name | string | 地址名称 | "A区主入口" |
| latitude | number | 纬度 | 39.9042 |
| longitude | number | 经度 | 116.4074 |
| createdAt | string | 创建时间 | "2023-10-01 10:00:00" |
| updatedAt | string | 更新时间 | "2023-10-05 14:30:00" |
