# 小车监控

## 📋 功能说明

### 1.1 核心目标
提供集控调度员对转运小车进行实时监控的能力。可以查看小车当前的详细监测数据、正在执行的任务、实时监控视频信息，并支持对小车任务的即时控制操作。界面风格与工作台一致，作为调度管控的子功能。

### 1.2 使用角色
集控调度员

## 📊 业务规则/约束

### 2.1 业务规则
- **小车切换**：支持通过标签页或下拉菜单切换不同的小车实例，切换后数据和视频流随之更新。
- **信息展示优先级**：任务信息优先展示“正在执行”的任务，若无，则展示“待执行”的任务。
- **视频流自动加载**：进入界面或切换小车时，自动获取对应小车的推流地址并播放实时视频（环视视角、后视视角）。
- **任务状态流转**：
  - 仅“未执行”任务可点击【执行】。
  - 仅“正在执行”任务可点击【暂停】或【终止】。
  - 仅“暂停”状态任务可点击【恢复】。

### 2.2 操作说明
- **数据类型**：实时监控大屏/控制台
- **数据源**：前端模拟设备和任务数据
- **关键操作**：
  - `小车切换`: [切换当前视图所展示的小车数据，并重新加载对应的视频推流和实时日志]
  - `视频控制`: [全屏/退出全屏、播放/暂停、静音/取消静音、截图]
  - `任务执行`: [二次确认后，将“未执行”状态的任务变更为“执行中”]
  - `任务暂停`: [二次确认后，将“执行中”的任务变更为“暂停”]
  - `任务恢复`: [将“暂停”的任务变更为“执行中”]
  - `任务终止`: [将“执行中”的任务变更为“终止”，下发靠边停车指令]

### 2.3 界面默认情况
- 默认选中列表中的第一辆小车。
- 视频区域默认播放两路视频（环视、后视）。
- 优先展示正在执行的任务，并实时追加运行日志。

## 🧩 界面结构与内容规划

### 3.1 页面布局
- **整体框架**：必须完全复用工作台（`dispatch-workbench`）的页面顶部结构，包含：
  - 顶部一级导航栏（智慧燃料集控中心，含主界面、采样机等菜单）。
  - 二级导航栏（工作台、任务管理、任务日志查询、车辆监控、车辆调试、报警查询），当前激活项为“车辆监控”。
- **主体内容区**：在二级导航栏下方，采用暗色科技感 UI 风格的多列网格布局。
  - **左侧区域**：
    - **视频监控区**：上下两路视频画面（环视、后视），带有悬浮控制栏。
    - **运行日志区**：滚动列表，展示实时任务日志。
  - **右侧区域**：
    - **小车切换器**：在右侧区域顶部提供小车实例切换功能。
    - **实时监测信息面板**：
      - 基础信息：编号、名称、定位状态、档位、速度、任务状态。
      - 作业信息：运行状态、流程状态、操作模式、两条滚筒线数据（容量、已装、类型、去向）、柜门状态。
      - 监控参数：电量信息、辅助请求、实时故障。
    - **任务面板**：展示当前/待执行任务主数据与明细，及操作按钮（执行、暂停、恢复、终止）。

### 3.2 字段字典
| 字段组 | 字段名 | 字段类型 | 枚举/格式/说明 |
|--------|-------|---------|---------------|
| 基础信息 | 当前执行任务编号 | 文本 | 示例：T-20231024-001 |
| 基础信息 | 任务状态 | 枚举 | 1-预处理（已读取）、2-执行中、3-已完成、4-已取消（故障） |
| 基础信息 | 档位 | 枚举 | 0-R, 1-P, 2-N, 3-D |
| 基础信息 | 任务执行状态 | 枚举 | 正在执行、未执行任务（原任务状态） |
| 作业信息 | 滚筒线容量 | 数值 | 示例：6 |
| 作业信息 | 滚筒线类型 | 枚举 | 满桶、空桶 |
| 监控参数 | 辅助请求 | 枚举 | 0-无路通行, 1-防撞触发, 17-主驱异常, 19-ICAN_30, 20-软件急停, 24-监控客户端急停, 33-车端按钮急停 |
| 监控参数 | 实时故障类型 | 枚举 | 0-传感器, 1-底盘, 2-应用, 3-主动检测 |
| 监控参数 | 实时故障状态 | 枚举 | 0-触发, 1-已解除 |

## 🎨 视觉规范与交互说明

### 4.1 视觉风格
- **主题规范**：继承项目默认的暗色调科技风（参考 `dispatch-workbench`）。
- **核心色彩**：
  - 正常/执行中：Cyan (`text-cyan-400`, `border-cyan-400/30`, `bg-cyan-400/10`)
  - 异常/故障/终止：Red (`text-red-400`, `border-red-400/30`, `bg-red-400/10`)
  - 暂停/警告：Yellow (`text-yellow-400`, `border-yellow-400/30`, `bg-yellow-400/10`)
  - 就绪/未执行：Gray (`text-gray-400`, `border-gray-400/30`, `bg-gray-400/10`)

### 4.2 交互细节
- **弹窗**：所有的任务操作（执行、暂停、终止）必须使用二次确认弹窗（Modal.confirm），弹窗需要适配暗黑主题背景色和按钮样式。
- **视频控件**：鼠标悬停在视频区域时，显示底部控制栏。

## 🚨 异常处理与提示策略
- 当小车离线时，视频区显示“信号丢失”占位图或提示，数据面板置灰或显示“-”。
- 故障信息实时触发时，右上角或面板内高亮显示报警提示。
