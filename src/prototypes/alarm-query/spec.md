# 报警查询

## 📋 功能说明

### 1.1 核心目标
> 简要说明该功能的核心定位、解决的问题、用户场景

集控调度员通过报警查询功能，查询采样集样器、归批设备、转运小车发生的报警数据信息，以便及时发现和处理设备故障与系统异常，保障无人小车调度系统的稳定运行。

### 1.2 使用角色
> 列出此功能模块使用的主要用户对象

- **集控调度员**：查看报警数据、排查故障、进行人工复位操作。

## 📊 业务规则/约束

### 2.1 业务规则
> 按界面内容、模块逐个说明其中主要业务对象的业务规则、流程等内容

1. **报警范围**：包括转运小车的辅助控制请求报警、故障报警信息，以及调度相关的集样器装样端、归批卸样端设备的通讯异常报警信息。
2. **报警数据生成**：
   - 无人小车调度系统订阅：根据小车上报的 605-运力资源辅助请求、607-运力资源故障信息实时解析生成报警数据。
   - 接卸端设备数据采集：根据设备端实时信号生成设备离线报警。
3. **报警字段特殊规则**：
   - 非转运小车（如集样器、归批设备）发生的报警，无“报警类型”和“报警状态”，显示为空或 `-`。
4. **排序规则**：报警列表默认按“报警时间”逆序排列。

### 2.2 操作说明
> 按用户在界面可操作的所有内容、按钮、列表、操作步骤等，同时附带各操作的前端后端校验规则

- **数据类型**：列表记录
- **数据源**：模拟前端生成的报警数据
- **关键操作**：
  - `模糊搜索`: 支持按“报警对象”、“报警内容”输入关键字进行模糊匹配查询。
  - `时间范围搜索`: 支持按“报警发生时间”的起止时间进行区间筛选。
  - `查看详情`: 点击列表操作列的“查看详情”，弹窗展示该条报警的完整信息。
  - `复位`: 针对因系统异常未自动消除的报警（且报警状态不是已解除），调度员可点击“复位”进行人工手动消除。复位时弹窗确认，并记录当前登录操作人及操作时间。

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- 页面顶部保留与工作台一致的系统一级菜单（“智慧燃料集控中心”及导航）和二级菜单，二级菜单中“报警查询”呈选中状态。
- 进入页面后默认加载所有报警数据列表，按时间倒序排列。
- 顶部提供搜索表单区，包含报警对象、报警内容输入框、时间范围选择器及查询/重置按钮。

## 🎨 视觉规范与布局

- **主题风格**：与 `dispatch-workbench` 保持一致的深色科技风（Dark Theme）。
  - 背景色：`bg-[#0b1120]`
  - 面板背景：`bg-[#1e293b]/40`
  - 强调色/边框：Cyan (`text-cyan-400`, `border-cyan-900/30`)
- **布局结构**：
  - Header：固定高度，深色模糊背景，一级菜单。
  - Sub-Header：二级菜单导航。
  - 搜索区：横向排列的输入框、时间选择器及按钮，置于列表上方。
  - 列表区：自适应高度，带表头固定的数据表格。
  - 分页组件（模拟）：列表底部。
- **组件状态**：
  - **严重报警**：使用红色系标签或文字高亮提示。
  - **普通报警**：使用黄色或蓝色系标签。
  - **已解除**：使用灰色系或绿色系标签，表示已恢复正常。
