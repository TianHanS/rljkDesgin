# 自动入厂监测

## 📋 功能说明

### 1.1 核心目标

面向入厂口值班的**入厂管理员**，在同一屏完成自动入厂监测：

- 现场分为 **A 系统**、**B 系统**，各对应 **2 个入厂点**（入厂点 1#、2# 属 A 系统；3#、4# 属 B 系统）。
- **一拖二对照**：一屏横向并列展示当前系统下 2 个入厂点，互不影响。
- 对各入厂点**启用 / 停用自动入厂登记服务**（须二次确认）。
- 监测**车号识别视频**、**LED 下发文案**、**运行日志**与**入厂车辆记录**。

每个入厂点配备 **1 台车号识别器 + 1 块 LED 大屏**。

**页面边界**：不包含系统框架层内容（页面标题、面包屑、菜单等由外层框架承载）；本页只保留与监测直接相关的功能控件。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 入厂管理员 / 门岗值班员 | 对照监控两个入厂点、启停自动入厂服务、处理异常日志 |
| 门岗班长 | 切换 A/B 系统、核对离线设备与插队/异常车辆 |
| 燃料集控调度 | 抽查入厂记录与系统负荷 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 系统与一拖二对照

- 现场配置：**A 系统**（入厂点 1#、2#）、**B 系统**（入厂点 3#、4#）。
- 默认进入 **A 系统**，横向对照展示入厂点 1# 与 2#。
- 切换系统后，对照入厂点、视频与日志随系统更新。
- **不展示**页头页面名称/说明文案、车辆统计 KPI、底部排队车辆列表。

原型系统：

| 系统 | 入厂点 | 说明 |
|------|--------|------|
| A 系统 | 入厂点 1#、入厂点 2# | 双点均在线且服务启用（默认演示） |
| B 系统 | 入厂点 3#、入厂点 4# | 入厂点 4# 设备离线演示 |

#### B. 入厂点卡片（纵向信息流）

每个入厂点卡片采用**自上而下纵向布局**（非左右分栏）：

1. **卡片头（横向一行）**：入厂点名称、设备状态标签、自动入厂登记开关
2. **监控带（横向宽屏）**：车号识别画面（21:9 宽屏比例）+ LED 条幅
3. **数据区**：Tab 切换「运行日志 / 入厂记录」；日志支持全部/正常/异常筛选

运行日志：识别车辆、登记结果、车辆异常、车辆抽检、车辆插队等；异常行红色凸显；按时间逆序。

入厂车辆记录：车牌号、入厂时间、采样位、过衡位；按入厂时间逆序。

#### C. 日志分级

| 级别 | 类型 | 展示 |
|------|------|------|
| 正常 | 识别车辆、登记成功、车辆抽检、服务启停 | 默认文字色；抽检可用警示标签但不标红 |
| 异常 | 登记失败、车辆异常、车辆插队、设备离线事件 | 红字 + 浅红底 |

#### D. 启停约束

- 停用后该点不再自动识别登记；LED 文案切换为停用提示。
- 离线点仍允许预置启停；画面显示离线遮罩。
- 启用/停用成功后给出 Message 反馈。

### 2.2 操作说明

- **数据类型**：系统监测看板 + 双点实时对照
- **数据源**：原型内 Mock（系统、入厂点、日志、入厂记录）
- **关键操作**：
  - `切换系统`：更新对照入厂点与监测数据
  - `启用/停用自动入厂登记`：Modal 二次确认
  - `日志筛选`：全部 / 正常 / 异常
  - `Tab 切换`：运行日志 ↔ 入厂记录

### 2.3 界面默认情况

- 浅色 Ant Design 后台风格（`antd-new`）：灰底 `#f5f5f5`、白卡片、主色 `#1677ff`。
- 页内仅保留 **A/B 系统 Segmented** 作为顶部工具条，无页面标题与说明。
- 双列入厂点卡片等高伸展，数据区在卡片内滚动。
- 窄屏（&lt; 1200px）双列改为上下堆叠。

## 🎨 视觉规范

### 3.1 布局

```
工具条：A/B 系统 Segmented（右对齐）
主体：入厂点卡片 × 2（横向并列）
  └ 每卡：头栏 → 宽屏视频 + LED → 日志/记录 Tab 区
```

### 3.2 视觉要点

- 设计规范：`antd-new` + 极简 ToB + Ant Design 6 组件
- 监控画面为横向宽屏取景区（21:9），强化车道监测语义
- 在线绿 `#52c41a`；离线灰；异常红 `#ff4d4f`
- 禁止大面积渐变、玻璃拟态与装饰性发光

### 3.3 组件状态

| 组件 | 默认 | 交互 | 禁用/异常 |
|------|------|------|-----------|
| 系统 Segmented | A 系统 | 点击切换 | — |
| 服务开关 | 按点位数据 | 先弹确认再改值 | 离线仍可预置 |
| 日志 Tab | 运行日志 | 切换入厂记录 | — |
| 日志行 | 正常色 | 可筛选 | 异常行红底红字 |
