# 自动入厂监测

## 📋 功能说明

### 1.1 核心目标

面向入厂口值班的**入厂管理员**，在同一屏完成「入厂调度 + 自动入厂监测」：

- 现场分为 **A 系统**、**B 系统**，各对应 **2 个入厂点**（入厂点 1#、2# 属 A 系统；3#、4# 属 B 系统）。
- **一拖二对照**：一屏同时展示当前系统下 2 个入厂点的全部监控信息，互不影响。
- 对各入厂点**启用 / 停用自动入厂登记服务**（须二次确认）。
- 监测**车号识别视频**、**排队车辆列表**、**已入厂登记车辆列表**，以及入厂点运行日志。

每个入厂点配备 **1 台车号识别器 + 1 块 LED 大屏**。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 入厂管理员 / 门岗值班员 | 对照监控两个入厂点、启停自动入厂服务、盯视频与排队、处理异常日志 |
| 门岗班长 | 切换 A/B 系统、核对离线设备与插队/异常车辆 |
| 燃料集控调度 | 抽查入厂记录与系统负荷 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 系统与一拖二对照

- 现场配置：**A 系统**（入厂点 1#、2#）、**B 系统**（入厂点 3#、4#）。
- 默认进入 **A 系统**，对照展示入厂点 1# 与 2#。
- 切换系统后，对照入厂点、排队列表、视频与日志随系统更新。
- **页头不展示车辆统计 KPI**（当前排队、今日已入厂等汇总指标已移除），聚焦实时监测与对照操作。

原型系统：

| 系统 | 入厂点 | 说明 |
|------|--------|------|
| A 系统 | 入厂点 1#、入厂点 2# | 双点均在线且服务启用（默认演示） |
| B 系统 | 入厂点 3#、入厂点 4# | 入厂点 4# 设备离线演示 |

#### B. 入厂点面板（每列必须完整展示）

每个入厂点列包含：

1. **系统标识 + 入厂点名称**（如「A 系统 · 入厂点 1#」）
2. **车号识别监控画面**（模拟实时视频：机位名、时间戳、识别车牌叠加；服务停用或设备离线时画面加遮罩说明）
3. **自动入厂登记服务启停**：开关操作必须弹出二次确认；确认后即时改状态，并写入运行日志
4. **设备连接状态**：入厂点整体为 **在线 / 离线**（以车号识别器为准）；同时展示识别器、LED 大屏分项状态
5. **运行日志**：识别车辆、登记结果、车辆异常、车辆抽检、车辆插队等；分 **正常 / 异常** 两类，异常行红色凸显；按时间逆序
6. **入厂车辆记录**：车牌号、入厂时间、采样位、过衡位；按入厂时间逆序

LED 大屏在视频下方以条幅展示当前下发文案（欢迎入厂 / 请排队 / 服务已关闭等）。

#### C. 系统监测数据

**排队车辆列表**（系统级）：排队序号、车牌号、煤种/物资、供应商、等待时长、排队状态（排队中 / 即将入厂 / 等待超时）。

**已入厂登记车辆列表**：落在各入厂点列内；字段见上。

#### D. 日志分级

| 级别 | 类型 | 展示 |
|------|------|------|
| 正常 | 识别车辆、登记成功、车辆抽检、服务启停 | 默认文字色；抽检可用警示标签但不标红 |
| 异常 | 识别失败、登记失败、车辆异常、车辆插队、设备离线事件 | 红字 + 浅红底，明确凸显 |

日志支持「全部 / 正常 / 异常」筛选。启用中且在线的入厂点会定时追加模拟运行日志（登记成功时同步插入入厂记录）。

#### E. 启停约束

- 停用后该点不再自动识别登记，现场需转人工入厂；LED 文案切换为停用提示。
- 离线点仍允许预置启停（到岗后生效），操作同样二次确认；画面显示离线遮罩。
- 启用/停用成功后给出 Message 反馈。

### 2.2 操作说明

- **数据类型**：系统调度看板 + 双点实时监测
- **数据源**：原型内 Mock（系统、入厂点、排队、日志、入厂记录）；无外部数据表
- **关键操作**：
  - `切换系统`：更新对照入厂点、排队列表与实时时钟上下文
  - `启用/停用自动入厂登记`：Modal 二次确认；确认后改开关、写日志、更新 LED
  - `日志筛选`：按正常/异常过滤当前入厂点日志
  - `查看入厂记录`：表格只读，按入厂时间逆序

### 2.3 界面默认情况

- 浅色 Ant Design 后台风格（`antd-new`），与人工入厂登记一致：灰底 `#f5f5f5`、白卡片、主色 `#1677ff`。
- 默认系统：A 系统；对照 入厂点 1# / 入厂点 2#。
- 页头展示当前时间（秒级刷新）与 A/B 系统 Segmented 切换（附带入厂点编号提示）。
- 双列等高，日志与表格在列内滚动，避免整页信息被单列撑开后无法对照。
- 窄屏（&lt; 1200px）双列改为上下堆叠，保证一拖二内容完整可读。

## 🎨 视觉规范

### 3.1 布局

```
页头：标题 | A/B 系统 Segmented（含入厂点编号） | 时钟
主体：入厂点列 × 2（视频 + LED + 日志 + 入厂记录）
底部：当前系统排队车辆列表
```

### 3.2 视觉要点

- 设计规范来源：项目默认主题 `src/themes/antd-new` + `frontend-design` 工业监测语义 + Ant Design 6 组件规范
- 在线：成功绿 `#52c41a`；离线：次要灰；异常/超时：错误红 `#ff4d4f`
- 系统标识：浅蓝底标签区分 A/B 系统，避免与入厂点名称混淆
- 服务启用：主色开关；停用：默认开关 + 视频遮罩
- 车号识别画面为监控语义的深色取景区（非整页暗色主题），叠加车牌与时间戳
- 禁止大面积渐变、玻璃拟态与装饰性发光

### 3.3 组件状态

| 组件 | 默认 | 交互 | 禁用/异常 |
|------|------|------|-----------|
| 系统 Segmented | A 系统选中 | 点击切换 | — |
| 服务开关 | 按点位数据 | 先弹确认再改值 | 无禁用；离线仍可预置 |
| 确认 Modal | — | 确认/取消 | 取消不改状态 |
| 日志行 | 正常色 | 可筛选 | 异常行红底红字 |
| 排队状态 | 排队中 | — | 等待超时红标签 |
