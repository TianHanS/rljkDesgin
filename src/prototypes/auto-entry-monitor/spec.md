# 自动入厂监测

## 📋 功能说明

### 1.1 核心目标

面向入厂口值班的**入厂管理员**，在同一屏完成「入厂调度 + 自动入厂监测」：

- 按**排队通道**切换现场视角；一个通道绑定 **2 个或以上发卡点（入厂点）**。
- **一拖二对照**：一屏同时展示该通道下 2 个发卡点的全部监控信息，互不影响。
- 对各发卡点**启用 / 停用自动入厂登记服务**（须二次确认）。
- 监测厂内/通道**排队统计**、**车号识别视频**、**排队车辆列表**、**已入厂登记车辆列表**，以及发卡点运行日志。

发卡点现场配置：每个入厂点配备 **1 台车号识别器 + 1 块 LED 大屏**。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 入厂管理员 / 门岗值班员 | 对照监控两个发卡点、启停自动入厂服务、盯视频与排队、处理异常日志 |
| 门岗班长 | 切换通道、核对离线设备与插队/异常车辆 |
| 燃料集控调度 | 抽查入厂记录与通道负荷 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 通道与一拖二对照

- 一个厂可有**多个入厂通道**；一个排队通道对应 **2 个或 2 个以上**发卡点。
- 默认进入**南门通道**，对照展示该通道前两个发卡点。
- 通道内发卡点超过 2 个时，提供「对照窗口」切换（始终保持两列）：如东门 1#·2# / 2#·3#。
- 切换通道后，对照窗口回到该通道第一组；统计、排队列表、视频与日志随通道更新。

原型通道：

| 通道 | 发卡点 | 说明 |
|------|--------|------|
| 南门通道 | 南门 1#、南门 2# | 双点均在线且服务启用（默认演示） |
| 北门通道 | 北门 1#、北门 2# | 北门 2# 设备离线 |
| 东门通道 | 东门 1#、东门 2#、东门 3# | 三点通道，演示对照窗口；东门 3# 服务默认停用 |

#### B. 发卡点面板（每列必须完整展示）

每个发卡点列包含：

1. **发卡点名称**
2. **车号识别监控画面**（模拟实时视频：机位名、时间戳、识别车牌叠加；服务停用或设备离线时画面加遮罩说明）
3. **自动入厂登记服务启停**：开关操作必须弹出二次确认；确认后即时改状态，并写入运行日志
4. **设备连接状态**：发卡点整体为 **在线 / 离线**（以车号识别器为准）；同时展示识别器、LED 大屏分项状态
5. **运行日志**：识别车辆、登记结果、车辆异常、车辆抽检、车辆插队等；分 **正常 / 异常** 两类，异常行红色凸显；按时间逆序
6. **入厂车辆记录**：车牌号、入厂时间、采样位、过衡位；按入厂时间逆序

LED 大屏在视频下方以条幅展示当前下发文案（欢迎入厂 / 请排队 / 服务已关闭等）。

#### C. 通道监测数据

页头统计（当前通道）：

| 指标 | 口径 |
|------|------|
| 当前排队 | 本通道排队列表车辆数 |
| 今日已入厂 | 本通道当日已登记车辆数（含对照点之外的同通道点） |
| 等待超 30 分钟 | 排队等待 ≥ 30 分钟的车辆数 |
| 今日抽检 | 当日抽检日志条数 |
| 今日异常 | 当日异常类日志条数（登记失败、车辆异常、插队等） |
| 平均等待 | 当前排队车辆等待时长均值（分钟，取整） |

全厂排队辆数作为页头辅助信息展示，不随通道切换丢失上下文。

**排队车辆列表**（通道级）：排队序号、车牌号、煤种/物资、供应商、等待时长、排队状态（排队中 / 即将入厂 / 等待超时）。

**已入厂登记车辆列表**：置于屏幕底部右栏，按通道汇总并带「发卡点」列；字段含车牌号、入厂时间、采样位、过衡位，按入厂时间逆序。与左栏排队列表同屏对照，避免再塞进发卡点列把视频挤小。

#### D. 日志分级

| 级别 | 类型 | 展示 |
|------|------|------|
| 正常 | 识别车辆、登记成功、车辆抽检、服务启停 | 默认文字色；抽检可用警示标签但不标红 |
| 异常 | 识别失败、登记失败、车辆异常、车辆插队、设备离线事件 | 红字 + 浅红底，明确凸显 |

日志支持「全部 / 正常 / 异常」筛选。启用中且在线的发卡点会定时追加模拟运行日志（登记成功时同步插入入厂记录）。

#### E. 启停约束

- 停用后该点不再自动识别登记，现场需转人工入厂；LED 文案切换为停用提示。
- 离线点仍允许预置启停（到岗后生效），操作同样二次确认；画面显示离线遮罩。
- 启用/停用成功后给出 Message 反馈。

### 2.2 操作说明

- **数据类型**：通道调度看板 + 双点实时监测
- **数据源**：原型内 Mock（通道、发卡点、排队、日志、入厂记录）；无外部数据表
- **关键操作**：
  - `切换通道`：更新统计、对照发卡点、排队列表与实时时钟上下文
  - `切换对照窗口`：仅东门等 3+ 点通道出现；始终展示 2 列
  - `启用/停用自动入厂登记`：Modal 二次确认；确认后改开关、写日志、更新 LED
  - `日志筛选`：按正常/异常过滤当前发卡点日志
  - `查看入厂记录`：表格只读，按入厂时间逆序

### 2.3 界面默认情况

- 浅色 Ant Design 后台风格（`antd-new`）：灰底 `#f5f5f5`、白底分区、主色 `#1677ff`。
- 默认通道：南门通道；对照 南门 1# / 南门 2#。
- **固定一屏（100vh）**，默认不出现整页滚动；视频、日志、排队、入厂记录同屏可见。
- 页头单行：标题 + 通道/对照切换 + 内联统计 + 时钟。
- 窄屏（&lt; 1200px）允许整页滚动，双列改为上下堆叠。

## 🎨 视觉规范

### 3.1 布局

值班监测台按「上看现场、中看日志、下看队列」组织，取消独立 KPI 卡片行与发卡点列内嵌套表格。

```
页头（单行）：标题 | 通道 | 对照窗口 | 内联统计 | 时钟
主体（1fr × 2 列，占满剩余高度）：
  每列：点位名 + 在线状态 + 启停开关
        车号识别大画面（列宽铺满）
        LED 条幅
        运行日志（列内滚动）
底栏（固定高度，左右两表）：
  左：当前通道排队车辆
  右：当前通道已入厂登记（含发卡点）
```

### 3.2 视觉要点

- 设计规范来源：项目默认主题 `src/themes/antd-new` + 极简 ToB 指导
- 在线：成功绿 `#52c41a`；离线：次要灰；异常/超时：错误红 `#ff4d4f`
- 服务启用：主色开关；停用：默认开关 + 视频遮罩
- 车号识别画面为监控语义的深色取景区（非整页暗色主题），叠加车牌与时间戳；画面铺满发卡点列宽，高度随剩余空间分配，保证对照时两路视频同等醒目
- 禁止大面积渐变、玻璃拟态与装饰性发光
- 设备状态只在点位标题行展示一次，不再在视频下重复堆标签

### 3.3 组件状态

| 组件 | 默认 | 交互 | 禁用/异常 |
|------|------|------|-----------|
| 通道 Segmented | 南门选中 | 点击切换 | — |
| 服务开关 | 按点位数据 | 先弹确认再改值 | 无禁用；离线仍可预置 |
| 确认 Modal | — | 确认/取消 | 取消不改状态 |
| 日志行 | 正常色 | 可筛选 | 异常行红底红字 |
| 排队状态 | 排队中 | — | 等待超时红标签 |
