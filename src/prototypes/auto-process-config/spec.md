# 自动化流程配置

## 📋 功能说明

### 1.1 核心目标

在**自动化流程管理（规格层）**之上，为具体业务模块配置自动化处理流程与详细参数。面向实施、运维人员：交互友好、说明充分、约束清晰，支持流程包与服务运维。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 实施人员 | 新建模块配置、组装流程环节、填写详细参数与消息 |
| 运维人员 | 服务启用/停用、流程包上传更新、端口配置 |

### 1.3 与流程管理的关系

- **流程管理**：按模块类型定义活动库、可关联参数与消息模板
- **流程配置（本页）**：按具体模块实例选用环节、填参数值、管服务（一模块一份配置）

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 模块配置列表（卡片）

- 按**创建时间逆序**
- 卡片信息：模块名称、模块类型、创建时间、环节数、**服务状态**、**待检查参数**角标（环节变更后未复核时显示）
- 未完成提示：
  - **流程待完善**（无环节 / 参数待检查）：「流程配置」按钮红点 + 卡片 Tag
  - **服务待完善**（未上传流程包）：「服务管理」按钮红点 + 卡片 Tag
- 顶部：新增
- 卡片操作：编辑、流程配置、服务管理、删除

#### B. 新建 / 编辑

- 配置模块：二级抽屉模块列表，支持按类型、名称筛选
- **一模块仅一份配置**；已配置模块置灰不可选
- 确认后回显模块名称、模块类型

#### C. 流程配置（一级大抽屉 · 双 Tab）

**Tab1 流程环节配置**
- 左右两栏默认占满抽屉可用高度；中间列表区域内部滚动
- 「保存环节配置」固定在右侧面板底部，不随环节增多下移
- 加载该模块类型规格下全部活动（名称、说明）
- 可重复添加同一活动；右侧流水线拖拽排序、删除
- 保存后：提示「请检查并更新详细参数」；**抽屉不关闭**；切到 Tab2；Tab2 显示提示角标
- **同一活动多次出现时，详细参数仅保留一份**（按活动编码去重）

**Tab2 详细参数配置**
- 按已选环节中的**去重活动**分块展示；参数按 `group` 分区，**一行 2～3 列网格**紧凑排布
- 枚举类参数使用 Radio；数值/文本用 InputNumber/Input
- 消息：LED/语音模板支持占位符插入 + **快捷输入**整句
- **汽车衡**类型演示含 10001～10081 全量计量参数（识别/空磅/上磅/量程/固化/重轻衡切换等）
- **无 LED 预览**（对接真实设备）
- 环节变更后未保存详细参数前，Tab 与卡片显示「待检查」提示

#### D. 服务管理

- 服务状态：启用 / 停用
- 流程包：上传 / 更新（展示版本、上传时间）
- 端口配置：服务端口等

### 2.2 操作说明

- **数据类型**：模块配置实例
- **数据源**：用户规约 + Mock（对齐流程管理规格）
- **关键操作**：新增、编辑、流程配置（双 Tab）、服务管理、删除

### 2.3 界面默认情况

- 进入即卡片列表（含 2～3 条 Mock）
- 流程配置、服务管理以 Drawer 打开
