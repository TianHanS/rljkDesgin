# 流程规格配置

## 📋 功能说明

### 1.1 核心目标

按**模块类型**管理各模块的自动化流程规格。一个模块类型对应一套通用流程；流程由多个业务环节（活动）组成；活动可关联配置参数、可配置消息组（LED / 语音）。配置人员在一屏内完成流程 CRUD、活动管理、参数关联与消息配置。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 系统配置员 | 新建流程、维护活动、关联参数、配置消息 |
| 燃料集控管理员 | 查看流程与活动启用状态、核对模块类型配置 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 数据实体关系

```
模块类型 1 —— 1 类型流程配置
类型流程配置 1 —— n 流程环节（活动）
流程环节 1 —— n 配置参数（不可跨活动重复关联）
流程环节 1 —— n 消息配置
```

#### B. 流程规格卡片（默认视图）

进入页面直接展示**卡片网格**（不使用表格列表），按更新时间逆序。

卡片信息：
- 流程名称、模块类型（编码 Tag + 名称）
- 活动数 / 启用活动数
- 备注、更新时间
- **活动提示区**：按序号展示活动名称 Tag；启用为蓝系、禁用为灰色；无活动时 Tag「暂无活动，请完善」+「活动管理」按钮红点

卡片操作：
- **流程编辑**：打开编辑抽屉，模块类型只读，可改名称与备注
- **活动管理**：打开活动管理大抽屉
- **删除**：二次确认；删除流程及其下活动、参数关联、消息

#### C. 新建流程配置

1. *模块类型：点击打开二次弹窗，单选模块类型列表；**已配置过的类型置灰不可选**；选中后回显名称
2. *流程名称：文本，必填；全表不重复
3. 备注：非必填
4. 保存：模块类型不重复、流程名称不重复

#### D. 活动管理（抽屉内仍为表格列表）

活动属性：
| 字段 | 约束 |
|------|------|
| *活动编码 | 必填、流程下唯一、可编辑 |
| *活动名称 | 必填、流程下唯一、可编辑 |
| *序号 | 必填、流程下唯一；新建默认 = 当前最大序号 + 1；**列表支持拖拽排序**，拖拽后自动重排序号 |
| *活动状态 | 启用 / 禁用；默认禁用；列表内 Switch 直接切换 |
| 说明 | 非必填 |

行操作：编辑、删除、参数关联、消息配置。

#### E. 活动参数关联（抽屉内仍为表格列表）

1. 点击「参数关联」打开二级抽屉，**仅加载本活动已关联的参数列表**（可拖拽调序、删除）
2. 需新增关联时，点击「添加参数」打开**三级抽屉**，加载该模块类型下其余可关联参数
3. 三级列表支持按参数名称、编码搜索；多选后确认添加回二级列表
4. **已被其他活动关联的参数置灰不可选**；本活动已关联参数不在三级列表展示
5. 二级抽屉点击「保存关联」，保存参数与活动的对应关系

#### F. 消息配置（抽屉内仍为表格列表）

1. 打开后展示该活动下消息组列表；支持新增、编辑、删除
2. 属性：消息名称*、编码*、LED 是否启用、LED 默认模板、语音是否启用、语音默认模板、说明
3. **消息名称、编码在同一流程下唯一**（跨活动不可重复）
4. LED / 语音关闭时，对应模板字段禁用

### 2.2 操作说明

- **数据类型**：配置类（流程 / 活动 / 参数关联 / 消息）
- **数据源**：用户业务规约 + 前端 Mock
- **关键操作**：
  - `新建流程` / `流程编辑` / `删除流程`
  - `活动新增` / `编辑` / `删除` / `拖拽排序` / `状态切换`
  - `参数关联`：二级仅看本活动已关联；三级抽屉添加其他参数；排序、删除、保存
  - `消息配置`：CRUD + 唯一性校验

### 2.3 界面默认情况

- 进入即展示流程规格卡片网格（含 2～3 条 Mock，含无活动示例）
- 活动管理、参数关联、消息配置均以 Drawer 叠加，抽屉内继续使用表格列表

## 🧭 布局与结构

- **布局模式**：一屏卡片网格；配置工作区为抽屉
- **页头**：标题「流程规格配置」+ 副文案 + 新建按钮
- **抽屉层级**：流程表单 < 活动管理 < 参数关联 / 消息配置 < **选择配置参数（三级）**
- **模块类型选择**：Modal 表格单选
