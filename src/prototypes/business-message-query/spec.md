# 业务消息查询

## 📋 功能说明

### 1.1 核心目标

供研发或运维人员按第三方系统对接要求，核对已配置的消息编码与字段含义；通过推送记录列表与多条件检索，快速定位某次对接推送的业务消息、类型与人工确认情况，支撑联调与线上问题排查。

### 1.2 使用角色

- **研发人员**：对接第三方接口、核对消息码与载荷字段。
- **运维人员**：监控推送结果、追溯需人工确认的消息及确认人。

## 📊 业务规则/约束

### 2.1 业务规则

- **列表字段（表头顺序）**：推送时间、来源、消息码、类型、内容、需人工确认、确认人、确认时间。
- **默认排序**：列表按「推送时间」逆序（最新在前）。
- **消息类型字典**：以码值展示为中文标签——`1` 成功、`2` 通知、`3` 警告、`4` 错误。
- **筛选条件**：
  - 推送时间：起止均为「年月日时分秒」粒度（原型中使用 `datetime-local` 控件模拟）。
  - 消息来源：下拉单选（含「全部」）。
  - 消息码：文本精确/包含匹配（原型为输入框模糊包含）。
  - 类型：下拉单选字典项（含「全部」）。
  - 确认人：模糊匹配（子串、不区分大小写）。

### 2.2 操作说明

- **数据类型**：平铺列表 + 查询条件区。
- **数据源**：前端 Mock 数据（无真实后端）。
- **关键字段**：
  - `二级菜单`：在「设备报警」与「业务消息」之间切换；默认落在「业务消息」。
  - `查询`：按当前条件过滤列表并保持推送时间逆序。
  - `重置`：清空条件并恢复默认展示全部 Mock 数据。

### 2.3 界面默认情况

进入页面二级菜单默认在「业务消息」，并展示全部示例记录；条件区默认「全部」来源与类型；时间范围留空表示不按时间过滤。

## 🎨 布局与结构

- 顶栏与任务管理同风格（集控标题、一级业务入口、时间与电源区）。
- **二级菜单栏**（顶栏下方、`h-12`、与任务管理二级栏同款样式）：仅两项——**设备报警**、**业务消息**；**默认选中「业务消息」**（下划线高亮与文字强调色与任务管理一致）。
- **业务消息**：展示本页查询条件区 + 列表 + 底部分页条。
- **设备报警**：本原型不展开业务，仅展示同风格占位说明，用于验证页签切换与导航层级。

## 🎨 视觉规范

- 沿用任务管理暗黑科技风：`#0b1120` 页面底、`#0f172a` 顶栏/表头、青色强调与边框（`cyan-400` / `cyan-900/30`）。
- Tailwind CSS V4，通过 `style.css` 引入 `@import "tailwindcss"` 与滚动条样式。
- 类型列使用语义色标签：成功偏绿、通知偏青、警告偏黄、错误偏红，保证与深色背景对比可读。
