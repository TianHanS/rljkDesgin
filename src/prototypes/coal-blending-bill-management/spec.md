# 配煤单管理

## 📋 功能说明

### 1.1 核心目标
为发电部燃料专工提供配煤单（加仓计划）全生命周期管理：计划创建、加仓明细维护、提交审批、审核通过后下发堆取料机，并对接 MIS 审核。交互全部采用 Ant Design 右侧抽屉，通过「编辑 / 查看」进入统一维护抽屉，查看态按机组/煤仓分组报表展示加仓明细。

### 1.2 使用角色
- **发电部燃料专工**：创建/编辑配煤单、维护加仓明细、提交审批、下发堆取料机
- **MIS 审核**：后台完成审批，本平台仅展示审核结果状态

## 📊 业务规则/约束

### 2.1 业务规则

1. **计划状态机**：`0编辑` → `1/2审核中`（MIS 后台审批，本平台统一展示「审核中」）→ `3审核通过`；未通过 → `4退回`
2. **列表**：默认查询当日计划；条件为空按计划日期逆序；支持计划编号模糊、计划开始时间范围筛选、表头排序
3. **行操作**：
   - `编辑`：编辑 / 审核通过且未过期 / 退回（抽屉内同时维护计划信息与加仓明细）
   - `提交审批`：仅编辑状态；明细为空提示「请先维护加仓明细！」；提交后状态变为「审核中」
   - `查看`：非编辑状态展示；抽屉内可浏览加仓明细报表
   - `下发堆取料机`：仅审核通过状态；二次确认后补发至煤场管控一体化
   - `删除`：仅编辑状态
4. **新建计划表单**：计划日期/开始/结束时间、计划名称、备注、计划交待信息（说明/清场节点/注意事项）；保存生成编号 GXSZ-YYMMDDnn
5. **保存校验**：保存配煤单时校验全部机组煤仓（2 机组 × A–F 共 12 个）是否均有加仓取煤方案；若有缺失，弹窗列出具体「机组/煤仓」，用户可选择「确认无误，保存」或「返回修改」
6. **加仓明细维护**：取煤来源包含**煤场分区**与**在港在船煤**两类；新增时打开**三级抽屉**多选燃煤，二级抽屉展示已选列表（约十余条）并选煤仓；明细暂存 `draftDetails`，**保存配煤单后一次性提交**
7. **配煤单导出**：列表单选一条配煤单后点击「导出」→ 确认后按「入炉煤掺配方式」版式打开打印预览（可另存 PDF）；未选择时提示「请先选择需导出的配煤单」
8. **下发堆取料机确认文案**：「方案审批后会自动下发至煤场管控一体化，确认再次补发配煤方案？」；**仅下发煤场取煤明细**，在港在船煤不参与下发，确认框中展示条数说明

### 2.2 交互设计（统一维护抽屉）

- **新建配煤单（两步）**：轻量步骤提示（1/2、2/2），非醒目分步条；步骤一录入计划主体信息，步骤二维护加仓明细；支持上一步 / 下一步 / 保存。
- **编辑 / 查看**：仍为单页结构，上方计划主体信息 + 下方加仓明细报表，与原先一致。
- **主抽屉（编辑/查看）**：上方「计划主体信息」表单，下方「加仓明细」分组报表预览；展开明细后随抽屉内容整体纵向滚动，无独立内嵌滚动区。
- **不展示 MIS 审批流程明细**：提交后仅见「审核中」状态，无一级/二级审核操作入口及审批记录时间线。
- **明细报表布局**（对齐业务 Excel 双行表头）：
  - 每组煤仓（A/B/C、E/F、D）独立一块报表。
  - **第一行表头**：`加仓机组及煤仓` | `1号机组/…` | `2号机组/…`（浅蓝底、黑色细边框）。
  - **第二行表头**：取煤来源、分区/批次、煤种、批次车船号、低位发热量、挥发分、硫分、全水、灰分。
  - 在港待卸煤来源行以橙色浅底及「入厂批次」标签区分。
  - **默认收起**：仅展示一行合计数据（分区范围、煤种、煤质均值等），与纸质配煤单缩略行一致。
  - **展开明细**：展示该组全部分区行，末行合计；支持「展开全部 / 收起全部」。
- **二级抽屉**：新增加仓明细；先选**煤仓**，再点击「选择燃煤」打开三级抽屉；确认后以列表展示已选煤场分区与在港在船煤。
- **三级抽屉（选择加仓燃煤）**：
  - **Tab1 煤场**：列表含煤场、分区、存煤量、煤种、热值、水分、挥发分、硫分、灰分；支持煤场下拉、热值范围、煤种模糊搜索；行多选高亮。
  - **Tab2 在港在船煤**：列表含车船号、入厂登记编号、靠泊时间、煤种、预报热值、水分、挥发分、硫分、灰分、预报煤量；行多选高亮。
  - 顶部统计：已选中分区数量、已选中在港煤条数；「确认选择」回到二级抽屉。
  - 抽屉宽度约 1280px；列表分页每页 100 条，表格区域占满可视高度。
- 查看态：报表只读，无新增/编辑/删除操作。
- 编辑/退回态：报表行内提供编辑、删除；顶部提供「新增加仓明细」。

### 2.3 导出版式（入炉煤掺配方式）
- 标题：入炉煤掺配方式；副标题行：掺配时间（计划日期 + 班次）。
- 按煤仓分组（A/B/C、E/F、D）生成多个掺配段落，每段含：
  - 段落标题：`#煤场 分区范围 堆取料机入 #炉 煤仓：出口温度`（温度红色高亮）。
  - 数据表：煤种、低位发热量、挥发分、硫分、全水、灰分、灰熔点、垛位。
- 底部：注意事项（计划说明 + 注意事项条目）、落款「发电部」及计划日期。

### 2.4 界面默认情况
- Ant Design 浅色后台管理风格
- 默认展示当日配煤单列表
