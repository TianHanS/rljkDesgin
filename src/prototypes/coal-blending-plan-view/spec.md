# 配煤单查看

## 📋 功能说明

### 1.1 核心目标

为燃料运行 / 调度人员提供**配煤单只读查看**能力：进入菜单后直接打开右侧抽屉，展示方案主体信息与按煤仓转置的总加仓方案明细（对齐业务配煤单列表下半区）。

### 1.2 使用角色

- **输煤专工 / 燃料值长**：查阅当前或指定配煤方案的机组加仓与取煤位置、煤质指标
- **值班人员**：查看执行中方案明细，无需编辑

## 📊 业务规则/约束

### 2.1 业务规则

1. **只读**：抽屉内全部字段不可编辑，无保存、提交等写操作。
2. **入口**：进入本菜单默认自动打开查看抽屉；关闭后可通过页面「查看配煤单」按钮再次打开。
3. **主体信息**：展示方案名称、方案编号、机组名称、执行日期、开始执行时间、创建人、创建时间。
4. **总加仓方案（转置表）**：
   - 列：第一列为行标签区（左上角展示机组名称），其余列按 `subList` 中的 `mcBunkerName`（如 A–F）动态生成。
   - 行依次为：煤种、取煤位置、热值 kcal/kg、硫分 %、灰分 %、水分 %、挥发分 %、标单。
   - 取煤位置展示规则：`煤场编码` + `煤区范围`（示例：`01 1-13`）；无值显示 `—`。
5. **空数据**：无 `subList` 时转置区展示空状态提示。

### 2.2 操作说明

- **数据类型**：单据查看（单条方案 + 煤仓子表）
- **数据源**：页面内 mock（字段对齐接口主表 / `subList`）
- **关键操作**：
  - `进入菜单`：自动打开查看抽屉
  - `查看配煤单`：重新打开抽屉
  - `关闭`：关闭抽屉，保留落地页

### 2.3 界面默认情况

- 主题：项目默认 `antd-new`（Ant Design 浅色后台）
- 抽屉宽度约 `min(1080px, 96vw)`
- 进入即展示示例方案「1号机组」总加仓方案（A–F 六仓）
