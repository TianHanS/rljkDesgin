# 输煤全流程动态展示

## 📋 功能说明

### 1.1 核心目标
为燃运集控值班人员提供「输煤系统」一站式动态监视入口：以 **2.5D 工艺总览图** 作为主界面，完整呈现煤场、斗轮机、转运站、皮带网、碎煤机、原煤仓与机组日耗；通过菜单或点击图元进入煤场三维、皮带监测、煤仓监测、机组工况等子视图，完成设备状态查看与煤堆/煤仓相关演示操作。

### 1.2 使用角色
- **燃运集控值班员**：实时掌握输煤流程与设备工况，处理异常入口
- **燃料专工**：查看煤堆煤质/煤量、煤仓分层与计划加仓关联信息
- **值长/管理人员**：快速总览机组耗煤与系统运行态势

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 模块与菜单
本原型为**单一模块、多菜单入口**：
| 菜单 | 视图 | 进入方式 |
|------|------|----------|
| 输煤总览 | 2.5D 工艺流程图 | 默认；菜单切换 |
| 煤场三维 | 可交互三维煤场 | 菜单；或点击总览中煤场/#1/#2 斗轮机 |
| 皮带监测 | 皮带设备仪表板列表/详情 | 菜单；或点击总览中皮带段 |
| 煤仓监测 | 煤仓分层与历史加仓 | 菜单；或点击总览中原煤仓 |
| 机组工况 | 机组运行与日耗 | 菜单；或点击总览中机组日耗区 |

#### B. 输煤总览（2.5D）
界面元素对齐参考工艺图，包含但不限于：
- **煤场区**：一号/二号煤场面板，仅数据展示——堆料机运行状态/角度、取料机运行状态/角度；点击进入煤场三维
- **转运站**：T31 / T32 / T33
- **皮带网**：C31A/B～C38A/B 等，运行态绿色、停运态红色，带流向箭头
- **碎煤机**：A / B 及关键报警测点摘要
- **原煤仓**：1A–1F、2A–2F，展示仓位高度（m）与填充色
- **实时辅数**：皮带电流表、瞬时/累计煤量、皮带速度、#1/#2 机组今日耗煤

数据规则（原型模拟）：
- 设备状态、电流、煤量、仓位按定时模拟刷新（约 3s）
- 煤种分层色与批次绑定，同批次同色

#### C. 煤场三维
- 浏览器内轻量 Three.js 场景：煤场堆体、地面皮带、斗轮空间定位示意
- 支持鼠标缩放、平移、旋转
- 悬停煤堆：指针旁显示位置/高度；浮层展示煤种、煤质、煤量、热值、温度、堆煤时间
- 点击煤堆：打开操作抽屉（增改化验、修改煤量、配煤上仓、历史堆取料）

#### D. 点击仪表板与抽屉
- **皮带/斗轮**：弹出/侧栏仪表板——工作状态、位置/姿态、作业煤种、班/日/月/年/总运行时间
- **煤仓**：分层煤种、煤量、煤质、占比、层高、颜色、加仓时间、预计可用时间；可查看历史加仓记录
- **机组**：当前负荷、今日耗煤、加仓相关摘要
- 次级操作均为**演示级**：表单可提交并 `message` 反馈成功，不持久化后端

#### E. 计划加仓工单
总览右侧（或侧栏）展示当前计划加仓工单摘要：煤堆/分区、煤种、机组、煤仓等字段，与配煤业务口径一致（示例数据）。

### 2.2 操作说明

- **数据类型**：工艺监视看板 + 设备/煤堆/煤仓详情
- **数据源**：生成（电厂级示例数据，模拟实时刷新）
- **关键操作**：
  - `切换菜单`: 在总览 / 三维 / 皮带 / 煤仓 / 机组间切换，保留上次选中设备上下文
  - `点击煤场/斗轮`: 进入「煤场三维」
  - `点击皮带`: 进入「皮带监测」并定位该皮带详情
  - `点击煤仓`: 进入「煤仓监测」并定位该仓
  - `点击机组日耗`: 进入「机组工况」
  - `点击测点/设备标签`: 打开测点信息浮层（点名、描述、限值）
  - `煤堆悬停/点击`: 读数提示 / 操作抽屉
  - `三维场景操控`: 滚轮缩放、拖拽旋转、右键或中键平移（OrbitControls）
  - `演示操作提交`: 校验必填后提示成功并关闭抽屉

### 2.3 界面默认情况
- 默认菜单：**输煤总览**
- 默认选中示例运行路径高亮（部分皮带绿色运行）
- 右侧展示一条「当前计划加仓工单」
- 三维页进入后默认俯视偏等轴测视角，自动缓慢旋转可关闭
- 主题：项目默认 `antd-new`（浅色工业集控），工艺图采用浅灰底 + 运行绿 / 停运红

## 🎨 布局与视觉

### 3.1 整体布局
- 顶栏：模块标题 + 菜单 Tabs
- 主区：当前子视图全宽
- 总览：主画布（工艺图）+ 右侧工单/图例窄栏
- 弹层：Drawer / Modal / Tooltip 呈现详情与操作

### 3.2 视觉规范来源
- 主题：`src/themes/antd-new`
- 设计指导：`skills/default-design-guide-minimal`（ToB 效率化）
- 工艺配色对齐用户提供的输煤系统参考图（绿运行、红停运、仓位填充）

### 3.3 组件状态
- 可点击图元：hover 描边/亮度提升，cursor-pointer
- 运行皮带：绿色 + 流向动画；停运：红色静态
- 抽屉表单：默认 / 校验错误 / 提交中 / 成功反馈
