# 上煤单管理

## 📋 功能说明

### 1.1 核心目标
> 简要说明该功能的核心定位、解决的问题、用户场景

为燃料运行人员提供上煤单的查询、查看与确认管理能力。系统自动按班次定时统计出库入炉数据并生成上煤单，人工在班次结束后进行确认，确认后上传 MIS 并更新煤堆库存；未确认单据可跳转「煤场出库入炉」进行明细维护。

### 1.2 使用角色
> 列出此功能模块使用的主要用户对象

- **运行值班员**：查询上煤单、查看明细、维护上煤描述
- **确认人员**：班次结束后确认上煤单并提交 MIS
- **燃料管理人员**：追溯班次上煤留档与确认记录

## 📊 业务规则/约束

### 2.1 业务规则

1. **数据统计更新逻辑**
   - 每 10 分钟自动计算当前班次出库入炉量：查询当前班次是否存在统计主表；若不存在，按「日期 + 班次」生成批次号，取班次开始时间作为上煤日期，状态默认「未确认」。
   - 数据写入 `out_storage_main`、`in_furnace` 两表，当班数据在原记录上覆盖更新。
   - 异常时，用户可在界面按班次新增出库数据；未确认班次支持明细新增、编辑、删除（跳转「煤场出库入炉」维护）。
   - 上煤批次每小时统计一次，明细按「煤场分区 - 煤仓」维度聚合累计加仓量。
   - 班次完结之前，不允许对当班出库入炉量进行确认。

2. **上煤单列表**
   - 默认查询近三日统计数据，按上煤日期逆序返回。
   - 查询条件：上煤日期（默认近三日）、批次号模糊匹配、确认人模糊匹配。
   - 表头操作：筛选（展开/收起高级筛选区）。

3. **列表操作**
   - **查看**：点击后打开右侧抽屉，只读展示上煤单表单与上煤明细列表。
   - **确认**：已确认单据不展示；点击后打开右侧确认抽屉，可编辑上煤描述；抽屉内「提交确认」需 Popconfirm 二次确认，提示「是否确认，确认后，上煤单将自动上传 MIS，对应班次上煤明细将禁止再次维护！」；未结束班次禁止确认；确认后上传 MIS、更新入炉明细为已确认、执行煤堆库存扣减。
   - **调整**：已确认单据不展示；跳转「煤场出库入炉」，代入对应上煤日期、班次筛选条件。

4. **上煤单表单（查看态）**
   - 上煤时间、班次、批次号、上煤总量(t)：只读。
   - 上煤描述：可编辑，确认时可一并提交。
   - 上煤明细按煤场、分区排序（同分区聚合，再细分煤仓）。
   - 明细字段：序号、煤场、分区、机组、煤仓、上煤量(t)。

### 2.2 操作说明

- **数据类型**：上煤单列表、上煤单主表、上煤明细
- **数据源**：前端 Mock（模拟定时统计、MIS 上传、煤堆扣减、页面跳转）
- **关键操作**：
  - `查询`：按上煤日期、批次号、确认人过滤
  - `筛选`：展开/收起筛选面板
  - `查看`：右侧抽屉只读展示表单与明细
  - `确认`：右侧抽屉编辑描述 → 校验班次已结束 → 二次确认 → 提交 MIS + 更新状态
  - `调整`：携带日期、班次参数跳转煤场出库入炉

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- 整体风格参照「卸煤计划管理」：浅色工业后台、浅蓝表头、斑马纹表格、橙色未确认状态标签。
- 默认加载近三日上煤单，按上煤日期倒序。
- 「查看」「确认」均采用右侧抽屉交互；确认抽屉右上角提供「提交确认」操作。
