# 煤场存煤结构管理

> 本原型为**新增**页面，不改动已有的 `src/prototypes/coal-storage-structure`（存煤结构管理）。
> 三个煤场：**#1 / #2 圆形各 36 分区（每区 10°）**，**厂外中转煤场为条形 3 分区**。堆煤高度上限 20 m。界面不展示圆形方位示意图。

## 📋 功能说明

### 1.1 核心目标

面向燃料专责与盘煤专责，把「激光盘煤得到的分区体积」转化为「可追溯到入厂批次、煤种、煤质的分层存煤结构」，并提供出入库与分层维护的完整操作闭环。

解决五个具体问题：

1. **单煤场聚焦**：界面始终呈现单一煤场的库存存煤数据，通过下拉单选切换煤场。
2. **结构化**：按煤场 → 分区 → 分层维护。圆形煤场依扇形楔、条形煤场依直棱柱几何关系计算各分层体积与估算煤量，并反算煤层分界的悬臂俯仰角。
3. **真实高度可读**：把 20 m 上限划分为 200 个 10 cm 分带，以热力图呈现各分区实际堆煤情况，使层厚与分区堆高差异可直接比对。
4. **自动化**：再次盘煤后按体积变动自动生成出入库——体积增加按周期内入厂批次做密度匹配，体积减少自上而下逐层扣减。
5. **人工维护**：入库（顶层新增煤层）、出库（后进先出）、分层拆分、合并上层/下层、删除表层，全部留痕。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 燃料专责 | 核对盘煤比对结果、标记未识别煤层、拆分与合并分层 |
| 盘煤专责 | 录入本次分区盘煤体积、发起盘煤比对 |
| 集控值长 | 查看分区存煤结构与可取煤量、核对出入库明细 |
| 燃料调运 | 登记入库与出库 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 煤场与分区

- 三个煤场，界面通过**下拉单选**切换，始终只展示单一煤场（切换时清空当前选中煤层）：
  | 煤场 | 形态 | 分区 | 盘煤数据源 |
  |------|------|------|-----------|
  | #1 圆形煤场 | 圆形封闭，Φ130 m | 36 区（每区 10°） | 有 |
  | #2 圆形煤场 | 圆形封闭，Φ130 m | 36 区（每区 10°） | 有 |
  | 厂外中转煤场 | 条形，全场长 240 m、底宽 50 m | 3 区（每区 80 m） | 无 |
- 圆形煤场：内半径 8 m 为中心堆料塔，外半径 65 m 为挡煤墙，挡煤墙高 22 m。
- 条形煤场：斗轮沿轨道走行堆煤，挡煤墙高 18 m。
- 允许最大堆煤高度 **20 m**，燃煤安息角 38°。
- 界面一律按**分区编号增序**自左向右排列；**不展示圆形方位示意图**。

#### B. 几何模型

**圆形分区（扇形楔）**：径向断面是等腰梯形，沿周向张开 Δα。按 Pappus 定理：

```
V(h) = Δα · r̄ · A(h)
A(h) = h · (W − h/tanθ)      径向断面积，顶宽 = W − 2h/tanθ
r̄   = Ri + W/2               断面形心半径，W = Ro − Ri
```

**条形分区（直棱柱）**：同一径向断面沿分区长度 L 拉伸：

```
V(h) = L · A(h)
```

`V(h)` 在有效区间单调递增，故可由体积二分反解堆高。分区几何容量 = `V(20 m)`。

**俯仰角反算**：煤层分界面由堆料时悬臂俯仰角决定，`h = pivotHeight + armReach·tan(φ)`。圆形煤场铰点高 12 m、悬臂水平投影 40 m（0~20 m 对应约 **−16.7° ~ +11.3°**）；条形煤场铰点高 10 m、悬臂水平投影 35 m。每层都有一段「起始角度（层底）~ 结束角度（层顶）」区间。

分层体积按堆煤顺序自下而上累计：第 k 层体积 = `V(h_k) − V(h_{k−1})`。

#### C. 煤量与上限

- 煤量 = 体积 × 计算密度。平台默认计算密度 0.85 t/m³，页头可调（0.6~1.2）。
- **各分区盘煤体积即该分区存煤煤量的上限**；层体积之和小于盘煤体积时，差额为「未分配体积」。
- 入库超出分区几何容量时禁止提交并给出原因。

#### D. 盘煤比对

1. 以**全煤场**为口径汇总新增体积 `ΣΔ⁺` 与周期内勾选入厂批次的卸煤量 `Σm`，匹配密度 `ρ = Σm / ΣΔ⁺`。
2. `ρ ∈ [0.78, 0.95] t/m³` → **自动识别**：各增量分区的新增体积按批次煤量比例拆分为煤层，按卸煤完成时间自下而上堆叠。
3. `ρ` 越界或周期内无可匹配批次 → **生成待标记煤层**：仅记录体积与按默认计算密度估算的煤量。
4. 体积减少的分区按减少体积**自上而下**逐层扣减，逐层按其入厂批次形成出库明细。
5. 圆形煤场按扇区连续作业，一个周期内通常只有少数扇区变动，故向导默认只列出有变动的分区，可一键展开全部 36 个。条形场仅 3 个分区，默认列出全部。

#### E. 未识别煤层

存在实际煤量体积但入厂批次归属不明的煤层，使用**固定异常红 `#cf1322`**，并叠加横向条纹纹理与「待标记」文案（颜色不作为唯一标识）。在实际堆煤视图、分层视图、分层数据、检视面板四处表现一致。检视面板顶部给出错误级提示，主按钮切换为 danger 态的「标记入厂批次」。

#### F. 操作 · 入库（顶层新增煤层）

- 抽屉内展示各分区的**分区总体积、存煤高度、存煤量**与剩余容量，支持**单选或多选**分区。
- 输入**入库煤量**与**计算密度**后，自动计算各分区的分摊煤量、新增体积与新增煤层的**起始/结束俯仰夹角**及堆高变化。
- 分摊规则：总煤量在所选分区间**平均分摊**——圆形煤场由堆料机绕中心回转铺层，条形煤场由斗轮沿轨道走行铺层。
- 入厂登记编号可留空，留空时新增煤层标记为待人工确认。
- **二次提示**：若所选分区已有盘煤体积（且该煤场有盘煤数据源），保存时弹出确认——「此煤场体积通过盘煤仪获得，若手动增加，将影响实际存煤体积信息。」

#### G. 操作 · 出库

- 选择分区、输入出库煤量与其他说明。
- 按**后进先出**顺序（自表层向下）扣减分区煤量，每层用其自身计算密度把煤量折算为体积，取空的煤层自动移除。
- 抽屉内实时预览逐层扣减明细（扣减顺位、煤层、入厂登记编号、煤种、扣减体积/煤量、是否取空），以及出库后剩余煤量与堆高。
- 煤量不足时禁止提交并给出缺口数值。

#### H. 操作 · 分层拆分

- 选中分层后展示该层的**煤量、体积、俯仰夹角区间与标高区间**。
- 下方分层信息列表按**自上而下**排列，每行含：入厂登记编号（下拉选择对应入厂批次）、结束角度、起始角度、标高区间、分层体积、占比、煤量。
- 角度联动规则：**下一层的结束角度自动取上一层的起始角度**；首行结束角度锁定为原层顶角，末行起始角度锁定为原层底角。用户只需逐行输入起始角度，其下方各层的角度、体积、占比与煤量实时联动重算。
- 由系统锁定或联动得出的角度以浅底徽标标注来源（「锁定层顶」「取上层起始角」「锁定层底」），与可输入的起始角度形成明确区分。
- 输入框清空或处于中间态（如仅输入负号）时保留原值，不把 `null` 强制写成 0，避免数值被弹回。
- 校验：每行起始角度必须小于其结束角度且自上而下依次递减；分层体积必须大于 0。
- 分层数可增减（2~6 层），增减时按角度等分重置初值。
- **确认拆分需二次确认**（`Popconfirm`）。

#### I. 操作 · 分层合并

- **合并上层**：仅非顶层煤层可用；**合并下层**：仅非底层煤层可用。不可用时按钮禁用并在 `Tooltip` 中说明原因。
- 抽屉内并列展示两层煤的信息（煤层、入厂登记编号、煤种、体积、煤量、层厚、起始/结束角度），并用红色标签明确标记**被合并煤层**，该行整行浅红底。
- 合并后保留基准层的入厂批次归属，计算密度按两层体积加权重算，俯仰夹角区间按几何关系重新确定；两层批次不同时给出警告说明归属变化。

#### J. 操作 · 删除

- **非表层煤不可直接删除**：按钮禁用，`Tooltip` 说明「其上方仍压覆着煤层，直接删除会使上层煤悬空。请先出库或合并处理表层煤。」
- 删除表层煤时二次确认：「直接删除将不会形成出入库记录，确认直接删除煤堆信息？」并列出该层的体积与煤量。
- 删除只写调整记录，不产生出入库记录。

### 2.2 操作说明

- **数据类型**：热力图 / 二维表格 + 操作抽屉 + 出入库台账
- **数据源**：前端生成（`data.ts`）。`/assets/database/` 下仅有 `orders.json`，与本业务无关，故按后台／ToB 场景生成专业、完整的兜底数据：2 个圆形煤场（各 36 区）+ 1 个条形煤场（3 区）、5 个煤种、12 个入厂批次，含预置未识别煤层。存煤分层按**作业带**生成：同一入厂批次覆盖连续分区并取相同层厚，相邻分区的同批煤层高度近似、色带连贯；未识别层也落在连续分区上。
- **入厂登记编号**格式沿用 `src/prototypes/coal-unloading-management` 的既有约定（如 `gxsz-2026-054RCDJ2026081802`）。

| 操作 | 效果 | 约束与校验 |
|------|------|-----------|
| `切换煤场` | 下拉单选，切换后界面仅展示该煤场数据并清空选中煤层 | 无盘煤数据源的煤场禁用盘煤比对；选项标注形态（圆形/条形）与分区数 |
| `调整默认计算密度` | 影响待标记煤层估算煤量、入库折算与盘煤匹配判定 | 0.6 ~ 1.2 t/m³ |
| `切换视图` | 实际堆煤视图 / 分层视图 / 分层数据 三视图共享同一选中状态；图例右侧读图说明随视图切换 | — |
| `切换展示信息` | 各煤层缩略信息在库存煤种（默认）、船名/航次、热值、体积、起始角度、入厂登记编号间切换 | 窄列使用紧凑形态，完整值见悬停气泡与检视面板 |
| `点选煤层` | 右侧检视面板展示体积、煤量、密度、层厚、标高区间、起始/结束角度与五项煤质 | 支持键盘 Enter / Space |
| `盘煤比对` | 录入分区盘煤体积、勾选入厂批次，实时显示 ρ 与判定，确认后落到煤层结构并生成台账 | 仅有盘煤数据源的煤场；体积 0 ~ 分区几何容量；无变动时禁用执行；圆形场默认只看变动分区，可展开全部 36 个 |
| `入库` | 在所选分区顶层新增煤层 | 需选至少 1 个分区、煤量与密度 > 0、不得超几何容量；已有盘煤体积时二次提示 |
| `出库` | 按后进先出扣减并生成逐层出库明细 | 煤量不得超过分区现存煤量 |
| `分层拆分` | 单层拆为 2~6 层 | 角度须自上而下递减、各层体积 > 0；需二次确认 |
| `合并上层 / 合并下层` | 相邻两层合并为一层 | 顶层禁用合并上层，底层禁用合并下层 |
| `删除煤层` | 直接删除表层煤，不形成出入库记录 | 非表层禁用；需二次确认 |
| `标记入厂批次` | 待标记煤层转为已标记，带入船名／航次／煤质，煤量按密度重算 | 入厂登记编号、库存煤种、计算密度必填 |
| `定位待标记煤层` | 跳选当前煤场第一个待标记煤层 | 无待标记时提示 |

### 2.3 界面默认情况

- 默认煤场 **#1 圆形煤场**，默认视图 **实际堆煤视图**，默认展示信息 **库存煤种**，右侧检视面板为**空态引导**（含「定位 N 个待标记煤层」入口）。
- 页面自上而下四层结构：
  1. **页头**：标题与业务说明、煤场下拉单选、默认计算密度、盘煤比对按钮。
  2. **煤场库存统计看板**：
     - 总体积（含盘煤时间）与上次盘煤体积（含盘煤时间），并列在同一卡内，右侧给出两次盘煤的净变化；
     - 存煤量（副标题标注默认计算密度与占几何容量比例）；
     - 未识别煤堆（个分区，副标题给出其实际存在的体积）；
     - 待人工标记数量（层，副标题可点击定位）。
  3. **存煤结构维护**：面板头含入库、出库按钮与视图切换；下方为展示信息筛选条、图例、视图区；右侧为常驻煤层检视面板。
  4. **底部台账**：入库记录 / 出库明细 / 调整记录 三个页签。
- 空状态：空区在实际堆煤视图中无方块且底轴堆高显示「—」；分层视图缺层格子用极淡斜纹表示。

## 🧭 布局与结构

- **布局模式**：单页纵向分区 + 主区双栏固定比例（内容区 `3.25fr` / 检视面板 `1fr`，检视最小 340 px）。页面根节点 `min-width: 1280px`，窄屏横向滚动，**不把检视面板折到主视图下方**。
- **存煤结构维护 / 煤层检视**：工具条、展示信息筛选条、图例均为 `flex-wrap: nowrap`；内容超出时该条内部横向滚动，不随页面宽度自动换行。
- **实际堆煤视图**：全宽热力图，无左侧圆形示意图。圆形场 36 列用 34 px 窄列横向滚动；条形场 3 列用 196 px 宽列撑满主区。分带高 2.4 px（200 分带共 480 px），左轴堆煤高度每 2 m 一个刻度、右轴同高度对应的俯仰角度、底轴分区编号（圆形场每 5 区加粗）并附该区堆高。
- **分层视图**：圆形场列宽最小 92 px、36 列横向滚动；条形场列宽最小 160 px、3 列均分。行高最小 56 px（容纳缩略信息 + 层厚 + 标高区间三行）。
- **关键尺寸**：页面内边距 20/24 px；卡片圆角 8 px；间距基准 4 px。
- **响应式**：
  - 主区双栏比例在各宽度下保持不变，不因断点改单栏。
  - `≤ 1200px`：看板改两列（盘煤体积卡占满整行）；抽屉表单改两列。
  - `≤ 760px`：看板与抽屉表单改单列；检视面板煤质仍保持五列。

- **签名元素**：把 20 m 堆煤上限拆成 200 个 10 cm 方块的热力图，纵轴是真实标高、右轴是同一高度对应的悬臂俯仰角度——层厚直接表现为连续方块的段数。圆形场以 36 列展开图阅读周向结构，条形场以 3 列宽条阅读条段，均不再附圆形方位示意图。
- **拒绝的默认做法**：
  1. 固定行高的层序矩阵作为主视图 → 以真实标高为纵轴的 10 cm 分带热力图；
  2. 弹窗内改配置 → 右侧常驻检视面板 + 操作抽屉，操作时不丢失可视化上下文；
  3. 图标 + 大数字 KPI 卡片 → 盘煤体积双值并置卡（本次/上次同框对照并直接给出净变化）。

### 配色规则（化解需求内在冲突）

需求同时要求「同批次煤按同一颜色展示」与「同类同煤质的燃煤使用相同颜色展示」，二者在“同煤质不同批次”时冲突。本页统一为：

> **色族 = 库存煤种（煤质类别），色阶 = 入厂登记编号（批次）**

五个煤种各有一组四阶低饱和工业色（神混=蓝灰、准格尔=琥珀棕、印尼褐煤=褐红、俄罗斯煤=深青、蒙煤=紫灰）；同煤种的不同入厂批次取同色族的不同色阶。图例明确标注该规则。

### 组件状态定义

| 状态 | 表现 |
|------|------|
| 默认 | 煤层方块填色 + 层顶分界线；卡片 1px 描边 |
| 悬停 | 煤层整层 `opacity .84`；格图内描 2px 白框（均无位移，不产生布局抖动） |
| 选中 | 煤层／格子 2px 主色描边 |
| 聚焦 | 煤层、格子均可 Tab 聚焦并显示主色外描边（`:focus-visible`） |
| 禁用 | 按钮 antd 禁用态 + `Tooltip` 说明禁用原因（而非静默禁用） |
| 加载 | 本原型为前端即时计算，无异步加载态；操作反馈统一用 `message` |
| 空 | 空区无方块 + 底轴「—」；检视面板空态引导；表格 antd 空态 |
| 异常 | 待标记煤层：固定异常红 + 横向条纹 + `Tag` 文案 + 面板 error 级 `Alert`；校验失败用 `Alert` + 输入框 error 态并禁用提交 |

### 可访问性

- 煤层文字前景色按背景相对亮度自动在 `rgba(0,0,0,0.88)` / `#ffffff` 间切换，保证 WCAG 2.1 AA 对比度。
- 颜色不作为唯一标识：待标记煤层另有条纹纹理与「待标记」文案；分层视图格内除底色外还有层厚与标高区间数值。
- 煤层（热力图 `<g>`、格图单元）均可 Tab 聚焦，支持 Enter / Space 触发；热力图 SVG 带 `role="img"` 与中文 `aria-label`，每个煤层带 `<title>` 悬停摘要。
- `prefers-reduced-motion: reduce` 时关闭全部过渡动画；过渡时长统一 160 ms。
