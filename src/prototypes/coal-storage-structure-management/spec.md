# 煤场存煤结构管理

> 本原型为**新增**页面，不改动已有的 `src/prototypes/coal-storage-structure`（存煤结构管理）。
> 两者定位差异：既有页面以堆叠柱状示意为主，本页面以「盘煤驱动 + 几何反算 + 台账闭环」为主线，
> 覆盖盘煤比对自动出入库、批次密度匹配、俯仰角反算、厂外煤场手动维护等完整业务链路。

## 📋 功能说明

### 1.1 核心目标

面向燃料专责与盘煤专责，把「激光盘煤得到的分区体积」转化为「可追溯到批次、煤种、煤质的分层存煤结构」。

解决四个具体问题：

1. **初始化**：初次盘煤只有体积，需按平台配置的默认燃煤密度完成煤量初始化。
2. **结构化**：煤堆需按煤场 → 分区 → 分层（批次）维护，并依直扇形楔几何关系计算各分层体积与估算煤量，反算煤层分界的臂架俯仰角。
3. **自动化**：再次盘煤后按体积变动自动生成出入库——体积增加时按周期内接卸批次做密度匹配，体积减少时自上而下逐层扣减。
4. **兜底**：密度不合理或无接卸台账时生成待标记煤层；无盘煤数据源的厂外煤场支持手动维护，且调整结果必须回写到数字化煤场原有煤堆，保证存煤有量可供取煤扣减。

典型场景：早班 07:30，盘煤报告到达，用户需要在十分钟内确认体积变了多少、系统自动怎么分批、哪几层需要人工标记。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 燃料专责 | 核对盘煤比对结果、标记未识别煤层、维护批次与煤质 |
| 盘煤专责 | 录入／导入本次分区盘煤体积、发起盘煤比对 |
| 集控值长 | 查看分区存煤结构与可取煤量、核对出入库明细 |
| 厂外煤场管理员 | 无盘煤煤场的手动入库、出库与库存调整登记 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 结构层级与几何模型

- 层级：**煤场 → 分区 → 煤层（批次）**。分区界面按分区序号从小到大自左向右排列。
- 挡煤墙高度 **19 m**，允许最大堆煤高度 **18 m**，堆底宽（挡煤墙净间距）**52 m**，燃煤安息角 **38°**。
- 煤堆形态为**直扇形楔**（等腰梯形直段 + 两端半锥，两端半锥合并为一个完整圆锥）：

  ```
  V(h) = A(h)·L + π·h³ / (3·tan²θ)
  A(h) = h·(W − h/tanθ)        顶宽 = W − 2h/tanθ
  ```

  其中 `L` 为堆煤直段长度、`W` 为堆底宽度、`θ` 为安息角。`V(h)` 在有效区间单调递增，故可由体积二分反解堆高。
- **俯仰角反算**：煤层分界面由堆料时臂架俯仰角决定，`h = pivotHeight + armReach·tan(φ)`（回转中心高 8.2 m，臂架水平投影 26 m），因此每层都有一段 `[φ底, φ顶]` 的起始／终止切角区间。
- 分层体积按堆煤顺序自下而上累计：第 k 层体积 = `V(h_k) − V(h_{k−1})`。

#### B. 煤量初始化与上限

- 初次盘煤后按平台配置的**默认燃煤密度**（默认 0.85 t/m³，页头可调）完成煤量初始化：`煤量 = 体积 × 密度`。
- **各分区盘煤体积即该分区存煤煤量的上限**。分区内各层体积之和小于盘煤体积时，差额显示为「未分配体积」。
- 分区几何容量（堆至 18 m 的体积）作为物理上限，盘煤体积录入不得超过该值。

#### C. 盘煤比对（体积增加）

1. 以**全煤场**为口径汇总新增体积 `ΣΔ⁺`，汇总盘煤周期内勾选接卸批次的卸煤量 `Σm`。
2. 匹配密度 `ρ = Σm / ΣΔ⁺`。
3. `ρ ∈ [0.78, 0.95] t/m³` → **自动识别**：各增量分区的新增体积按各批次煤量比例拆分为煤层，按卸煤完成时间自下而上堆叠，煤量按 ρ 计算，状态为「已标记」。
4. `ρ` 越界或周期内无可匹配批次 → **生成待标记煤层**：仅记录该煤层的具体体积与按默认密度估算的煤量，状态为「待标记」，并提示用户手动标记存煤批次。
5. 两种路径均记录新增煤层的**起始切角角度范围**（`pitchFrom → pitchTo`）并写入入库记录说明。

#### D. 盘煤比对（体积减少）

- 按减少体积**自上而下**逐层扣减：`cut = min(层体积, 剩余待扣减)`，体积扣空的煤层自动移除。
- 每一层的扣减都按其批次归属单独形成一条出库明细（分区 + 批次口径）。

#### E. 待标记煤层与人工维护

- 待标记煤层使用**火警橙 + 45° 斜纹**（颜色之外另有纹理与文案，不以颜色作为唯一标识），在剖面图、热力格图、明细表、检视面板四处一致呈现。
- **标记批次**：选择接卸批次后自动带入船名、航次与化验煤质，煤量按所填密度与层体积重算。
- **调整煤量 / 起始俯仰角**：两种输入方式互算——
  - 按煤量：`体积 = 煤量 / 密度`；
  - 按层顶俯仰角：`h = pivotHeight + armReach·tan(φ)` → `体积 = V(h) − 层底累计体积`。

  差额优先与**相邻上层借还**，保持分区总体积不超过盘煤体积上限；借用量不得超过上层存量（超出时提示「已受上层存量限制」）。调整后上层分界俯仰角随之重算。
- **合并相邻煤层**：保留基准层的批次归属，体积相加，密度按体积加权重算；跨批次合并前用确认弹窗说明归属变化。
- 所有人工操作均写入**调整记录**（时间、操作人、对象、动作、调整前、调整后）。

#### F. 无盘煤煤场（厂外中转煤场）

- 无激光盘煤数据源，「盘煤比对」按钮禁用并说明原因；库存以**手动台账**为准。
- 支持三类登记：
  - **入库**：入库时间、目标分区、来煤批次、入库煤量、备注 → 按堆煤顺序堆至煤堆顶层（顶层同批次时并入）；
  - **出库**：按取煤顺序自上而下扣减，逐层按其自身密度折算体积，煤量不足时拒绝并提示缺口；
  - **直接调整库存**：录入目标库存煤量，差额自动判定为入库或出库。
- 每笔登记都**回写到数字化煤场的煤堆分层结构**并同步刷新分区盘煤体积，保证煤场存煤有量、可继续取煤扣减。
- 厂内煤场则反向约束：「手动维护库存」按钮禁用，库存变动只能通过盘煤比对或煤层调整完成。

### 2.2 操作说明

- **数据类型**：可视化剖面图 / 热力块状表格 / 二维明细表 + 配置表单 + 出入库台账
- **数据源**：前端生成（`data.ts`）。`/assets/database/` 下仅有 `orders.json`，与本业务无关，故按后台／ToB 场景生成专业、完整的兜底数据：3 个煤场、15 个分区、5 个煤种、7 个接卸批次，含 2 个预置待标记煤层。
- **关键操作**：

  | 操作 | 效果 | 约束与校验 |
  |------|------|-----------|
  | `切换煤场` | 切换 #1 煤场 / #2 煤场 / 厂外中转煤场，清空当前选中煤层 | 厂外煤场自动切换为手动维护模式 |
  | `调整默认燃煤密度` | 影响待标记煤层的估算煤量与盘煤匹配判定 | 0.6 ~ 1.2 t/m³ |
  | `切换视图` | 剖面结构 / 热力格图 / 分层明细 三视图共享同一选中状态 | — |
  | `切换缩略展示参数` | 剖面与热力格图中煤层上的文字在批次、船名、航次、煤种、热值、硫分、灰分、挥发分、水分、体积、煤量之间切换 | 未标记煤层显示「待标记」 |
  | `点击煤层` | 在右侧检视面板展示体积、煤量、密度、层厚、标高区间、分界俯仰角与五项煤质 | 支持键盘 Enter / Space 触发 |
  | `点击差量条` | 定位该分区顶层煤层 | 空区无顶层时不响应 |
  | `盘煤比对` | 录入各分区本次盘煤体积、勾选周期内接卸批次，实时显示 ρ 与判定，确认后落到煤层结构并生成台账 | 仅厂内煤场；体积 0 ~ 分区几何容量；无任何体积变动时禁用执行 |
  | `标记存煤批次` | 待标记煤层转为已标记，带入船名／航次／煤质，煤量按密度重算 | 批次、煤种、密度必填 |
  | `调整煤量 / 起始俯仰角` | 按几何关系重算本层与相邻上层分布 | 调整后体积必须大于 0；借用量受上层存量限制 |
  | `合并上层 / 合并下层` | 相邻两层合并为一层 | 底层禁用「合并下层」，顶层禁用「合并上层」；跨批次需确认 |
  | `定位待标记煤层` | 跳选当前煤场第一个待标记煤层 | 无待标记时提示 |
  | `手动入库 / 出库 / 库存调整` | 登记台账并回写煤堆结构 | 仅厂外煤场；出库煤量不得超过现存煤量；目标库存与现值一致时不产生记录 |

### 2.3 界面默认情况

- 默认煤场 **#1 煤场**，默认视图 **剖面结构**，默认缩略参数 **批次**，右侧检视面板为**空态引导**（含「定位 N 个待标记煤层」入口）。
- 页面自上而下四层结构：
  1. **页头**：标题与业务说明、煤场切换、默认密度、盘煤比对 / 手动维护按钮、上次盘煤时间与盘煤周期。
  2. **盘煤差量条**：左侧为每分区一根发散条（向上=体积增加、向下=体积减少），右侧五个数字（本次盘煤体积、存煤煤量、自动入库、自动出库、待标记煤层）。厂外煤场时改为台账口径。
  3. **主区**：左为结构视图（含参数切换条与图例），右为常驻煤层检视面板。
  4. **底部台账**：入库记录 / 出库明细 / 调整记录 / 厂外手动台账 四个页签。
- 空状态：无存煤的分区在剖面中显示虚线轮廓与「空区」，并在页脚提示「无存煤，可接收新批次」；热力格图中缺层的格子用极淡斜纹表示。
- 异常状态：待标记煤层在检视面板顶部显示 `Alert` 警告并把主按钮切换为 danger 态的「标记存煤批次」。

## 🧭 布局与结构

- **布局模式**：单页纵向分区 + 主区双栏（内容区 `1fr` / 检视面板 `344px`）。
- **关键尺寸**：页面内边距 20/24 px；卡片圆角 8 px；分区剖面 SVG 198 × 242 px，横向可滚动；热力格图行高 46 px、列最小宽 98 px。
- **响应式**：
  - `≤ 1360px`：主区收为单栏，检视面板移至结构视图下方并取消吸顶。
  - `≤ 1100px`：差量条与数字组改为上下排列。
  - `≤ 720px`：页头纵向堆叠，煤质由五列改为三列。
- **信息密度**：属于密集型工程工具，采用小字号（11 ~ 13.5 px）+ 紧凑行高，数字统一 `tabular-nums` 等宽对齐。

### 设计意图与领域取色

设计意图：**像一份工程剖面图纸**——冷静、密实、有刻度、可信。

可视化域的颜色取自煤场实景，与控件主色分工明确（控件表达“可操作”，可视化表达“煤场里的东西”）：

| 语义 token | 取值 | 来源与用途 |
|-----------|------|-----------|
| `--yard-apron` | `#f1f0ed` | 场坪水泥，页面底色 |
| `--yard-wall` / `--yard-wall-edge` | `#cbc6bd` / `#a9a39a` | 挡煤墙混凝土，剖面墙体 |
| `--coal-ink` 四级 | `#262320` / `#5b554e` / `#8b847b` / `#b3aca3` | 煤黑文本层级（主要／次要／元信息／占位） |
| `--rule-hair/line/firm/focus` | 透明度 0.08 / 0.16 / 0.30 + 主色 | 四级分隔线，按边界重要度分配权重 |
| `--scan-teal` | `#0f8f8c` | 激光盘煤量测语义：体积增加、自动入库 |
| `--stacker-amber` | `#b8790a` | 斗轮机语义：体积减少、自动出库、最大堆高限值线 |
| `--unmarked-flare` | `#e8590c` | 待标记煤层异常态 |

- **深度策略**：仅用描边（borders-only），不叠加阴影 —— 匹配密集型工具的技术感。
- **签名元素**：分区剖面中，煤层分界线按反算出的俯仰角**倾斜**绘制并被煤堆轮廓自然裁剪（半平面裁剪），左侧为堆高刻度（m），右侧为分界俯仰角标注（°）。这一表达只可能属于斗轮堆取料煤场。
- **拒绝的默认做法**：
  1. 普通水平堆叠柱 → 带挡煤墙轮廓与倾斜分界的梯形剖面；
  2. 弹窗内改配置 → 右侧常驻检视面板，操作时不丢失可视化上下文；
  3. 图标 + 大数字 KPI 卡片 → 盘煤差量条，把体积增减与自动出入库判定画在一起。

### 配色规则（化解需求内在冲突）

需求同时要求「同批次煤按同一颜色展示」与「同类同煤质的燃煤使用相同颜色展示」，二者在“同煤质不同批次”时冲突。本页统一为：

> **色族 = 煤种（煤质类别），色阶 = 批次**

五个煤种各有一组四阶低饱和工业色（神混=蓝灰、准格尔=琥珀棕、印尼褐煤=褐红、俄罗斯煤=深青、蒙煤=紫灰）；同煤种的不同批次取同色族的不同色阶。图例明确标注该规则。

### 组件状态定义

| 状态 | 表现 |
|------|------|
| 默认 | 煤层填色 + 白色细分界线；卡片 1px 描边 |
| 悬停 | 煤层 `opacity .86`；格图内描 2px 白框；差量条项浅底 + 描边（均无位移，不产生布局抖动） |
| 选中 | 煤层／格子 2px 主色描边，所属分区卡片浅主色底 |
| 聚焦 | 差量条项 2px 主色外描边（`:focus-visible`）；煤层与格子为原生可聚焦元素 |
| 禁用 | 按钮 antd 禁用态 + `Tooltip` 说明禁用原因（而非静默禁用） |
| 加载 | 本原型为前端即时计算，无异步加载态；操作反馈统一用 `message` |
| 空 | 分区空区虚线轮廓 + 「空区」；检视面板空态引导；表格 antd 空态 |
| 异常 | 待标记煤层：火警橙 + 45° 斜纹 + `Tag` 文案 + 面板 `Alert` |

### 可访问性

- 煤层文字前景色按背景相对亮度自动在 `#1b1815` / `#ffffff` 间切换，保证 WCAG 2.1 AA 对比度。
- 颜色不作为唯一标识：待标记煤层另有斜纹纹理与「待标记」文案；热力格内除底色外还有层厚细条与数值。
- 煤层（剖面 `<g>`、格图单元）与差量条项均可 Tab 聚焦，支持 Enter / Space 触发；剖面 `<svg>` 带 `role="img"` 与中文 `aria-label`，每个煤层带 `<title>` 悬停摘要。
- `prefers-reduced-motion: reduce` 时关闭全部过渡动画；过渡时长统一 160 ms。
