# 存煤结构管理

## 📋 功能说明

### 1.1 核心目标
> 简要说明该功能的核心定位、解决的问题、用户场景

该模块为“燃料集控平台”的核心功能，提供四维数字化煤场界面，用于煤场存煤结构（按煤场、分区、分层）的可视化管理与维护。主要解决盘煤后的煤量初始化、批次分层维护、煤量与体积的自动计算及匹配、异常煤层标记及手动调整等问题。

### 1.2 使用角色
> 列出此功能模块使用的主要用户对象

- 燃料管理人员
- 煤场调度员
- 盘煤专责人员

## 📊 业务规则/约束

### 2.1 业务规则
> 按界面内容、模块逐个说明其中主要业务对象的业务规则、流程等内容

1. **结构层级**：煤场 -> 分区 -> 分层。
2. **煤量计算**：
   - 盘煤获取体积 -> 按默认密度计算初始化煤量。
   - 分层维护 -> 根据直扇形楔几何关系计算体积与估算煤量。
   - 反算俯仰角：根据体积反算分界俯仰角度。
3. **盘煤比对更新**：
   - **体积增加**：匹配周期内接卸批次。密度合理时自动识别为新批次；否则记录体积/煤量并标记为异常，需手动标记批次。
   - **体积减少**：按减少体积，自上而下逐层扣减对应批次煤量，生成出库明细。
4. **可视化要求**：
   - 煤场分区从左至右（按体积/从小到大）排列展示。
   - 热力图/柱状图/二维表格展示存煤情况。
   - 按高度相对比例渲染各层。
   - 同批次/同煤质燃煤使用相同颜色。
   - 悬浮/点击可查看详情，并可在缩略图中切换显示关键参数（批次、船名、煤种等）。
5. **异常与手动维护**：
   - 未识别批次使用异常颜色标记，支持点击配置。
   - 已标记煤层支持合并、更改。
   - 无盘煤信息的厂外煤场支持手动出入库维护。

### 2.2 操作说明
> 按用户在界面可操作的所有内容、按钮、列表、操作步骤等，同时附带各操作的前端后端校验规则

- **数据类型**：可视化图表/配置表单
- **数据源**：前端模拟生成
- **关键字段**：
  - `切换显示信息`: 可在“批次、船名、航次、煤种、热值、硫分、灰分、挥发分、水分”之间切换煤层上显示的文本。
  - `点击煤层`: 弹出弹窗或抽屉，显示该分层的详细信息（体积、煤量、煤质等），若为“未识别”批次，提供表单进行手动配置。
  - `合并/更改煤层`: 在详情弹窗中，提供合并相邻煤层或更改当前煤层信息的操作。
  - `盘煤比对(模拟)`: 按钮触发模拟的盘煤数据更新（增加/减少），展示系统的自动扣减或新增提示。
  - `手动出入库`: 提供给厂外煤场的手动记录入口。

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- 页面顶部为全局操作栏与信息切换控件。
- 页面主体为“煤场存煤结构图”，X轴为各分区（如：1A, 1B, 2A...），Y轴为堆煤高度/体积。
- 采用堆叠柱状图形式呈现各分区下的煤层，同批次使用相同颜色，未识别使用显眼的警告色（如红色/橙色条纹）。
- 柱子色块上默认显示批次号或船名。
- 右侧或底部可提供简单的出入库记录列表。
