# 卸煤管理（含新增卸煤计划与完结）

## 📋 功能说明

### 1.1 核心目标

为燃料运行人员提供卸煤计划管理能力，覆盖：

1. **新增卸煤计划**：关联来煤入厂登记、填写计划信息、创建堆煤方案；
2. **卸煤计划完结**：圆形煤场分区较细（36 区）时，一船入库分摊到多分区的完结场景。

默认示例按一船煤分别卸入**一号圆形煤场、二号圆形煤场**展示。

### 1.2 使用角色

- **输煤专工 / 燃料值长**：新增计划、创建堆煤方案、维护卸煤记录、确认分配量并完结
- **燃料管理人员**：查看计划与分区分配明细

## 📊 业务规则/约束

### 2.1 业务规则

#### 列表

- 卸煤状态：待卸煤 / 正在卸煤 / 卸煤中断 / 已卸煤
- **「完结」显示条件**：「卸煤中断」，或「待卸煤」
- **完结准入（后端校验模拟）**：仅「卸煤中断」，或「待卸煤且已有卸煤明细」允许完结；否则提示：**卸煤状态异常，请先中断卸煤！**
- 其他操作（查看、开始卸煤、编辑、提交审批、删除等）按现有业务保留简化演示

#### 新增卸煤计划（侧边抽屉）

点击「新增」打开**右侧抽屉**（宽度 `min(960px, 96vw)`），与完结交互统一，一屏展示三段信息：

1. **入厂登记信息**（只读摘要 + 选择批次）  
   - 未选择时展示引导区；点击「选择批次」打开**二级抽屉**（`push={false}`，宽度 `min(1120px, 94vw)`）  
   - 批次表字段：入厂登记编号、供应商名称、煤品种、煤种、运单量(t)、车船名、航次、到港日期  
   - 单选一条批次后确定，回填摘要：供应商、车船号、航次、入厂登记编号、煤品种、煤种、运单量、单价、实际到厂时间  
   - 清空可移除已选批次  

2. **计划信息**（标签右对齐横向表单，两列）  
   - 计划名称、开始时间*、结束时间*、计划卸煤吨位(t)*、卸煤类型*、备注  
   - 计划卸煤吨位默认带入所选批次运单量，可改；选批次后默认同步起止时间与卸煤类型  

3. **堆煤方案**  
   - 「创建方案」/「方案调整」打开**二级抽屉**（宽度 `min(1180px, 96vw)`）  
   - 主抽屉内表格展示已选分区；可为空  

保存校验：须已选入厂批次；开始/结束时间、计划卸煤吨位(>0)、卸煤类型必填；若已填写堆煤方案，则分区计划堆煤量合计须等于计划卸煤吨位。保存后写入列表，状态为「待卸煤 / 编辑中」。

#### 创建 / 调整堆煤方案

二级抽屉顶部只读摘要带入计划信息：煤品种、煤种、**计划堆煤量(=计划卸煤吨位)**、入厂登记编号、航次、船号。

- 展示两煤场全部分区列表，**按煤场 → 分区号排序**，多选、不分页；支持煤场筛选、「仅展示已选分区」
- 字段：序号、煤场、分区、计划堆煤量、分配百分比、容量上限、存煤量、剩余容量、堆煤后状态、煤质信息
- **分配卸煤量**：须先勾选分区；模拟后端按「剩余容量权重」计算各分区计划堆煤量、分配百分比、堆煤后是否超容量上限
- 权重基数 = max(容量上限 − 存煤量, 0)；权重合计为 0 时按勾选分区均分
- 计算结果**取整**；各分区小数余数累计后加到最后一区，保证合计等于计划卸煤吨位
- 若任一分区「存煤量 + 计划堆煤量 > 容量上限」，前端提示：**可能超出分区容量**（不阻断保存，可继续调整）
- 用户可重新勾选分区并再次点击「分配卸煤量」重算，直至提交保存
- 分配后可手改各分区计划堆煤量（整数）；手动修改后同步刷新分配百分比与超限状态
- **重置**：清空勾选与已分配量，可重新勾选后再分配
- 保存时合计须等于计划堆煤量，否则阻断并提示「输入的煤量总和与计划堆煤量不相等」

#### 完结交互（侧边抽屉 + 分步表单）

完结使用**右侧抽屉**承载（宽度 `min(1160px, 96vw)`），内容拆为 3 步：

##### 第 1 步：确认卸煤明细 / 卸煤总量

a. **入厂登记批次信息、卸煤计划信息**只读展示（车船号、航次、煤品种、计划编号、计划卸煤总量、运单量、卸煤类型、计量皮带秤、供应商、到厂时间、备注等）。

b. **卸煤记录列表管理**（行内编辑 / 删除；点「新增」打开二级普通表单）：

| 字段 | 规则 |
|------|------|
| 卸煤类型* | 字典 `CoalRealunloadMethod`：`CoalRealUnloadMethod_1` 皮带卸煤 / `CoalRealUnloadMethod_2` 上煤 / `CoalRealUnloadMethod_3` 人工填报 |
| 计量皮带秤* | 仅类型=1 时展示；下拉单选入厂皮带秤设备 |
| 卸煤开始/结束时间* | 年月日时分秒 |
| 时段冲突校验 | 类型=1 且已选皮带秤+起止时间后，模拟后端校验：该皮带秤在时间段内是否已存在卸煤记录（匹配范围为**全部计划**的卸煤记录）；冲突则阻断保存 |
| 入库煤场* | 下拉单选煤场 |
| 上煤煤仓* | 仅类型=2 时展示；下拉多选煤仓列表 |
| 卸煤量* | 必填且 >0；类型=1 在通过冲突校验后可按时段模拟回填，可手改 |

c. **下一步**：校验卸煤总量 > 0，否则不可完结（无法进入第 2 步）。

##### 第 2 步：确认实际入库煤场分区，分配各分区实际入库量

a. 加载卸煤记录卸煤总量、加载计划堆煤方案分区；进入本步时按方案分区剩余容量自动计算各分区入库堆煤量。  
b. 用户可重新勾选实际堆煤分区，点击「重新计算」；按**卸煤总量**全局分配，计算规则与创建计划时维护堆煤方案一致。  
c. 权重取整、余数落末区；返回分配量、分配百分比、是否超容量；超限提示：**可能超出分区容量**（不阻断）。  
d. 用户可手调各分区实际卸煤量；前端校验累计总数与卸煤总量一致。  
e. **下一步**：总量与各分区明细累计须相等，否则提示：**入库明细明细与总量不一致！请确认！**

列表支持煤场 / 分区号筛选、「仅展示已选分区」（默认勾选）；煤场彩色标签区分。

##### 第 3 步：确认完结

进入前 / 完结时再次校验卸煤状态为「卸煤中断」，或「待卸煤且存在卸煤明细」；否则：**卸煤状态异常，请先中断卸煤！**

a. 展示卸煤关联入厂登记信息、卸煤总量。  
b. 展示分配完成的各分区入库煤量详细列表（只读）。  
c. **完结**：二次确认文案——请确认卸煤量明细无误，完结后，卸煤量将上传MIS行程入库记录！完结后状态 → 已卸煤，并更新分区存煤量（原型模拟）。

抽屉底部：取消 / 上一步 / 下一步 / 完结（仅第 3 步）。第 2 步外层高度固定，仅分区列表局部滚动。

#### 分区容量

- 每分区有容量上限配置；配置为空时默认 **5000t**
- 剩余容量 = 容量上限 − 当前存煤量（可为负，权重按 max(剩余, 0) 计算）

#### 自动分摊

**新增堆煤方案**（全局总量）：

> 建议计划堆煤量 = round(计划卸煤吨位 ×（分区权重基数 ÷ 权重基数合计）) 取整；余数加至最后一区

同时返回：分配百分比、堆煤后是否超容量（存煤量 + 计划堆煤量 > 容量上限）。超限时前端提示「可能超出分区容量」。

**完结分配**（全局总量，规则同新增堆煤方案）：

> 建议入库量 = floor(取整后的卸煤总量 ×（分区权重基数 ÷ 权重基数合计）)；余数加至最后一区

卸煤总量若带小数，先 `round` 为整数作为分配目标后再分摊；手调后合计须等于该目标整数。超限提示「可能超出分区容量」。

#### 完结校验与结果

- 各分区实际入库量合计 = 卸煤记录累计卸煤总量
- 完结后状态 → 已卸煤；更新分区存煤量；提示上传 MIS 行程入库记录（原型模拟）

### 2.2 操作说明

- **数据类型**：列表 + 新增主抽屉 + 入厂批次二级抽屉 + 堆煤方案编辑二级抽屉 + 完结主抽屉 + 卸煤记录二级抽屉
- **数据源**：页面内 mock（入厂批次列表、两个圆形煤场各 36 分区、默认容量 5000t）
- **关键操作**：
  - `新增`：打开新增右侧抽屉
  - `选择入厂批次`：二级抽屉单选回填入厂登记信息，计划卸煤吨位默认同步运单量
  - `创建方案` / `方案调整`：二级抽屉编辑堆煤方案，带入计划卸煤吨位
  - `分配卸煤量`：按剩余容量权重生成各分区计划堆煤量
  - `重置`：清空勾选与分配结果
  - `保存（堆煤方案）`：合计须等于计划堆煤量
  - `保存（新增）`：写入列表为待卸煤
  - `完结`：卸煤中断 / 待卸煤可点；三步：确认明细与总量 → 分区分配 → 确认完结

### 2.3 界面默认情况

- 列表默认展示若干示例计划，其中至少 1 条为「卸煤中断」且卸煤记录分别落到两个煤场
- 浅色风格，对齐项目默认主题 `antd-new`
