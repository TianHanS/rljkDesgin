# 数据监测

## 📋 功能说明

### 1.1 核心目标
> 简要说明该功能的核心定位、解决的问题、用户场景

集控调度员通过数据监测界面，查看各装卸端、小车等业务对象的实时监测数据，用于指导集控调度员对转运任务进行规划。界面通过数据块形式展示转运小车、装车端、卸车端等对象的关键监测数据，并提供小车的视频监控入口及控制功能。

### 1.2 使用角色
> 列出此功能模块使用的主要用户对象

- 集控调度员
- 系统管理员

## 📊 业务规则/约束

### 2.1 业务规则
> 按界面内容、模块逐个说明其中主要业务对象的业务规则、流程等内容

1. **转运小车**
   - 针对厂站下通常只有1个小车的情况，将转运小车监测的数据面板替换为车辆监控页面的横向数据看板。
   - **看板一：车辆信息**：展示小车编号、在线状态、任务状态、定位状态、当前档位（D/R/P/N）、运行速度、运行状态、操作模式、柜门状态及滚筒线状态。新增小车标题栏旁边的状态图标：通讯状态（在线/离线）、定位状态（有效/失效）、报警状态（报警闪烁/不显示）、辅助请求（请求闪烁/不显示），鼠标悬停在图标上应展示对应的文字提示标签。
   - **看板二：监控参数**：展示通讯状态、电池状态（电量、充电状态、续航里程、电压、电流、温度、总里程），以及实时的辅助请求和故障列表。
   - 此外，在转运小车数据面板的核心网格中，除流程状态与电池状态外，新增**当前档位**和**剩余续航里程**的直接展示。
   - **看板三：环视视角监控**：展示小车环视视角的实时视频流。
   - **看板四：后视视角监控**：展示小车后视视角的实时视频流。

2. **装车端（采样集样）**
   - 包含编号、名称、设备状态（就绪、运行、暂停、故障）、流程状态（车辆对接中、装车中、卸车中、设备复位中）。
   - 装车端包含三部分参数：空桶缓存线（容量、当前数）、集样器工位（工位数、空桶数、满桶数）、满桶缓存线（容量、当前数）。
   - 展现形式：去除进度条样式，采用纯数据看板的形式突出核心数字显示。

3. **卸车端（归批制样）**
   - 包含名称、编号、设备状态（就绪、运行、暂停、故障）、流程状态（车辆对接中、装车中、卸车中、设备复位中）。
   - 监测参数包含暂存空桶数。

### 2.2 操作说明
> 按用户在界面可操作的所有内容、按钮、列表、操作步骤等，同时附带各操作的前端后端校验规则

- **数据类型**：实时监测数据大屏
- **数据源**：前端 Mock 数据
- **关键字段**：
  - `小车监控`: 点击小车面板右上角的监控图标，打开视频监控模态框或跳转界面查看实时视频。
  - `小车控制`: 点击小车面板上的控制图标，弹出小车控制二级弹窗。
    - `小车充电`: 仅当小车状态为空闲（就绪）时，指定小车前往充电点进行充电。
    - `小车回库`: 指定小车返回仓库停放。
    - `开仓门/关舱门`: 异常时，人工进行小车仓门开关。
    - `调试操作`: 控制小车根据后台配置进行调试动作。

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- 默认以深色工业风为主，风格参考工作台界面的样式和内容。
- **连续网格布局**：考虑到实际业务中设备数量较少（一般1个小车、5-6个装车端、1个卸车端），为了最大化利用屏幕空间，移除原有的大区块横向分割线。
- 所有设备卡片（转运小车、装车端、卸车端）放置在同一个全局 Grid 网格中连续排列。
- **色彩与图标区分**：
  - **转运小车**：青色系（Cyan），使用 `Truck` 图标。
  - **装车端**：紫色系（Purple），使用 `UploadCloud` 图标。
  - **卸车端**：橙色系（Orange），使用 `DownloadCloud` 图标。
