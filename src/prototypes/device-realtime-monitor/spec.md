# 设备实时监测

## 📋 功能说明

### 1.1 核心目标
> 提供全厂设备的实时运行状态监控和历史参数曲线分析。支持通过设备树快速定位具体设备，查看分类的实时指标数据，并通过趋势图分析指标的历史变化。

该功能的核心定位是帮助运维人员和设备管理工程师实时掌握全厂设备的工作状况，通过数据和曲线对比，进行异常排查和健康度评估。

### 1.2 使用角色
> 主要针对系统运维人员、设备管理工程师等具有设备管理职责的角色。

- 运维人员：通过实时指标排查当前异常。
- 设备工程师：通过参数历史曲线进行设备的趋势分析和调优。

## 📊 业务规则/约束

### 2.1 业务规则
> 按界面内容、模块逐个说明其中主要业务对象的业务规则、流程等内容

- **设备树区域**：
  - 展示全厂范围内的设备，以树形结构呈现（如：国信沙洲电厂 -> 输煤程控 -> C31AB -> 具体设备）。
  - 点击左侧树的叶子节点，右侧面板会更新对应设备的实时和历史数据。
- **实时数据 Tab**：
  - 设备指标按列表形式展示。
  - 支持按指标名称进行模糊匹配搜索。
  - 支持按“参数分类”（例如温度、辐射、电气）和按“点位类型”（遥信、遥测）两种聚合方式展示，通过界面右上角的单选按钮进行切换。
  - 每个指标模块列表需显示：指标名称、分类、点位类型、当前读数（带单位，遥信显示状态）。
  - 实时更新：前端通过 WebSocket（或模拟的定时轮询）获取最新数据刷新读数。
- **参数曲线 Tab**：
  - 展示设备各指标的历史数据趋势。
  - 默认时间范围：近 2 小时。
  - 默认数据步长：5 秒。
  - 增加“查询”按钮。修改时间范围或步长后，需点击“查询”按钮才会重载数据。
  - 增加“图表/列表”视图切换操作：
    - 图表视图：按指标的“分类”分组显示多张折线图（例如温度类一张图，压力类一张图）。如果指标无分类，则统一归入“未分类”。
    - 列表视图：按分类显示包含时间、及各指标数值的表格数据，供详细数据查阅。
  - 增加“自定义分析”子 Tab，提供给用户通过下拉多选组件自由组合多个指标进行曲线或者列表维度的对比分析。
  - 增加从“实时数据”中点击指标对应的“查看监测曲线”快捷操作。点击后会自动切换至参数曲线的“自定义分析” Tab，并自动预选对应指标。
  - 曲线功能：支持时间范围的选择，数据步长的调整（1s、5s、10s、30s、60s、120s）。
  - 用户可以通过图例点击控制单个指标曲线的隐藏与显示，通过滚轮/内置工具进行曲线图缩放查看。

### 2.2 操作说明
> 按用户在界面可操作的所有内容、按钮、列表、操作步骤等，同时附带各操作的前端后端校验规则

- **数据类型**：设备监控看版
- **数据源**：前端模拟生成（包含设备树结构、指标列表、实时数据及历史曲线数据）。
- **关键字段**：
  - `点击设备树节点`: 切换设备上下文，清除旧数据，发起新设备的实时和历史数据请求。
  - `切换 Tab`: 在“实时数据”和“参数曲线”间平滑切换，避免图表销毁带来的卡顿。
  - `更改时间范围`: 结合 `DatePicker.RangePicker` 选择起始与结束时间，结束时间不可晚于当前时间，触发数据重载。
  - `更改数据步长`: 选择 Select 中的步长（1s~120s），重载并聚合对应颗粒度的历史曲线。
  - `图表交互`: ECharts 组件内置的 `dataZoom` 进行缩放，`legend` 点击切换显示/隐藏。

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- 左侧设备树默认展开前两级结构。
- 默认选中树中能找到的第一个具体的“设备节点”（叶子节点）。
- 右侧默认选中展示“实时数据”Tab。
- “参数曲线”下的筛选条件默认值：时间范围[当前时间-2小时, 当前时间]，步长 `5s`。
