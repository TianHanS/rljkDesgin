# 调度任务管理

## 📋 功能说明

### 1.1 核心目标
提供给集控调度员用于查询、管理小车调度任务的页面。通过该页面，调度员可以查看任务状态，并执行任务的创建、执行、暂停、恢复、终止和删除操作，支持按条件检索任务，以确保小车运输流程的高效运转。

### 1.2 使用角色
- **集控调度员**：日常监控调度任务、创建新任务干预自动流程、处理异常任务。

## 📊 业务规则/约束

### 2.1 业务规则
- **任务结构**：调度任务分为主数据和子任务（任务明细），界面上以树形列表展示。
- **排序规则**：列表默认按“任务实际开始执行时间”逆序排序；未执行的任务排在最前，并按“创建时间”逆序排序。
- **任务编号**：需要与无人调度小车保持一致，作为后续所有交互（查询、控制）的唯一标识。
- **明细规则**：
  - “车辆调度”类型：仅“装卸端/停靠点”可编辑，无操作类型和空桶数量。
  - “样桶装卸”类型：可选择“操作类型”。若停靠点为“装样端”，则“配送空桶数量”可编辑（根据装样端空桶需求自动填充，正整数）。

### 2.2 操作说明

- **数据类型**：树形列表与表单配置
- **数据源**：前端 Mock 数据
- **关键字段与操作**：
  - `顶部查询`：包含计划时间(时间范围)、实际执行时间(时间范围)、确认人(输入)、确认方式(下拉: 全部/人工/定时)、任务状态(下拉: 全部/未开始/执行中暂停/终止/已完成)。
  - `新建任务`：
    - 主数据增加：任务名称（非必填）。
    - 触发方式：人工确认(默认)/定时自动开始。若为定时，则计划时间必填。
    - 任务明细表：支持行内编辑。在任务列表上方提供“按模板新建”按钮，鼠标移入提示“获取任务模板”。
    - 点击“按模板新建”弹出模板选择列表，展示模板名称与说明。点击模板即关闭选择弹窗，按模板加载任务明细信息。
    - 其中默认模板选项为系统内置，点击后加载模板数据（模拟向后端请求，根据装车端空桶需求数量排定优先级并自动计算填充），数据包含8步（前往卸车端/归批制样、样桶装卸归批制样装空桶、前往装车端、装车端卸空桶装满桶、前往另一个装车端、装车端卸空桶装满桶、前往卸车端/归批制样、卸满桶）。用户可在此基础上修改、删除。重复点击按模板数据覆盖已编辑的数据。
  - `任务模板维护`：
    - 在任务管理页面提供入口按钮，点击展示任务模板列表。
    - 模板列表字段包括：模板名称、创建时间、创建人、更新时间、更新人、操作（如删除）。
    - 列表支持新增操作，点击“新增”弹出新增模板弹窗。
    - 模板新增/编辑弹窗包含：模板名称输入框、与新建任务一致的“任务明细编辑”表格。
  - `执行`：针对未执行任务，点击执行时：
    - 后端判断当前是否具备执行条件及任务是否允许执行。
    - 若允许且具备条件：前端弹出二次确认框“是否确认执行任务？”。
    - 若后端返回不具备条件：前端弹出带有具体异常信息的确认框（例如：“系统异常：小车电量低于阈值20%，当前电量15%。是否确认强制执行任务？”）。用户仍可操作强制确认执行。
  - `暂停`：针对“执行中”任务，选中后点击暂停弹出二次确认框：
    - 若当前任务为**装卸任务**：完成当前正在执行的装卸子任务后，不再继续执行后续子任务，主任务状态更新为“暂停”，前端直接提示暂停成功。
    - 若当前任务为**调度任务**：向设备下发暂停控制指令，根据接口响应结果提示。若成功则状态更新为暂停；若失败则返回异常提示（如“设备响应异常”），用户可重复进行暂停操作。
  - `恢复`：针对“暂停”或异常中断任务继续恢复执行。点击恢复时：
    - 弹出二级弹窗加载，后端判断当前是否具备恢复条件及任务是否允许执行。
    - 若允许且具备条件：前端弹出二次确认框“是否确认恢复执行任务？”。
    - 若后端返回不具备条件：前端弹出带有具体异常信息的确认框（例如：“系统异常：小车电量低于阈值20%，当前电量15%。是否确认强制恢复执行任务？”）。
    - 当系统判定不具备条件时，用户仍可操作红色的强制确认恢复按钮。
  - `终止`：针对“执行中”任务，选中后可进行终止。弹出二次确认框：“确认终止结束任务？”：
    - 若当前任务为**调度任务**：向设备下发任务终止指令，待小车系统返回成功后，控制车辆靠边停车。
    - 若当前任务为**装卸任务**：待当前装卸子任务完成后，方可自动终止后续动作。
    - 无论哪种类型，终止成功后均更新其未执行的子任务及主任务为“终止”状态。
  - `删除`：针对“未开始”任务，二次确认后删除该任务。

### 2.3 界面默认情况
- **布局**：与工作台保持一致的暗黑科技风（#0b1120、#0f172a 背景，青色主题色）。
- **列表加载**：默认展示所有任务并分页，展开图标默认折叠，部分数据带状态标签（如执行中、已完成、未开始）。

## 🎨 视觉与交互规范

- 遵循已有 `dispatch-workbench` 主题风格，使用 Tailwind CSS 构建。
- 表格固定表头和操作列。
- 深色背景下的 Modal 必须具有良好的对比度和边框效果。
- 所有二次确认采用弹窗或气泡确认提示。
