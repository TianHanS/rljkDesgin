# 司机自助入厂登记

## 📋 功能说明

### 1.1 核心目标
> 简要说明该功能的核心定位、解决的问题、用户场景

面向厂区入厂点自助终端，提供司机从登录、扫码登记到磅单查询的一体化操作流程，减少人工登记压力并提升通行效率。界面采用浅色、清晰、大触控操作设计，适配现场大屏/触摸终端使用场景。

### 1.2 使用角色
> 列出此功能模块使用的主要用户对象

- 运输司机：扫码登记、查询近期磅单
- 门岗/入厂点值守人员：协助异常处理（黑名单、扫码失败、登记失败）

## 📊 业务规则/约束

### 2.1 业务规则
> 按界面内容、模块逐个说明其中主要业务对象的业务规则、流程等内容

1. **登录与会话**
   - 司机输入 4A 账号和密码登录，前端模拟获取 `token`。
   - 登录后会话持续保持，除非用户手动点击退出，不触发自动登录超时。
   - 用户点击退出时，弹出密码验证确认框，仅允许管理员账号或当前登录用户的密码通过后才允许退出系统。

2. **首页**
   - 展示欢迎标语（大唐郓城电厂）、厂站名称、当前时间（秒级刷新）。
   - 提供两项主功能入口：`云驿APP入厂登记`、`磅单查询`。

3. **入厂登记流程**
   - 进入页面后展示“请扫描云驿 APP 运单二维码”及“请将二维码对准扫码窗口”提示（附带外接音响语音播报提示），并启动 `120s` 倒计时。
   - 支持扫码枪键盘流输入：前端实时监听按键，按 Enter 判定一条扫码输入结束。
   - 扫码后流程：
     1) 二维码解密（模拟 Base64 解码）  
     2) 解包运单字段并按煤车/非煤车显示差异化标签  
     3) 大字号展示字段：车牌号、矿发净重/毛重/皮重，以及差异化字段：
        - 煤车：供应商、矿点、运输单位、煤种
        - 非煤车：物资类型、任务单号、发货时间、司机及电话
     4) 大尺寸显示“正在进行登记”加载态（不遮挡信息）  
     5) 登记成功后大尺寸提示成功（附带成功语音提示），保留解析信息，启动 `20s` 自动返回首页倒计时
   - 页面始终提供“返回首页”操作。

4. **磅单查询流程**
   - 进入后展示最新车辆磅单卡片，默认每页 `6` 条。
   - 增加**车牌号模糊查询**功能：在顶部提供输入框，可输入车牌号快速筛选对应的电子磅单。
   - 增加**手动刷新**机制：页面顶部提示“若您刚完成回皮计量，未找到对应磅单请手动刷新”，并提供显眼的「手动刷新」操作按钮。
   - 布局：`2 行 × 3 列` 卡片网格（触屏可点选）。
   - 卡片字段：车牌号、物资类型、入厂时间、毛重、皮重、净重、二维码（直接在外层 6 块卡片中展示二维码区域以供直接扫描）。
   - 点击卡片可放大查看，再次点击恢复列表状态。
   - 提供大尺寸上一页/下一页按钮，统一居于屏幕一侧，并在按钮旁**增加当前分页计数展示（如：第 1 / 4 页）**，便于触屏操作。
   - 显著加大“运煤车/物资车”分类标签与二维码（附带点击放大提示）在列表卡片中的展现。
   - 增加在列表卡片中展示更多的车辆物资信息：运煤车显示矿点、煤种、供应商；物资车显示物资类型。
   - 页面 `60s` 无操作自动返回首页，同时提供返回操作。

### 2.2 操作说明
> 按用户在界面可操作的所有内容、按钮、列表、操作步骤等，同时附带各操作的前端后端校验规则

- **数据类型**：登录表单、登记单据、磅单列表卡片。
- **数据源**：用户需求 + 前端 Mock 数据（模拟扫码输入、登记结果、磅单分页）。
- **关键字段**：
  - `登录`: 4A 账号、密码必填；提交后生成 token 并进入首页。
  - `扫码登记`: 监听扫码输入结束符 Enter，支持“模拟扫码”按钮便于演示。
  - `登记提交`: 解密失败时提示错误并保持在当前页；成功后进入“成功待返回”状态。
  - `磅单卡片放大`: 点击卡片切换放大/缩小，放大态展示完整字段和二维码。
  - `分页`: 上一页/下一页按钮带禁用状态，避免越界翻页。
  - `自动返回`: 入厂登记页 120s、登记成功后 20s、磅单查询页 60s 无操作倒计时。

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- **整体视觉**（参照用户提供的设计截图）：浅蓝渐变背景 + 柔和光带装饰，内容承载于白色圆角卡片；顶部右侧常驻“日期时间 + 星期”信息，登录后追加“退出”操作。
- **默认入口**：首次进入为登录页；登录页采用左对齐大标题“欢迎使用出入厂自助登记系统”+ 厂站名 + 下划线式输入框风格；登录成功进入首页。
- **首页默认展示**：大标题欢迎语、厂站名称、两个大尺寸卡片式主操作按钮（入厂登记/磅单查询）。
- **入厂登记默认展示**：左右双栏布局——左侧白色卡片“入厂自助登记”展示车牌号码与计划信息表单（蓝点分组标题、标签+下划线值，运煤车登记成功后追加“入厂引导”分组）；右侧白色卡片“计划信息获取”展示扫码提示/登记中/登记成功状态与“返回”按钮；页面顶部右侧显示自动返回倒计时。
- **磅单查询默认展示**：最新 6 车卡片、车牌搜索框、手动刷新提示条、分页按钮与分页计数、无操作计时提示。
