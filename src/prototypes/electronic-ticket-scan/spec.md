# 电子磅单司机扫描

## 📋 功能说明

### 1.1 核心目标
> 简要说明该功能的核心定位、解决的问题、用户场景

该功能旨在为轻衡或电厂出厂点的司机提供一个常开的电子磅单扫描界面。司机完成车辆扫描或过轻后，此界面会自动获取并展示车辆的最新计量信息，并生成大尺寸的磅单二维码供司机使用手机扫描，以获取完整的车辆磅单信息。此外，界面支持按具体位置（轻衡、出厂点）进行配置过滤，并展示近期的车辆出厂记录。

### 1.2 使用角色
> 列出此功能模块使用的主要用户对象

- 运输司机（主要浏览者、二维码扫描者）
- 厂区现场管理人员/司磅员（系统配置者）

## 📊 业务规则/约束

### 2.1 业务规则
> 按界面内容、模块逐个说明其中主要业务对象的业务规则、流程等内容

1. **磅单位置配置**
   - 界面顶部提供位置切换功能。
   - **汽车轻衡**：下拉单选（全部、轻衡1、轻衡2等），默认为空，可不选。
   - **出厂点**：下拉单选（全部、出厂点A、出厂点B等），默认为空，可不选。
   - 配置结果通过“保存”按钮生效，前端保存过滤条件并提示保存结果。

2. **最新车辆计量信息展示**
   - 展示过滤位置下的最新一条磅单信息。
   - 包含：数据更新时间、流水号、车号、入厂时间、煤种、矿点、毛重、皮重、净重（单独高亮）、扣研、扣杂、扣水、发货单位。
   - 旁边展示与之对应的大尺寸二维码，更新时间需与计量信息一致。

3. **车辆出厂记录列表**
   - 位于信息展示下方，记录近期出厂的车辆明细。
   - 字段：序号、流水号、车牌号、供应商矿点、煤种、入厂时间、毛重(t)、皮重(t)、净重(t)、扣吨(t)（扣研+扣杂+扣水总和）、过衡位、在厂状态。
   - 排序：按入厂时间逆序（最新的在前）。

### 2.2 操作说明
> 按用户在界面可操作的所有内容、按钮、列表、操作步骤等，同时附带各操作的前端后端校验规则

- **数据类型**：单据展示、配置面板、列表记录。
- **数据源**：前端 Mock 数据（模拟后端推送的标记和自动更新）。
- **关键字段**：
  - `保存配置`: 校验配置项，将所选“轻衡”和“出厂点”保存为当前过滤条件，弹出成功/失败的 Toast 提示。
  - `查看磅单`: 列表操作列按钮。点击后，弹出模态框（Modal），内容结构同主界面的“车辆计量信息+大尺寸二维码”，供司机回顾历史磅单或补扫二维码。

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- **视觉风格**：浅色系管理后台风格，常开界面设计（对比度高，字号适中偏大以便现场查看）。
- **初始化**：顶部配置区默认为空，下方展示所有位置的最新车辆磅单信息和大尺寸二维码，列表展示所有出厂记录。
- **布局**：
  - 顶部：位置配置栏（背景白色，内嵌表单项）。
  - 中部：分左右两块，左侧为“车辆计量信息”卡片，右侧为“二维码”展示卡片。
  - 底部：“车辆出厂记录”数据表格。
