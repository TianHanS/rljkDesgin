# 全程能耗分析

## 📋 功能说明

### 1.1 核心目标

分析燃煤在运输过程及厂内流转中的**热值损耗**（途损 / 堆损），并结合机组发电与入炉煤质测算**发电煤耗**；统计各班组输煤系统电耗与堆/上煤煤量，计算**输煤单耗**并开展班组效能评比；对历史能耗进行趋势分析与短期预测。

### 1.2 使用角色

- **燃料管理人员**：关注热值损耗告警、发电煤耗与班组效能
- **输煤运行班组**：查看本班输煤单耗与排名
- **值长 / 专工**：查阅历史趋势与预测，辅助调度决策

## 📊 业务规则/约束

### 2.1 业务规则

1. **热值损耗**
   - 途损 = 船运单热值 − 入厂热值（kcal/kg）
   - 堆损 = 入厂热值 − 入炉热值（kcal/kg）
   - 考虑化验误差波动：偏差在容差带（原型默认 ±40 kcal/kg）内视为正常波动；超出阈值告警
   - 途损告警阈值默认 80 kcal/kg；堆损告警阈值默认 60 kcal/kg
2. **发电煤耗（正平衡法）**
   - 标煤量(t) = 入炉煤量(t) × 入炉热值(kcal/kg) / 7000
   - 发电煤耗(g/kWh) = 标煤量(t) × 10⁶ / 发电量(kWh)
   - 按机组实时 / 日汇总展示
3. **班组输煤单耗**
   - 输煤单耗(kWh/t) = 班次输煤设备耗电量(kWh) / 班次（堆煤量 + 上煤量）(t)
   - 按班组排名评比；可按月份筛选
4. **趋势与预测**
   - 展示近 12 个月发电煤耗、输煤单耗历史曲线
   - 预测段为原型模拟（简单外推），与历史数据分段区分展示
5. **告警**：热值损耗超阈在告警列表展示，可打开明细抽屉查看船次 / 批次煤质链路

### 2.2 操作说明

- **数据类型**：分析看板（KPI + 表格 + 图表 + 告警抽屉）
- **数据源**：页面内 mock
- **关键操作**：
  - `查询`：按统计月份刷新口径提示
  - `告警明细`：打开只读抽屉查看热值链路
  - `切换图表指标`：发电煤耗 / 输煤单耗
