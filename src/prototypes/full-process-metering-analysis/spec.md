# 全程计量分析

## 📋 功能说明

### 1.1 核心目标

汇聚水尺计量、入厂/入炉称重、固定式盘煤、煤仓煤量等数据，对船运 → 煤场 → 入炉全流程煤量进行汇总、比对与校核，保持各节点量平衡；对问题频次较高的计量节点与业务对象提出报警与运维提醒。

### 1.2 使用角色

- **燃料管理人员**：查看全程平衡、问题船号/发货方趋势，辅助月盘点对账
- **运行维护人员**：关注报警计量点/设备，及时校准；执行煤堆清零

## 📊 业务规则/约束

### 2.1 业务规则

1. **节点汇总**：水尺计量、入厂煤量、入炉煤量、煤场存煤量、煤仓存煤量。
2. **原始计量来源**：水尺数据、入厂入炉称重系统、盘煤系统（煤仓来自智能配煤掺烧）。
3. **三段平衡**：
   - 船运节点：水尺 ↔ 入厂称重
   - 煤场节点：入厂 − 入炉 ↔ 盘煤存煤变化
   - 入炉节点：入炉称重 ↔ 煤仓耗用/结存
4. **平衡判定**：差值绝对值 ≤ 阈值（原型默认 0.5%）为平衡；超过则告警。
5. **节点报警**：问题较多的计量节点在报警区展示，支持按严重程度筛选。
6. **煤堆清零**：取煤后支持手工清零或自动清零；清零后该堆存量记为 0 并留痕（原型模拟）。
7. **数据挖掘**：
   - 统计计量问题频次较高的船号、发货方、前港（发港）；无航线信息时标「—」
   - 统计问题频次较高的计量点与设备，提醒校准
8. **月盘点平衡**：各煤种全程计量汇总应与当月定期盘点数据保持平衡，差异超阈提示。

### 2.2 操作说明

- **数据类型**：分析看板（汇总卡片 + 流程图 + 表格 + 操作）
- **数据源**：页面内 mock
- **关键操作**：
  - `查询`：按统计月份刷新看板 mock 数据口径说明
  - `手工清零`：对指定煤堆确认后清零
  - `自动清零开关`：模拟取煤后自动清零规则启停
  - `查看明细`（报警行）：打开侧抽屉展示近期差值记录（只读）

### 2.3 界面默认情况

- 主题：项目默认 `antd-new` 浅色中后台
- 默认统计月份为当前月示例（2026-08）
- 页面自上而下：筛选 → 五节点汇总 → 三段平衡 → 报警 → 煤堆清零 → 问题挖掘 → 月盘点平衡
