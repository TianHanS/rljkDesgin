# 日志查询

## 📋 功能说明

### 1.1 核心目标
提供统一的过程日志查询界面，方便调度和运维人员快速定位和追踪转运任务或车辆运行过程中的日志数据。该界面作为二级菜单功能呈现，保持与工作台一致的导航和深色主题风格。

### 1.2 使用角色
- **调度员/操作员**：追踪任务执行状态，查询任务流转日志。
- **运维/工程师**：排查车辆异常、报警及运行日志。

## 📊 业务规则/约束

### 2.1 业务规则
- **顶部菜单与导航**：与工作台界面一致，包含一级菜单（主界面、采样机等）和二级菜单（工作台、任务管理、日志查询等），当前二级菜单高亮选中“日志查询”。
- **查询模式切换**：支持“按小车查询”与“按任务查询”两种模式的自由切换。
- **按小车查询**：
  - 小车下拉列表选项自动加载可用车辆（如 01无人车, 02有人车 等）。
  - 默认选中第一辆小车。
  - 日志时间范围查询条件默认为空。
  - 日志列表数据必须按时间逆序（最新的在前）展示。
- **按任务查询**：
  - 查询条件包括：任务编号（输入框）和任务开始时间范围。
  - 列表数据为任务列表，默认按“实际开始时间”逆序排序。
  - 支持任务的“点击查看”操作。
  - “查看”详情内容：需包含任务的基本信息，并以时间轴（Timeline）形式展示该任务关联的所有日志，时间轴按时间逆序排列。

### 2.2 操作说明
- **数据类型**：日志与任务查询列表。
- **数据源**：前端本地 Mock 数据兜底。
- **关键字段与操作**：
  - `切换模式`：通过单选按钮（Radio Group）或选项卡（Tabs）在“小车”与“任务”间切换，切换后重置对应的查询表单并刷新列表。
  - `查询（小车模式）`：基于选中“小车”与“时间范围”过滤日志。
  - `查询（任务模式）`：基于“任务编号”与“开始时间范围”过滤任务列表。
  - `查看（任务模式操作列）`：打开抽屉（Drawer）或弹窗（Modal），加载该任务详情和日志时间轴。

### 2.3 界面默认情况
- 页面加载后，默认显示“按小车查询”模式。
- 小车下拉框默认选中第一个可用小车，并自动加载其历史日志列表（时间逆序）。
- 顶部导航的二级菜单默认选中“日志查询”。

## 🧩 内容结构与字段字典

### 3.1 页面结构划分
1. **顶部导航栏（Header）**：全局一级导航、用户信息、时间。
2. **二级菜单栏（SubMenu）**：模块内导航。
3. **主内容区（Main）**：
   - **模式切换区**：小车 / 任务 切换控件。
   - **搜索过滤区（Filter）**：对应当前模式的搜索表单。
   - **数据展示区（Table）**：表格数据展示，包含分页。
4. **详情弹层（Drawer/Modal）**：仅“任务查询”模式下的查看详情界面。

### 3.2 字段字典
**按小车查询列表**
- `日志时间`（Datetime）：日志生成时间，如 2023-10-24 10:05:32
- `类型`（Enum）：正常（绿色/蓝色）、异常（橙色/黄色）、报警（红色）
- `日志内容`（String）：具体的日志文本描述

**按任务查询列表**
- `任务编号`（String）：任务唯一标识，如 T-20231024-001
- `任务类型`（String）：如 车辆调度、样桶装卸
- `计划时间`（Datetime）：任务计划开始时间
- `实际开始时间`（Datetime）：任务实际启动时间
- `状态`（Enum）：执行中、已完成、异常、未执行
- `操作`（Action）：[查看]

**任务详情抽屉（Drawer）**
- 布局结构：抽屉加宽，采用左右布局。
- 左侧（任务信息）：包含任务主信息（任务名称、类型、触发方式、关联车辆、计划时间、耗时、确认人等）以及任务明细子任务列表（序号、任务类型、装卸端/停靠点、操作类型、空桶数量、行驶距离/耗时）。
- 右侧（日志时间轴）：包含时间点、类型（不同颜色图标标记）、日志内容描述（逆序排列）。

## 🎨 视觉与交互规范

### 4.1 视觉风格
- **整体主题**：与 `dispatch-workbench` 保持完全一致的深色科技风（背景色 `#0b1120`, `#0f172a` 等，主色调青色 `cyan-400`）。
- **组件样式**：
  - **表格（Table）**：深色背景，暗色边框，hover时行背景微亮，文字色以 `gray-300` 为主。
  - **标签（Badge）**：类型标签需具有高对比度颜色（正常: 绿/青, 异常: 黄, 报警: 红）。
  - **时间轴（Timeline）**：左侧时间线，节点带有对应日志类型的颜色状态点。
  - **弹窗/抽屉**：半透明毛玻璃效果，深色底色，高亮边框。

### 4.2 交互行为
- 列表分页和查询应当为平滑刷新（无需全局Loading阻塞）。
- 抽屉从右侧滑出，带遮罩层，点击遮罩层可关闭。
- 保证表格在不同分辨率下的横向滚动与列宽适配。
- “按小车查询”的时间范围若未选择，则查出该小车的所有历史日志。
