# 智慧燃料集控中心 - 工作台 (Main Dashboard)

## 📋 功能说明

### 1.1 核心目标
通过集控监测主界面展示智慧燃料入厂全流程（燃煤线、原煤样转运线、煤样线），并展示各个环节主要设备的运行实时状态与监测参数。本版本为**重构后的浅色干净企业风格**，剔除过于花哨的科幻大屏视觉，以扁平化、高可用、数据清晰的线框图UI为基准进行设计，供集控调度员进行全局监控。

### 1.2 使用角色
集控调度员

## 📊 业务规则/约束

### 2.1 页面核心模块与数据展示

#### 1. 顶部导航与用户信息
- **Logo区域**：左侧展示“智慧燃料集控中心”及副标题“大唐雷州发耳电厂”。
- **导航菜单**：包含“工作台”（当前激活）、“设备监控”、“数据查询”、“视频门禁”、“卸煤管控”、“报警”。
- **用户信息**：右侧展示当前用户（如刘焱）及当前时间（如 17:00:00 2026/01/28 星期三）。

#### 2. 作业模块 (核心指标统计)
- 顶部横向展示各大模块的统计数据，以圆形图表为主。
- 左侧汇总：“模块总数” (12个)，“控制接入” (5个)，“监测接入” (7个)。
- 右侧分别列出 5 大模块：
  1. **机械采样** (12个)
  2. **皮带采样** (12个)
  3. **制样模块** (12个)
  4. **化验模块** (12个)
  5. **存样模块** (12个)
- 每个模块下方附带状态统计：“紧急 0 | 严重 1 | 普通 10”。

#### 3. 运行情况与报警 (左侧栏)
- **运行情况 (饼图)**：环形图展示“正常 (25台)”、“通讯异常 (5台)”、“报警 (0台)”。中心或侧边展示“今日已恢复报警 892 条”。
- **实时报警列表**：展示最新的严重、普通、控制流程报警。每条包含：等级标签（严重/普通/控制流程）、设备名称（如1#汽车采样机）、状态摘要（采样急停）、时间（14:26:58）。底部有“更多详情”按钮。

#### 4. 设备流程与监控卡片 (中右区域)
- **过滤与操作栏**：包含分类 Tabs（全部、出入厂、采样、计量、制样化验），状态图例（正常 25、通讯异常 5、报警 0），搜索框，以及视图切换图标。
- **设备卡片**：网格布局展示各节点设备状态。
  - **样式**：白底圆角卡片，左侧有代表状态的彩色圆圈（如绿色正常，黄色异常），右侧有角标（如“远程控制”、“远程监测”）。
  - **内容**：主标题（如 1#汽车采样机），当前作业信息（如 在采车辆 湘A98992），流程状态（如 全自动采样运行中）。
  - **涵盖节点**：汽车机械采样机、南门自动入厂、南门人工登记、入炉皮采、船运皮采、火车皮采、合样归批、自动制样、无人化验、存样柜、其他设备。

#### 5. 底部趋势与作业量统计
- **报警故障趋势**：柱状图展示报警数量趋势，包含时间维度切换（今日、本周、本月）。
- **模块作业量统计**：横向节点流程式统计，包含“汽车入厂(230车) -> 计量(520车) -> 采样(128车) -> 制样(2批) -> 化验(2批)”。同样支持时间维度切换（今日、本周、本月）。

## 🎨 视觉规范与页面结构

### 3.1 视觉风格 (线框图/扁平风重构)
- **背景色**：全局采用浅灰色/白色背景 (`#F5F7FA` 或 `#FFFFFF`)，剔除原有的深蓝渐变和发光特效。
- **卡片/面板**：纯白底色 (`#FFFFFF`)，带极淡的灰色边框或极微弱的阴影，确保界面干净清爽。
- **字体颜色**：
  - 主标题/正文：深灰色 (`#333333` 或 `#1A1A1A`)，强调对比度。
  - 次要文本：浅灰色 (`#666666` 或 `#999999`)。
- **状态色彩**：
  - 正常：扁平化绿色 (`#52C41A`)。
  - 通讯异常/警告：扁平化橙黄色 (`#FAAD14`)。
  - 报警/严重：扁平化红色 (`#F5222D`)。
  - 标签/Badge：采用浅色背景+深色文字的扁平样式，如浅绿底深绿字、浅橙底深橙字等。
- **图表**：去除高光和渐变，使用纯色扁平化填充，与整体亮色主题保持一致。

### 3.2 布局规划
- **顶部 Header**：横向贯穿，白色背景，包含 Logo、主导航和右侧用户信息。
- **主体内容区**：
  - **Top Row**：全宽的“作业模块”统计面板。
  - **Middle Row**：分为左右两列。
    - 左侧 (`w-1/4` 或 `w-1/3`)：运行情况饼图 + 报警列表。
    - 右侧 (`w-3/4` 或 `w-2/3`)：设备监控卡片网格，顶部带过滤 Tabs。
  - **Bottom Row**：平分为左右两块。
    - 左侧：报警故障趋势柱状图。
    - 右侧：模块作业量统计流向图。
