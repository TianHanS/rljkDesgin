# 燃煤入厂登记

> 本原型为**新增**页面，面向门岗/入厂点值班员的浅色后台管理界面。不改动已有的司机自助入厂登记。本页**只做燃煤入厂登记**，不含煤样卡与转场煤。

## 📋 功能说明

### 1.1 核心目标

值班员在**一屏固定布局**内完成燃煤入厂登记：表单与登记列表同时可见，页面本身不纵向滚动（仅列表内部滚动）。

1. **来煤信息获取**：按入厂点配置选择计划、扫计划码、按车牌匹配或读矿发卡，也可扫云驿二维码。
2. **矿发信息获取**：预入厂、矿发卡、送货单回填或云驿码回填毛/皮/净。
3. **入厂信息与登记**：采样方式、采样位、过衡位、卸煤区域、**允许入厂（只读）**；确认登记后联动道闸 / LED / 广播。
4. **人工允许入厂**：车辆云驿同步状态为「禁止入厂」时，在底部办理人工放行后再登记。

**明确不做**：煤样卡查询、补发煤样卡、确认登记并发煤样卡、来煤/转场煤模式切换；**不展示**车辆卡号、入厂卡字段。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 入厂点值班员 | 办理燃煤入厂登记、允许预入厂车辆 |
| 门岗班长 | 切换入厂点、核对禁止入厂车辆、查看登记列表 |
| 燃料集控 | 抽查登记记录 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 入厂点与配置

页头下拉切换入厂点，配置随点位变化并即时改写按钮与必填：

| 配置项 | 含义 | 南门 | 北门 | 东门 | 西门 |
|--------|------|------|------|------|------|
| `GET_PLAN_MSG` | 来煤计划：1 选择计划 / 2 扫计划码 / 3 按车牌 / 4 读矿发卡 | 1 | 3 | 4 | 2 |
| `GET_ORIGINAL_MSG` | 矿发信息：1 预入厂 / 2 矿发卡 / 3 送货单回填 / 4 云驿码 | 3 | 1 | 2 | 4 |
| `SAMPLE_MEASURE_EDIT` | 采样/过衡位：0 非必填，1 必填 | 1 | 0 | 1 | 1 |

页头标题固定为 **燃煤入厂登记**，不提供来煤/转场分段切换。

#### B. 车牌号码（可编辑 + 联想）

- **车牌号码为唯一可编辑字段**（AutoComplete 输入框，底部分割线样式与表单一致）。
- 输入 **≥ 3 位** 时，按前缀/包含关系自动联想候选车牌（计划 + 预入厂车辆库）。
- 选中联想项后，自动加载关联计划与矿发信息（同选择计划/预入厂逻辑）。
- 其余来煤/矿发/入厂字段仍为只读下划线展示。

#### C. 来煤信息获取

- **登记区除车牌外全部只读**：以标签 + 下划线展示，通过选择计划 / 扫码 / 读卡 / 车牌联想回填。
- **选择计划**：弹窗单选计划，回显供应商、矿点、煤种、运输单位、卸煤区域、品名、发站及发站时间、车牌，并带回毛皮净与默认采样位/过衡位。
- **扫描计划二维码**：按钮进入加载，读取扫码枪内容（计划 ID），查询计划后回填。
- **按车牌匹配计划**：北门等配置下，输入/选择车牌后，再用「获取预入厂信息」取计划。
- **读矿发卡**：解析 `车牌OreadWriteOaObO车牌O计划idO毛重O皮重O`。回填计划；毛皮按矿发配置写入。
- **扫描云驿二维码**：
  1. 点击按钮 → 短暂 loading → 弹出**请扫码动画**模态（扫描框 + 扫描线动效 + 隐藏扫码枪输入）。
  2. 识别成功 → 成功态 → 自动关闭并回填车辆与矿发信息。
  3. 格式：`计划流水号|运输任务单号|车牌号码|发货时间|矿发毛重|矿发皮重|矿发净重|计划ID|当前时间|发站时间`；当前时间与系统时间相差超过 15 分钟 →「二维码失效，请刷新！」
  4. 原型提供「模拟扫码成功」按钮便于演示。

#### D. 矿发信息

- 毛/皮/净只读展示；须 **< 200**；确认登记时净重必填。
- **不展示**「车辆卡号」字段。
- `GET_ORIGINAL_MSG = 1`：按车牌取预入厂毛皮净。
- `= 2`：矿发卡读取后比对**表单车牌**与**卡内车牌**，不一致弹出确认。
- `= 3`：字段只读，选择计划时带回计划毛皮净。
- `= 4`：用云驿码中的毛/皮/净填充。

#### E. 入厂信息与允许入厂状态

- 采样方式、采样位、过衡位、卸煤区域为只读下划线展示。
- **不展示**「入厂卡」字段。
- 新增只读字段 **允许入厂**：
  - 值：**是**（绿色 Tag）/ **否**（红色 Tag）；无车牌时显示「—」。
  - 字段后 **问号图标**，鼠标移入 Tooltip 说明：车辆是否允许入厂由云驿平台在到厂前自动同步；禁止入厂可能因封签核验、在途风险或网络未同步等原因。
- 选择计划/扫码/车牌联想回填时写入默认采样方式「机械采样」、默认采样位/过衡位。
- 采样/过衡位在 `SAMPLE_MEASURE_EDIT = 1` 时登记前必有值。

#### F. 人工允许入厂

部分车辆已预入厂，云驿同步状态仍为 **禁止入厂**，不能直接确认登记。

1. 底部操作区顺序：**确认登记** → **允许入厂** → **清空**。
2. **允许入厂**按钮：仅当当前车牌对应状态为 **禁止入厂** 时可点击；允许入厂或未匹配预入厂记录时禁用。
3. 点击后打开抽屉 **允许车辆入厂登记**：
   - 只读：车牌号码、供应商、矿发毛重、矿发皮重、矿发净重、允许入厂状态（红/绿 Tag）。
   - 可编辑：**原因**（多行文本，必填）。
   - 底部快捷输入：「网络异常未自动同步允许入厂状态」「核验后无误人工手动放行」。
   - 确认后更新为允许入厂，关闭抽屉，表单内「允许入厂」变为「是」。
4. 确认登记前若该车牌仍禁止，阻断并提示先办理允许入厂。

演示数据：`蒙A90005`、`湘C92223` 为禁止；`桂A8T216` 为已允许。

#### G. 确认登记

1. 必填校验（车牌、净重、发站时间、卸煤区域、采样/过衡位按配置）。
2. 提交表单；失败用 `message.error` 通知。
3. 成功后列表顶部插入新纪录（时间倒序）。
4. 现场联动用 `message.success` 摘要：道闸抬杆、LED、广播。
5. 登记成功后清空表单（采样方式恢复机械采样）。

#### H. 清空

清空表单，不改列表。

#### I. 登记列表

展示本入厂点全部入厂登记，按入厂时间倒序。列：序号、流水号、车牌号、供应商、矿点、煤种、采样方式、矿发净重、过衡位、采样位、入厂时间、状态、操作（仅查看）。无分页，超出列表区域时仅表格内部滚动。

### 2.2 操作说明

- **数据类型**：登记单据 + 列表
- **数据源**：用户需求；前端 Mock（计划、预入厂、扫码示例）
- **关键操作**：
  - `车牌输入/联想`：三位起自动匹配，选中加载关联信息
  - `选择计划` / `扫描计划二维码` / `读矿发卡` / `扫描云驿二维码` / `获取预入厂信息`：回填表单
  - `允许入厂`（底部）：禁止入厂时人工放行
  - `确认登记`：提交 + 现场联动摘要
  - `清空`

### 2.3 界面默认情况

- 默认入厂点 **南门入厂点**，标题 **燃煤入厂登记**。
- 表单空表；车牌可输入，其余只读下划线（值为「—」）；采样方式默认文案「机械采样」。
- 列表预置 2 条历史（桂A8T216、鲁B12876，状态均为已登记）。
- 底部「允许入厂」默认禁用。

## 🧭 布局与结构

- **布局模式**：一屏固定（根容器 `height: 100%` + `overflow: hidden`）。页头 + 登记表单卡片（不伸缩）+ 登记列表卡片（占满剩余高度）。
- **页头**：标题「燃煤入厂登记」、当前配置摘要（计划获取 / 矿发获取）、入厂点下拉。
- **表单卡片**：标题「登记入厂信息」；右侧为获取动作（选择计划、扫码等，**不含**允许入厂）；三列字段（来煤 / 矿发 / 入厂）；底部右对齐「确认登记 / 允许入厂 / 清空」。
- **列表卡片**：占满剩余视口；表格 `scroll.y` 跟随容器高度。
- **抽屉/弹窗**：选择计划、云驿扫码、允许入厂登记、登记详情用 antd Drawer / Modal。

## 🎨 视觉规范

### 设计规范来源

- **主题**：项目默认 `src/themes/antd-new`。主色 `#1677ff`，圆角 6 px，`ConfigProvider` + `zhCN` + `componentSize="small"`。
- **设计规范**：`src/themes/antd-new/DESIGN-SPEC.md`。
- **设计方法**：管理后台走 `/skills/default-design-guide-minimal/SKILL.md`。

### 设计意图

浅色中后台值班台一屏布局。除车牌外登记字段用**标签 + 底部分割线**只读展示。允许入厂用 **success/error Tag** 强化；云驿扫码用扫描框 + 扫描线动画。

### 组件状态

| 状态 | 表现 |
|------|------|
| 默认 | 白卡片 + 下划线只读行；车牌 AutoComplete |
| 悬停 | 按钮/问号 Tooltip hover |
| 选中 | 计划表单选行高亮；车牌联想下拉选中 |
| 聚焦 | 车牌输入框主色描边 |
| 禁用 | 允许入厂按钮在「允许入厂=是」时 disabled |
| 加载 | 扫码按钮 loading；云驿模态扫描中 Spin |
| 空 | 字段「—」；列表 antd 空态 |
| 异常 | 二维码失效、车牌不匹配、禁止入厂阻断用 Modal / message |

### 可访问性

- 必填项 label 前 `*`；颜色不作为唯一状态（Tag 带文字）。
- 问号图标带 `aria-label`；扫码隐藏输入可键盘捕获。
- `prefers-reduced-motion: reduce` 时关闭扫描线动画。
