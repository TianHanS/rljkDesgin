# 人工入厂登记

> 本原型为**新增**页面，面向门岗/入厂点值班员的浅色后台管理界面。不改动已有的司机自助入厂登记。

## 📋 功能说明

### 1.1 核心目标

把暗色现场大屏上的「人工入厂登记」改成燃料集控后台的浅色管理页，让值班员在同一屏完成：

1. **来煤信息获取**：按入厂点配置选择计划、扫计划码、按车牌匹配或读矿发卡，也可扫云驿二维码。
2. **矿发信息获取**：预入厂、矿发卡、送货单手录或云驿码回填毛/皮/净。
3. **入厂信息与登记**：采样方式、采样位、过衡位、卸煤区域、入厂卡；确认登记后联动道闸 / LED / 广播。
4. **人工允许入厂**（新增）：预入厂车辆仍为「禁止入厂登记」时，录入车牌查出预入厂信息，更新为「允许入厂」后再做登记。
5. **煤样卡**：按配置展示确认并发卡、补发、查询。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 入厂点值班员 | 登记来煤/转场煤、允许预入厂车辆、发煤样卡 |
| 门岗班长 | 切换入厂点、核对禁止入厂车辆、查看登记列表 |
| 燃料集控 | 抽查登记记录与现场联动日志 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 入厂点与配置

页头下拉切换入厂点，配置随点位变化并即时改写按钮与必填：

| 配置项 | 含义 | 南门 | 北门 | 东门 |
|--------|------|------|------|------|
| `GET_PLAN_MSG` | 来煤计划：1 选择计划 / 2 扫计划码 / 3 按车牌 / 4 读矿发卡 | 1 | 3 | 4 |
| `GET_ORIGINAL_MSG` | 矿发信息：1 预入厂 / 2 矿发卡 / 3 送货单手录 / 4 云驿码 | 3 | 1 | 2 |
| `SAMPLE_MEASURE_EDIT` | 采样/过衡位：0 非必填，1 必填 | 1 | 0 | 1 |
| `ENABLE_ENTER_CARD` | 是否展示并提交入厂卡 | 开 | 关 | 开 |
| `ENABLE_ENTER_SAMPLE_CARD` | 是否展示发煤样卡相关按钮 | 开 | 关 | 关 |

另有 **西门入厂点**：`GET_PLAN_MSG = 2`（选择计划 + 扫描计划码）、`GET_ORIGINAL_MSG = 4`（云驿码填矿发）。

页头分段：**来煤登记** / **转场煤登记**。转场煤共用表单结构，列表用标签区分。

#### B. 来煤信息获取

- 管理员可编辑回填字段。
- **选择计划**：弹窗单选计划，回显供应商、矿点、煤种、运输单位、卸煤区域、品名、发站及发站时间、车牌。
- **扫描计划二维码**：按钮进入加载，读取扫码枪内容（计划 ID），查询计划后回填；支持示例码。
- **按车牌**：车牌失焦/回车后查计划；查不到提示无匹配计划。
- **读矿发卡**：解析 `车牌OreadWriteOaObO车牌O计划idO毛重O皮重O`。回填计划；毛皮按矿发配置写入。
- **扫描云驿二维码**：格式 `计划流水号\|运输任务单号\|车牌号码\|发货时间\|矿发毛重\|矿发皮重\|矿发净重\|计划ID\|当前时间\|发站时间`。
  1. 填充车牌；「当前时间」与系统时间相差超过 15 分钟 →「二维码失效，请刷新！」
  2. 按计划 ID 查计划，填充供应商、矿点、煤种、运输单位、卸煤区域。
  3. 矿发毛/皮/净是否写入取决于 `GET_ORIGINAL_MSG`（为 4 时写入）。
- 运输单位：下拉可搜，数据来自运输单位字典。

#### C. 矿发信息

- 毛/皮/净为小数，须 **< 200**；净重必填。
- `GET_ORIGINAL_MSG = 1`：按车牌取预入厂毛皮净。
- `= 2`：矿发卡读取后比对**表单车牌**与**卡内车牌**，不一致弹出确认：「输入车牌与读卡车辆车牌不匹配，矿发卡车牌为：湘C92223」。
- `= 3`：手录送货单。
- `= 4`：用云驿码中的毛/皮/净填充。

#### D. 入厂信息

- 采样方式：机械采样 / 人工采样，默认机械采样，必填。
- 采样位、过衡位、卸煤区域：下拉可搜。采样/过衡位必填性由 `SAMPLE_MEASURE_EDIT` 决定。
- 入厂卡：`ENABLE_ENTER_CARD` 为真时展示。后端推送 `YCOneTimeCardContent` 时回填。提交优先级：**临时卡 ＞ 固定卡 ＞ 无卡号**。

#### E. 人工允许入厂（新增）

部分车辆已预入厂，状态仍为 **禁止入厂登记**，不能直接确认登记。

1. 点【允许入厂】，录入车牌并查询预入厂。
2. 展示计划摘要、预入厂时间、当前许可状态。
3. 禁止入厂时，点【更新为允许入厂】后状态变为允许，并可一键填入登记表单。
4. 确认登记前若该车牌仍禁止，阻断并提示先办理允许入厂。

演示数据：`蒙A90005`、`湘C92223` 为禁止；`桂A8T216` 为已允许。

#### F. 确认登记

1. 必填校验。
2. 提交表单；若需发卡则按卡号优先级上传。
3. 失败用 `message.error` 通知。
4. 成功后列表顶部插入新纪录（时间倒序）。
5. 现场联动（按道闸配置模拟）：道闸抬杆 `YKEnterBarrierGateUp` / `YKBarrierGateUp`；LED「$车牌号 登记成功」；广播「$车牌号 请入厂，前往$采样位 $过衡位」；写入模块日志。

#### G. 确认登记并发煤样卡

仅 `ENABLE_ENTER_SAMPLE_CARD = 1` 时展示。登记成功后弹窗：

- 回显车牌；按车牌、当前时间 ±30 min 查询入厂流水号。
- 文案：请刷卡，等待写卡成功！写卡过程中请勿随意移动...
- 写卡成功后提示并 **5 秒倒计时**关闭。
- 说明：采集程序 60 秒后清除写卡内容（页面脚注）。

#### H. 补发煤样卡 / 煤样卡查询

同配置项为 1 时展示。补发：从列表选一条已登记记录走同一写卡窗。查询：按车牌列出该车发卡记录。

#### I. 清空

清空表单与当前计划/许可提示，不改列表。

#### J. 登记列表

展示本入厂点全部入厂登记，按入厂时间倒序。列：序号、流水号、车牌号、供应商、矿点、煤种、采样方式、矿发净重、过衡位、采样位、入厂时间、状态、操作。

### 2.2 操作说明

- **数据类型**：登记单据 + 列表
- **数据源**：用户需求截图与规则；前端 Mock（计划、预入厂、扫码示例）
- **关键操作**：
  - `选择计划` / `扫描计划二维码` / `读矿发卡` / `扫描云驿二维码` / `获取预入厂`：回填表单
  - `允许入厂`：查询预入厂并更新许可
  - `确认登记` / `确认并发煤样卡`：提交 + 联动 + 可选写卡
  - `补发煤样卡` / `煤样卡查询`
  - `清空`

### 2.3 界面默认情况

- 默认入厂点 **南门入厂点**，模式 **来煤登记**。
- 表单空表，采样方式默认机械采样；南门显示选择计划、云驿扫码、允许入厂、入厂卡、发煤样卡按钮。
- 列表预置 2 条历史（桂A8T216 已发卡、鲁B12876 已登记）。
- 禁止入厂车辆未允许前，页内 Alert 提示。

## 🧭 布局与结构

- **布局模式**：单页纵向。页头工具条 + 登记表单卡片 + 登记列表卡片。
- **页头**：入厂点下拉、来煤/转场分段、当前配置摘要（计划获取 / 矿发获取）。
- **表单卡片**：标题「登记入厂信息」；右侧为获取动作（选择计划、扫码、允许入厂、煤样卡查询等）；三列字段（来煤 / 矿发 / 入厂）；底部右对齐主按钮。
- **列表卡片**：全宽表格，操作列为查看 / 补发。
- **关键尺寸**：页面灰底 `#f5f5f5`，卡片白底圆角 8 px，内边距 20/24 px；表单三列，`≤1200px` 改两列，`≤760px` 单列。
- **抽屉/弹窗**：选择计划、扫码、允许入厂、煤样卡写卡与查询均用 antd Drawer / Modal，不跳页。

## 🎨 视觉规范

### 设计规范来源

- **主题**：项目默认 `src/themes/antd-new`。主色 `#1677ff`，圆角 6 px，`ConfigProvider` + `zhCN`。
- **设计规范**：`src/themes/antd-new/DESIGN-SPEC.md`。
- **设计方法**：管理后台走 `/skills/default-design-guide-minimal/SKILL.md`（克制、边框分层、浅灰底）。

### 设计意图

由截图暗色现场大屏改为**白色浅色中后台**：页头与卡片用 1 px `#f0f0f0` 描边，不用霓虹与大阴影。状态色：禁止入厂 error、允许入厂 success、已登记 default、已发卡 processing。

### 组件状态

| 状态 | 表现 |
|------|------|
| 默认 | 白卡片 + antd 描边输入 |
| 悬停 | 按钮/行 antd hover |
| 选中 | 计划表单选行高亮 |
| 聚焦 | `:focus-visible` 主色描边 |
| 禁用 | 配置关闭的按钮不渲染；采样位在不可编辑配置下仍可看 |
| 加载 | 扫码按钮 loading；写卡 Modal 内 Spin |
| 空 | 列表 antd 空态 |
| 异常 | 二维码失效、车牌不匹配、禁止入厂阻断用 Alert / Modal.confirm / message |

### 可访问性

- 必填项 `*` + 校验文案；颜色不作为唯一状态（Tag 带文字）。
- 扫码输入可用键盘；主按钮可 Tab。
- `prefers-reduced-motion: reduce` 时关闭倒计时动画闪烁。
