# 燃煤入厂登记

> 本原型为**新增**页面，面向门岗/入厂点值班员的浅色后台管理界面。不改动已有的司机自助入厂登记。本页**只做燃煤入厂登记**，不含煤样卡与转场煤。

## 📋 功能说明

### 1.1 核心目标

值班员在**一屏固定布局**内完成燃煤入厂登记：表单与登记列表同时可见，页面本身不纵向滚动（仅列表内部滚动）。

1. **来煤信息获取**：按入厂点配置选择计划、扫计划码、按车牌匹配或读矿发卡，也可扫云驿二维码。
2. **矿发信息获取**：预入厂、矿发卡、送货单手录或云驿码回填毛/皮/净。
3. **入厂信息与登记**：采样方式、采样位、过衡位、卸煤区域、入厂卡；确认登记后联动道闸 / LED / 广播。
4. **人工允许入厂**：预入厂车辆仍为「禁止入厂登记」时，录入车牌查出预入厂信息，更新为「允许入厂」后再做登记。

**明确不做**：煤样卡查询、补发煤样卡、确认登记并发煤样卡、来煤/转场煤模式切换。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 入厂点值班员 | 办理燃煤入厂登记、允许预入厂车辆 |
| 门岗班长 | 切换入厂点、核对禁止入厂车辆、查看登记列表 |
| 燃料集控 | 抽查登记记录 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 入厂点与配置

页头下拉切换入厂点，配置随点位变化并即时改写按钮与必填：

| 配置项 | 含义 | 南门 | 北门 | 东门 | 西门 |
|--------|------|------|------|------|------|
| `GET_PLAN_MSG` | 来煤计划：1 选择计划 / 2 扫计划码 / 3 按车牌 / 4 读矿发卡 | 1 | 3 | 4 | 2 |
| `GET_ORIGINAL_MSG` | 矿发信息：1 预入厂 / 2 矿发卡 / 3 送货单手录 / 4 云驿码 | 3 | 1 | 2 | 4 |
| `SAMPLE_MEASURE_EDIT` | 采样/过衡位：0 非必填，1 必填 | 1 | 0 | 1 | 1 |
| `ENABLE_ENTER_CARD` | 是否展示并提交入厂卡 | 开 | 关 | 开 | 开 |

页头标题固定为 **燃煤入厂登记**，不提供来煤/转场分段切换。

#### B. 来煤信息获取

- **登记区字段全部只读**：以标签 + 下划线展示，不可手改；通过选择计划 / 扫码 / 读卡 / 允许入厂回填。
- **选择计划**：弹窗单选计划，回显供应商、矿点、煤种、运输单位、卸煤区域、品名、发站及发站时间、车牌，并带回毛皮净与默认采样位/过衡位。
- **扫描计划二维码**：按钮进入加载，读取扫码枪内容（计划 ID），查询计划后回填；支持示例码。
- **按车牌匹配计划**：北门等配置下，通过「允许入厂」或扫码回填车牌后，再用「获取预入厂信息」取计划（车牌字段本身不可手输）。
- **读矿发卡**：解析 `车牌OreadWriteOaObO车牌O计划idO毛重O皮重O`。回填计划；毛皮按矿发配置写入。
- **扫描云驿二维码**：格式 `计划流水号\|运输任务单号\|车牌号码\|发货时间\|矿发毛重\|矿发皮重\|矿发净重\|计划ID\|当前时间\|发站时间`。
  1. 填充车牌；「当前时间」与系统时间相差超过 15 分钟 →「二维码失效，请刷新！」
  2. 按计划 ID 查计划，填充供应商、矿点、煤种、运输单位、卸煤区域。
  3. 矿发毛/皮/净是否写入取决于 `GET_ORIGINAL_MSG`（为 4 时写入；字段只读时选择计划也会带回计划净重）。
- 运输单位等字典字段只读展示回填结果。

#### C. 矿发信息

- 毛/皮/净只读展示；须 **< 200**；确认登记时净重必填（由计划/扫码/读卡回填）。
- `GET_ORIGINAL_MSG = 1`：按车牌取预入厂毛皮净。
- `= 2`：矿发卡读取后比对**表单车牌**与**卡内车牌**，不一致弹出确认：「输入车牌与读卡车辆车牌不匹配，矿发卡车牌为：湘C92223」。
- `= 3`：字段只读，选择计划时带回计划毛皮净（不再手录送货单）。
- `= 4`：用云驿码中的毛/皮/净填充。

#### D. 入厂信息

- 采样方式、采样位、过衡位、卸煤区域、入厂卡均为只读下划线展示。
- 选择计划/扫码回填时写入默认采样方式「机械采样」、默认采样位/过衡位；入厂卡优先取预入厂卡号。
- 采样/过衡位在 `SAMPLE_MEASURE_EDIT = 1` 时登记前必有值；入厂卡在 `ENABLE_ENTER_CARD` 开启时必有值。提交优先级：**临时卡 ＞ 固定卡 ＞ 无卡号**。

#### E. 人工允许入厂

部分车辆已预入厂，状态仍为 **禁止入厂登记**，不能直接确认登记。

1. 点【允许入厂】，录入车牌并查询预入厂。
2. 展示计划摘要、预入厂时间、当前许可状态。
3. 禁止入厂时，点【更新为允许入厂】后状态变为允许，并可一键填入登记表单。
4. 确认登记前若该车牌仍禁止，阻断并提示先办理允许入厂。
5. 表单标题旁用红色 Tag 提示当前车牌仍禁止入厂（不使用占高度的整行 Alert，避免撑破一屏）。

演示数据：`蒙A90005`、`湘C92223` 为禁止；`桂A8T216` 为已允许。

#### F. 确认登记

1. 必填校验。
2. 提交表单；若需入厂卡则按卡号优先级上传。
3. 失败用 `message.error` 通知。
4. 成功后列表顶部插入新纪录（时间倒序）。
5. 现场联动用 `message.success` 摘要：道闸抬杆、LED「$车牌号 登记成功」、广播「$车牌号 请入厂，前往$采样位 $过衡位」。
6. 校验失败时字段旁提示，并用 `message.error` 提示首个错误，避免值班员误以为无响应。
7. 登记成功后清空表单（采样方式恢复机械采样），列表保留新纪录。

#### G. 清空

清空表单与当前计划/许可提示，不改列表。

#### H. 登记列表

展示本入厂点全部入厂登记，按入厂时间倒序。列：序号、流水号、车牌号、供应商、矿点、煤种、采样方式、矿发净重、过衡位、采样位、入厂时间、状态、操作（仅查看）。无分页，超出列表区域时仅表格内部滚动。

### 2.2 操作说明

- **数据类型**：登记单据 + 列表
- **数据源**：用户需求截图与规则；前端 Mock（计划、预入厂、扫码示例）
- **关键操作**：
  - `选择计划` / `扫描计划二维码` / `读矿发卡` / `扫描云驿二维码` / `获取预入厂信息`：回填表单
  - `允许入厂`：查询预入厂并更新许可
  - `确认登记`：提交 + 现场联动摘要
  - `清空`

### 2.3 界面默认情况

- 默认入厂点 **南门入厂点**，标题 **燃煤入厂登记**。
- 表单空表（只读下划线，值为「—」），采样方式默认文案「机械采样」；南门显示选择计划、云驿扫码、允许入厂。
- 列表预置 2 条历史（桂A8T216、鲁B12876，状态均为已登记）。
- 禁止入厂车辆未允许前，标题旁 Tag 提示。

## 🧭 布局与结构

- **布局模式**：一屏固定（根容器 `height: 100%` + `overflow: hidden`）。页头 + 登记表单卡片（不伸缩）+ 登记列表卡片（占满剩余高度）。
- **页头**：标题「燃煤入厂登记」、当前配置摘要（计划获取 / 矿发获取）、入厂点下拉。无来煤/转场分段。
- **表单卡片**：标题「登记入厂信息」；右侧为获取动作（选择计划、扫码、允许入厂）；三列**只读下划线字段**（来煤 / 矿发 / 入厂，label 宽 80 px）；底部右对齐「确认登记 / 清空」。
- **列表卡片**：占满剩余视口；表格 `scroll.y` 跟随容器高度，操作列仅「查看」。
- **关键尺寸**：页面灰底 `#f5f5f5`，卡片白底圆角 8 px；`min-width: 1280px`；`html/body/#root` 与根容器均为 `height: 100%` + `overflow: hidden`；页头与卡片内边距压缩（约 6–12 px）。
- **抽屉/弹窗**：选择计划、扫码、允许入厂、登记详情用 antd Drawer / Modal，不跳页。

## 🎨 视觉规范

### 设计规范来源

- **主题**：项目默认 `src/themes/antd-new`。主色 `#1677ff`，圆角 6 px，`ConfigProvider` + `zhCN` + `componentSize="small"`。
- **设计规范**：`src/themes/antd-new/DESIGN-SPEC.md`。
- **设计方法**：管理后台走 `/skills/default-design-guide-minimal/SKILL.md`（克制、边框分层、浅灰底）。

### 设计意图

由截图暗色现场大屏改为**白色浅色中后台**，并压成值班台一屏。登记字段用**标签 + 底部分割线**只读展示，不用输入框/下拉；空值显示「—」（浅灰）。状态色：禁止入厂 error、允许入厂 success、已登记 default。

### 组件状态

| 状态 | 表现 |
|------|------|
| 默认 | 白卡片 + 下划线只读行 |
| 悬停 | 按钮/行 antd hover |
| 选中 | 计划表单选行高亮 |
| 聚焦 | 页头 Select `:focus-visible` 主色描边 |
| 禁用 | 配置关闭的按钮不渲染；字段本身不可编辑 |
| 加载 | 扫码按钮 loading |
| 空 | 字段「—」；列表 antd 空态 |
| 异常 | 二维码失效、车牌不匹配、禁止入厂阻断用 Modal.confirm / message |

### 可访问性

- 必填项 label 前 `*`；颜色不作为唯一状态（Tag 带文字）。
- 扫码输入可用键盘；主按钮可 Tab。
- `prefers-reduced-motion: reduce` 时关闭过渡动画。
