# 燃煤入厂登记

> 人工办理点登记界面，面向入厂管理员。支持切换入厂点、按菜单权限加载二级功能（来煤/转场煤/非煤物资/出厂登记），配置驱动表单字段与操作按钮。

## 📋 功能说明

### 1.1 核心目标

入厂管理员在**一屏固定布局**内完成燃煤入厂登记：登记表单与入厂车辆列表同时可见，页面本身不纵向滚动（仅列表内部滚动）。

1. **切换入厂点**：顶部下拉单选入厂点，浏览器 `localStorage` 缓存上次选择，再次进入默认加载缓存入厂点。
2. **二级功能 Tab**：来煤登记、转场煤登记、非煤物资登记、出厂登记，按登录人菜单权限动态加载（原型 Mock 权限）。
3. **来煤信息获取**：人工选择计划、计划码扫码、云驿扫码、煤样卡查询、车牌联想等方式回填表单。
4. **配置驱动表单**：非配置字段默认加载；配置字段按模块编码 `FIELD_*` 控制可见与可编辑。
5. **配置驱动操作**：操作按钮按 `OPERATION_*` 配置动态展示；清除重置为常驻操作。
6. **入厂车辆列表**：按入厂时间倒序，不支持查询；操作列按配置展示「补发煤样卡」，已出厂车辆不显示该操作。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 入厂管理员 | 人工录入送货单、读卡、扫码，办理入厂手续与发卡 |
| 门岗班长 | 切换入厂点、核对登记信息、查看入厂车辆列表 |
| 燃料集控 | 抽查登记记录 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 入厂点与模块

1. 顶部 **入厂点下拉** 切换 MEOR 模块类型对应入厂点；选择后写入 `mer_last_site_id` 缓存。
2. **二级功能 Tab** 根据 `MODULE_MENUS.permitted` 过滤展示（原型：来煤/转场煤/出厂可见，非煤物资无权限隐藏）。
3. 切换入厂点时清空表单；切换 Tab 时清空表单。

#### B. 表单字段（配置项）

| 表单字段 | 配置项 | 约束 |
|---------|--------|------|
| *车牌号码 | FIELD_vehicleNo | 可编辑；输入 ≥3 位联想车牌；不合规提示「车牌错误」 |
| 车辆卡号 | FIELD_cardNo | 只读 |
| 供应商/矿点/煤种/品名/运输单位 | — | 非配置字段，默认只读加载 |
| 矿发毛重 t | FIELD_mineHairGrossWeight | 配置可编辑时为小数步进器，两位小数 |
| 矿发皮重 t | FIELD_mineHairTare | 同上 |
| *矿发净重 t | FIELD_ticketHeight | 同上，登记必填 |
| 发站 | — | 只读 |
| 发站时间 | FIELD_fromDate | 按配置只读展示 |
| 采样位 | FIELD_simplingName | 可编辑时为汽车采样机下拉 |
| 过衡位 | FIELD_poundName | 可编辑时为汽车衡下拉 |
| 卸煤区域 | — | 只读 |
| 采样方式 | FIELD_simplingSource | 机械采样 / 人工采样，提交明文字符串 |
| 入厂卡/煤样卡 | FIELD_cardNo1 | 只读 |

#### C. 操作（配置项）

| 操作 | 配置项 | 约束 |
|------|--------|------|
| 人工选择计划 | OPERATION_manualSelectPlan | 右侧抽屉；当日来煤计划单选；可按供应商/矿点/煤种筛选；点击行选中；回填供应商、矿点、煤种、品名、运输单位、发站、发站时间、采样位、过衡位、预卸煤区 |
| 云驿扫码 | OPERATION_yunYiCode | 扫码弹窗；Esc/关闭退出；校验 15 分钟时效；按计划 ID 查计划；回填表单；提交含运单号 |
| 云驿自动模式 | OPERATION_yunYiCodeAuto | 西门入厂点启用 Tag 提示「待定」 |
| 计划码扫码 | OPERATION_planCode | 扫码弹窗；按计划 ID 查计划并回填 |
| 煤样卡查询 | OPERATION_cardNo1Search | 右侧抽屉读卡；5s 未读卡提示；成功展示卡号与入厂信息；可重新读卡 |
| 确认登记 | OPERATION_enterComfire | 校验必填 → 提交 → 成功清空表单并刷新列表 |
| 确认预登记 | OPERATION_preEnterComfire | 同上，成功提示「预登记成功」 |
| 确认登记并发卡 | OPERATION_cardNo1WriteAndenterComfire | 登记成功后写卡提示与结果 |
| 清除重置 | — | 常驻，清空表单 |
| 补发煤样卡（列表） | OPERATION_cardNo1Write | 已出厂不显示；写卡 5s 超时提示失败 |

#### D. 入厂车辆列表

- 不支持查询；按入厂时间逆序。
- 无任何列表操作配置时隐藏操作列；有配置时操作列 `fixed: 'right'`。
- 演示数据：`鲁B12876` 为已出厂，不显示补发煤样卡。

### 2.2 操作说明

- **数据类型**：登记单据 + 列表
- **数据源**：用户提供业务规约；前端 Mock（计划、预入厂、读卡、扫码示例）
- **关键操作**：
  - `入厂点切换`：下拉 + localStorage 缓存
  - `人工选择计划` / `计划码扫码` / `云驿扫码` / `煤样卡查询`：回填表单
  - `确认登记` / `确认预登记` / `确认登记并发卡`：提交登记
  - `清除重置`：清空表单
  - `补发煤样卡`：列表行操作

### 2.3 界面默认情况

- 进入页面按缓存加载入厂点（默认南门）；表单空表，采样方式默认「机械采样」。
- 列表预置 2 条历史（桂A8T216 在厂、鲁B12876 已出厂）。
- 非煤物资登记 Tab 因无菜单权限不展示。

## 🧭 布局与结构

- **布局模式**：一屏固定（根容器 `height: 100%` + `overflow: hidden`）。
- **顶部工具栏**：入厂点下拉 + 二级功能 Tabs + 云驿自动模式 Tag（按配置）。
- **登记表单卡片**：标题 + 操作按钮区 + 三列字段 + 底部提交按钮。
- **入厂车辆列表卡片**：占满剩余视口；表格内部滚动；操作列固定右侧。
