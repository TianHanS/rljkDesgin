# 消息配置

## 📋 功能说明

### 1.1 核心目标

供研发或运维人员按第三方系统对接要求，维护「消息码」与各业务字段（来源、推送范围、通知方式、人工确认与自动关闭策略等），作为后续业务消息推送与查询的配置主数据。

### 1.2 使用角色

- **研发人员**：对接第三方、维护消息码与字段映射。
- **运维人员**：启停配置、调整通知策略与免打扰时段。

## 📊 业务规则/约束

### 2.1 业务规则

- **列表表头（顺序）**：消息码、状态（**开关**表示启用/禁用，无额外文字标签）、类型（字典 `1` 成功、`2` 通知、`3` 警告、`4` 错误）、说明、来源、推送范围、通知方式、需人工确认、自动关闭时长（秒）、创建人、创建时间、更新人、更新时间。
- **排序**：列表按**操作时间**逆序展示；原型以 **更新时间** 作为操作时间排序键。
- **筛选**：消息码模糊匹配；类型下拉单选（字典 `msg_type`）；来源下拉单选（字典 `msg_source`）。
- **行内启停**：**仅 `Switch` 开关**表示启用/禁用，不再使用「启用/禁用」文字标签；变更前使用 **`Popconfirm` 气泡**二次确认后再写入状态。
- **行操作**：新增（页级按钮）、编辑、删除；**删除**使用 **`Popconfirm` 气泡**二次确认（文案含同步删除相关消息记录提示），确认后 Toast 提示结果。

### 2.2 字典与枚举

- **msg_type**：`1` 成功、`2` 通知、`3` 警告、`4` 错误。
- **msg_source**：管控平台、集控接口处理消息、三方设备厂家业务流程。
- **推送范围**：`1` 全局、`2` 按模块。
- **推送模块**（多选，仅当范围为「按模块」时必选）：原型内置模块类型列表（如采样机、汽车衡等），用于多选下拉。
- **msg_notification_method**：仅通知、通知并语音播报、播报+声光报警。

### 2.3 新增/编辑表单约束

1. **消息码**（*）：字符串；**禁止空格**（输入阶段拦截或校验失败）。
2. **类型**（*）：下拉单选，`msg_type`。
3. **说明**：可选，对该消息的说明文字。
4. **来源**（*）：下拉单选，`msg_source`。
5. **推送范围**（*）：`1` 全局 / `2` 按模块。
6. **推送模块**（*）：当范围为「按模块」时，模块类型**多选**必选。
7. **通知方式**（*）：`msg_notification_method`。
8. **需人工确认**（*）：单选，默认**否**。
9. **自动关闭时长**（*）：当**无需**人工确认时必填，默认 **30** 秒；需要人工确认时本字段不适用（表单隐藏/不校验，列表可展示为「-」）。
10. **免打扰时段**（非必填）：开始整点、结束整点，下拉 `0`–`23`；**开始与结束不能相同**，**例外**：`0`–`0` 表示不启用免打扰；字段旁提示：配置为 `0-0` 表示不启用。
11. **保存**：
    - 校验消息码**全局唯一**（与已有配置比较，编辑时排除自身）；重复提示「已存在」类文案。
    - 新建成功后默认 **启用**。

### 2.4 删除

- 使用 **`Popconfirm` 气泡**二次确认，文案包含：已存在的相关消息记录将同步删除，确认删除此配置？
- 确认后提示删除结果（配置及关联消息记录，原型 Toast 模拟）。

## 🎨 布局与结构

- 采用 **Ant Design** 典型后台布局：**浅色白系**（`ConfigProvider` 默认算法 + 灰白页面底 `#f0f2f5`、白底内容区）。
- 顶部标题区 + 筛选条 + 表格卡片；**新增/编辑**在右侧 **`Drawer`** 中完成；**启停**使用 **`Popconfirm` 气泡**确认；**删除**使用 **`Popconfirm` 气泡**确认（不使用居中 `Modal`）。
- **抽屉内表单**：使用 **`Row` + `Col`（24 栅格）** 排版，**`md` 及以上一行两列**（`xs` 窄屏自动单列）；说明、推送模块、免打扰说明等占 **整行（24 列）**。

## 🎨 视觉规范

- 与「业务消息查询」暗色大屏区分：本页为 **Ant Design 管理后台浅色风格**，组件以 antd 默认视觉为主，辅以轻量 Tailwind 仅用于根布局背景类（`style.css` 含 `@import "tailwindcss"`）。
