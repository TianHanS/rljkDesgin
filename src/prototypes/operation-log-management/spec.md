# 运行日志管理

## 📋 功能说明

### 1.1 核心目标

在「燃料质检集控中心」场景下，值班人员填报、查询**质检运行日志**（值班交接、工作情况、设备情况、异常处理等），支持列表检索与近 2 日内的维护操作，并与当班相关报警记录关联展示。

### 1.2 使用角色

- **集控值班员**：填报/编辑当班日志、交接信息。
- **班长/专工**：查询历史日志、导出。
- **系统管理员**（隐含）：日志保留与权限策略（原型 Mock）。

## 📊 业务规则/约束

### 2.1 业务规则

1. **默认视图**：进入模块即为**日志记录列表**。
2. **列表筛选**：工作情况（模糊）、设备情况（模糊）、日志日期范围；支持查询、重置、导出（原型 Toast）。
3. **列表字段**：序号、日志日期、开始时间、结束时间、工作情况(记事内容)、设备情况、其他事项、操作。
4. **班次（班值）**：`后夜班`（00:00–08:00）、`白班`（08:00–16:00）、`前夜班`（16:00–24:00）；**新增**时按**当前时刻**自动匹配班次及默认起止时间、值班日期。
5. **近 2 日规则**：以**日志日期**为准，仅**当日与昨日**的日志允许**编辑、删除**；更早记录仅可**查看、复制**。
6. **复制**：不受日期限制；气泡提示「复制新增一条日志」；打开表单预填源记录内容，**值班日期默认当日**，起止时间按所复制班次与当日重新计算；保存时生成新 ID。
7. **表单**（新增/编辑/复制）：见 2.2；底部展示**相关报警记录**（只读，按班次时间范围 Mock）。

### 2.2 操作说明

- **数据类型**：运行日志单据 + 异常处理明细子表 + 关联报警只读列表。
- **数据源**：用户提供界面截图；原型 Mock。
- **关键字段**
  - `新增`：Drawer 表单，默认当前班次班值与起止时间。
  - `编辑`：近 2 日可编辑；否则禁用并提示。
  - `复制`：任意日志可复制；Tooltip「复制新增一条日志」；值班日期默认当日。
  - `删除`：近 2 日可删；Popconfirm 二次确认。
  - `查看`：只读打开表单。
  - `保存日志`：校验必填项；成功关闭 Drawer 并刷新列表。

### 2.3 界面默认情况

- 列表默认按日志日期、开始时间逆序；日期筛选默认近 7 日。
- 无数据时表格 Empty；表单异常处理区默认 0 行，可「异常处理录入」增行。

## 布局与结构

- **顶栏**：燃料质检集控中心标题 + 横向主导航（日志管理高亮）。
- **列表区**：筛选条 + 新增按钮 + 表格 + 分页。
- **表单**：右侧 Drawer，上下结构 — 日志填报字段 + 相关报警记录表 + 保存。

## 视觉规范

- 深蓝工业大屏（`#0b1120` / 霓虹青描边），与 log-query、集控类原型一致。
- 必填项红色 `*`；表格交替行；Drawer 深色底。
