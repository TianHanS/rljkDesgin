# 厂外调度（厂外排队监控）

> 本原型为**新增**页面，面向门岗调度员的浅色后台。厂外通道通过车号识别与 LED 对入厂车辆自动取号排队；本页启用/停用排队程序、监看识别画面，并调整通道队列。

## 📋 功能说明

### 1.1 核心目标

调度员在**一屏固定布局**内完成厂外排队监控与队列干预，无需跳页。

1. **自动排队点切换**：一个厂多个入厂通道；一个通道对应多个入厂点。切换通道后，监控、设备、识别日志与队列一并切换。
2. **全局排队启用/停用**：厂外自动排队与云驿排队互斥，开启一侧时连锁关闭另一侧。
3. **排队点视频与设备**：监看该通道车号识别实时画面；展示识别相机、LED、道闸、排队终端状态。
4. **排队队列管理**：查询通道下正在排队车辆（含允许入厂状态与车号抓拍），支持增补、冻结、解冻、优先、插队、移除。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 厂外调度员 | 切换通道、启停排队、监看识别、调整队列 |
| 门岗班长 | 核对禁止入厂/冻结车辆、处理插队与优先 |
| 燃料集控 | 抽查排队与云驿接管状态 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 排队通道与入厂点

| 通道 | 关联入厂点 | 说明 |
|------|-----------|------|
| 南入厂通道 | 南门入厂点、西门入厂点 | 默认通道 |
| 北入厂通道 | 北门入厂点 | — |
| 东入厂通道 | 东门入厂点 | — |

- 页头下拉切换通道；配置摘要展示关联入厂点。
- 通道切换只换本通道的画面、设备、日志与队列，**不改变**全局厂外排队 / 云驿排队开关。

#### B. 全局排队与云驿互斥

厂级两个开关，不可同时开启（可同时关闭）：

| 开关 | 开启时 |
|------|--------|
| 厂外自动排队 | 车号识别命中且不在本通道队列中的车牌，自动取号入列；LED 显示当前叫号 |
| 云驿排队 | 厂外自动入列停止；LED 提示「请使用云驿 APP 取号」 |

- 打开厂外排队 → 若云驿为开，则**连锁关闭云驿**，提示「已停用云驿排队，厂外自动排队已启用」。
- 打开云驿排队 → 若厂外为开，则**连锁关闭厂外**，提示「已停用厂外自动排队，云驿排队已启用」。
- 关闭当前开启的一侧：仅停用，不自动打开另一侧。
- 厂外排队停用期间：识别日志仍刷新，但**不再自动入列**；人工增补/冻结等队列操作仍可用。页头展示停用或云驿接管提示。

#### C. 视频监控与识别日志

- 画面为当前通道车号识别相机（原型用模拟监控窗，叠加最近一次识别车牌、时间、通道名）。
- **车号识别排队登记日志**：本通道识别记录按时间逆序；字段：车牌号、识别时间；可点开对应抓拍。
- 识别周期模拟：约 8 秒追加一条日志。厂外排队开启且该车牌不在队列中时，自动增补为「正常」并取号。

#### D. 设备状态监测

每个通道展示四类设备：车号识别相机、LED 诱导屏、道闸、排队终端。状态：在线 / 告警 / 离线。LED 额外展示当前屏显文案（随排队开关与队首车辆变化）。

#### E. 排队队列

列表字段：排队序号、取号号码、排队通道、车牌号、车号抓拍、排队时间、排队状态、允许入厂、操作。

排队状态：

| 状态 | 允许入厂 | 排序位置 |
|------|---------|---------|
| 优先 | 允许（优先） | 最前 |
| 正常 | 允许 | 优先之后、冻结之前 |
| 冻结 | 禁止 | 最后 |

操作规则：

1. **冻结**：状态改为冻结，禁止入厂，序号变为全队列最后一辆。
2. **解冻**：状态改为正常，允许入厂，序号变为**正常队列（不含冻结）的最后一辆**（位于优先、其余正常之后，冻结之前）。
3. **增补**：录入车牌新增排队；取号号按通道前缀递增；状态正常；插在冻结之前。同一通道车牌不可重复。
4. **优先**：状态改为优先，允许优先入厂，序号变为 1（既有优先车辆顺延）。冻结车辆须先解冻。
5. **插队**：在非冻结车辆中指定目标序号，车辆移到该位，其余非冻结车辆顺延；冻结车辆仍贴在队尾。
6. **移除**：确认后从本通道队列删除，不影响识别日志。

抓拍：列表缩略图，点击预览放大。

### 2.2 操作说明

- **数据类型**：通道配置 + 监控状态 + 排队队列
- **数据源**：用户需求；前端 Mock（通道、设备、识别日志、队列、抓拍 SVG）
- **关键操作**：
  - `切换排队通道`：刷新监控、设备、日志、队列
  - `厂外自动排队` / `云驿排队`：互斥连锁开关
  - `增补`：弹窗录入车牌后入列
  - `冻结` / `解冻` / `优先` / `插队` / `移除`：改队列并重排序号
  - `抓拍预览`：查看车号抓拍大图

### 2.3 界面默认情况

- 默认通道 **南入厂通道**；厂外自动排队 **开启**，云驿排队 **关闭**。
- 南通道队列预置优先、正常、冻结混合车辆（含桂A8T216、鲁B12876、蒙A90005、湘C92223 等）。
- 监控窗显示最近一次识别叠加；日志已有若干条逆序记录。
- 北通道 LED 为告警，用于演示设备状态色。

## 🧭 布局与结构

- **布局模式**：一屏固定（`height: 100%` + `overflow: hidden`）。页头工具条 + 上区监控/设备/日志 + 下区队列（占满剩余高度）。
- **页头**：标题「厂外调度」旁展示当前通道关联入厂点 Tag；右侧为自动取号/云驿接管状态、通道下拉、厂外排队 Switch、云驿排队 Switch。
- **上区**：左约 58% 车号识别监控；右为设备状态（上）与识别日志（下）。
- **下区**：队列工具条（增补、车牌筛选）+ 表格；`scroll.y` 跟随剩余高度，页面本身不纵向滚动。
- **关键尺寸**：灰底 `#f5f5f5`，白卡片 1 px `#f0f0f0` 描边、圆角 8 px；`min-width: 1280px`；`componentSize="small"`。
- **抽屉/弹窗**：增补、插队用 Modal；移除用 Popconfirm；抓拍用 Image 预览。不跳页。

## 🎨 视觉规范

### 设计规范来源

- **主题**：项目默认 `src/themes/antd-new`。主色 `#1677ff`，圆角 6 px，`ConfigProvider` + `zhCN`。
- **设计规范**：`src/themes/antd-new/DESIGN-SPEC.md`。
- **设计方法**：管理后台走 `/skills/default-design-guide-minimal/SKILL.md`（克制、边框分层、浅灰底）。监控窗为功能性深色视口，不作为整页暗色主题。

### 设计意图

调度台浅色中后台：页头与卡片用描边分层，不用霓虹、大阴影或装饰渐变。状态色：在线 success、告警 warning、离线 default、优先 processing、冻结 error、正常 default。

### 组件状态

| 状态 | 表现 |
|------|------|
| 默认 | 白卡片 + antd 描边 |
| 悬停 | 按钮/行 hover |
| 选中 | 通道 Select 当前值 |
| 聚焦 | `:focus-visible` 主色描边 |
| 禁用 | 冻结车辆的「优先」「插队」禁用；已优先的「优先」禁用 |
| 加载 | 无整页 loading；识别为监控窗 LIVE 指示 |
| 空 | 北/东通道队列或筛选无数据时表格空态 |
| 异常 | 设备告警 Tag；互斥切换 message；重复车牌 message.error |

### 可访问性

- 状态不只靠颜色（Tag 带文字：在线/告警、允许/禁止）。
- 开关、表格操作可键盘到达。
- `prefers-reduced-motion: reduce` 时关闭 LIVE 闪烁。
