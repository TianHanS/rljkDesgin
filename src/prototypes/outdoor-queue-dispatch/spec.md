# 厂外调度（厂外排队监控）

> 本原型为**新增**页面，面向门岗调度员的浅色后台。厂外通道通过车号识别与 LED 对入厂车辆自动取号排队；本页启用/停用排队程序、监看识别画面，并调整通道队列。

## 📋 功能说明

### 1.1 核心目标

调度员在**一屏固定布局**内完成厂外排队监控与队列干预，无需跳页。

1. **自动排队点切换**：一个厂多个入厂通道；一个通道对应多个入厂点。切换通道后，监控、设备、识别日志与队列一并切换。
2. **厂外自动排队启用/停用**：页头仅保留厂外自动排队开关。开启时调用接口关闭云驿排队（界面不展示云驿状态，也不可直接控制云驿）。
3. **排队点视频与设备**：监看该通道车号识别实时画面；设备仅监测车号识别器、LED，用绿/灰圆点表示在线/离线。
4. **排队队列管理**：查询通道下正在排队车辆（含允许入厂状态与车号抓拍），支持增补、冻结、解冻、优先、插队、移除。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 厂外调度员 | 切换通道、启停厂外排队、监看识别、调整队列 |
| 门岗班长 | 核对禁止入厂/冻结车辆、处理插队与优先 |
| 燃料集控 | 抽查排队与设备在线情况 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 排队通道与入厂点

| 通道 | 关联入厂点 | 说明 |
|------|-----------|------|
| 南入厂通道 | 南门入厂点、西门入厂点 | 默认通道 |
| 北入厂通道 | 北门入厂点 | LED 离线，用于演示灰点 |
| 东入厂通道 | 东门入厂点 | 车号识别器离线，用于演示灰点 |

- 页头下拉切换通道；标题旁展示关联入厂点。
- 通道切换只换本通道的画面、设备、日志与队列，**不改变**厂外自动排队开关。

#### B. 厂外自动排队与云驿

页头**只展示**「厂外自动排队」开关，不展示云驿排队开关或云驿接管状态。

- **开启**厂外自动排队：车号识别命中且不在本通道队列中的车牌自动取号入列；LED 显示当前叫号；同时**调用关闭云驿排队接口**（原型 `closeYunyiQueueApi`），登记日志写入「已调用接口关闭云驿排队」。
- **关闭**：识别日志仍刷新，但不再自动入列；人工增补/冻结等仍可用。不自动打开云驿。
- 车号识别器或 LED 任一离线：不入列，日志写「设备异常离线无法正常排队请检查」。

#### C. 视频监控与识别日志

- 画面为当前通道车号识别相机（模拟监控窗，4:3，放在左侧窄栏，避免又宽又矮）。
- **车号识别登记日志**采用控制台样式，按时间逆序：`日志时间` + `日志内容`。
  - 成功：`皖B55190 排队成功`
  - 已在队列：`皖B55190 已在队列中`
  - 程序未启用：`皖B55190 已识别，排队程序未启用`
  - 设备离线：`设备异常离线无法正常排队请检查`
- 识别周期模拟：约 8 秒追加一条日志。

#### D. 设备状态监测

每个通道仅两个设备：**车号识别器**、**LED**。表现形式为一行两个状态点：

- 绿色小圆点 = 在线
- 灰色小圆点 = 离线

圆点附 `title` / `aria-label`「在线」或「离线」。南通道两点均在线；北通道 LED 离线；东通道车号识别器离线。

#### E. 排队队列

列表字段：排队序号、取号号码、排队通道、车牌号、车号抓拍、排队时间、排队状态、允许入厂、操作。

排队状态：

| 状态 | 允许入厂 | 排序位置 |
|------|---------|---------|
| 优先 | 允许（优先） | 最前 |
| 正常 | 允许 | 优先之后、冻结之前 |
| 冻结 | 禁止 | 最后 |

操作规则：

1. **冻结**：状态改为冻结，禁止入厂，序号变为全队列最后一辆。
2. **解冻**：状态改为正常，允许入厂，序号变为**正常队列（不含冻结）的最后一辆**（位于优先、其余正常之后，冻结之前）。
3. **增补**：录入车牌新增排队；取号号按通道前缀递增；状态正常；插在冻结之前。同一通道车牌不可重复。成功时日志写「$车牌 排队成功」。
4. **优先**：状态改为优先，允许优先入厂，序号变为 1（既有优先车辆顺延）。冻结车辆须先解冻。
5. **插队**：在非冻结车辆中指定目标序号，车辆移到该位，其余非冻结车辆顺延；冻结车辆仍贴在队尾。
6. **移除**：确认后从本通道队列删除，不影响识别日志。

抓拍：列表缩略图，点击预览放大。

### 2.2 操作说明

- **数据类型**：通道配置 + 监控状态 + 排队队列
- **数据源**：用户需求；前端 Mock（通道、设备、识别日志、队列、抓拍 SVG）
- **关键操作**：
  - `切换排队通道`：刷新监控、设备、日志、队列
  - `厂外自动排队`：启停自动取号；开启时调用关闭云驿排队接口
  - `增补`：弹窗录入车牌后入列
  - `冻结` / `解冻` / `优先` / `插队` / `移除`：改队列并重排序号
  - `抓拍预览`：查看车号抓拍大图

### 2.3 界面默认情况

- 默认通道 **南入厂通道**；厂外自动排队 **开启**。
- 南通道队列预置优先、正常、冻结混合车辆（含桂A8T216、鲁B12876、蒙A90005、湘C92223 等）。
- 监控窗显示最近一次识别叠加；左侧日志为控制台记录。
- 界面无云驿排队开关、无「云驿接管」标签。

## 🧭 布局与结构

- **布局模式**：一屏固定（`height: 100%` + `overflow: hidden`）。页头 + 左右双栏。
- **页头**：标题「厂外调度」+ 关联入厂点 Tag；右侧为自动取号/排队停用、通道下拉、厂外自动排队 Switch。
- **左栏（400 px）**：上为 4:3 车号识别监控；中为设备状态一行两点；下为控制台日志（占满剩余高度）。
- **右栏**：排队队列占满剩余视口；`scroll.y` 跟随容器高度。
- **关键尺寸**：灰底 `#f5f5f5`，白卡片 1 px `#f0f0f0` 描边、圆角 8 px；`min-width: 1280px`；`componentSize="small"`。
- **抽屉/弹窗**：增补、插队用 Modal；移除用 Popconfirm；抓拍用 Image 预览。不跳页。

## 🎨 视觉规范

### 设计规范来源

- **主题**：项目默认 `src/themes/antd-new`。主色 `#1677ff`，圆角 6 px，`ConfigProvider` + `zhCN`。
- **设计规范**：`src/themes/antd-new/DESIGN-SPEC.md`。
- **设计方法**：管理后台走 `/skills/default-design-guide-minimal/SKILL.md`（克制、边框分层、浅灰底）。监控窗为功能性深色视口，不作为整页暗色主题。

### 设计意图

调度台浅色中后台：页头与卡片用描边分层，不用霓虹、大阴影或装饰渐变。监控放在左侧窄栏保持接近 4:3，队列使用右侧宽区。设备状态用绿 `#52c41a` / 灰 `#bfbfbf` 圆点；日志错误行文字 `#cf1322`。

### 组件状态

| 状态 | 表现 |
|------|------|
| 默认 | 白卡片 + antd 描边 |
| 悬停 | 按钮/行 hover |
| 选中 | 通道 Select 当前值 |
| 聚焦 | `:focus-visible` 主色描边 |
| 禁用 | 冻结车辆的「优先」「插队」禁用；已优先的「优先」禁用 |
| 加载 | 无整页 loading；识别为监控窗 LIVE 指示 |
| 空 | 筛选无数据时表格空态 |
| 异常 | 灰点离线；控制台红色错误日志；重复车牌 message.error |

### 可访问性

- 设备圆点带「在线/离线」文字说明（title + aria-label）；队列状态用 Tag 文字。
- 开关、表格操作可键盘到达。
- `prefers-reduced-motion: reduce` 时关闭过渡。
