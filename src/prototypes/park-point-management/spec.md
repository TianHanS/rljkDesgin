# 停靠点管理 (Park Point Management)

## 📋 功能说明

### 1.1 核心目标
查看站点下的停靠点数据信息，并可对停靠点进行装卸端关联操作。

### 1.2 使用角色
- 配置人员
- 系统管理员

## 📊 业务规则/约束

### 2.1 业务规则
- **所属关系**：停靠点属于站点，一个站点包含多个停靠点。
- **列表展示**：
  - 字段：停靠点名称、停靠点值、站点名称、关联站点 ID、关联装卸端、是否充电点、纬度、经度、创建时间、更新时间、更新人、备注。
  - 排序：默认按“停靠点名称”排序。
- **关联装卸端**：
  - 非必填项。
  - 映射关系为 1-1，同一装卸端不可重复被关联。
  - 下拉单选，支持清除。
  - 选中后加载装卸端信息，包括装卸端类型（卸车端（归批）、装车端（集样）），并以只读方式展示。

### 2.2 操作说明

- **查询/筛选**：
  - **停靠点名称**：模糊匹配。
- **关联装卸端（编辑操作）**：
  - **位置**：列表操作列。
  - **交互**：点击弹出侧边抽屉。
  - **内容**：
    - 停靠点其他数据加载并展示（只读样式）。
    - 关联装卸端输入项（下拉选择，可清除，且不可选择已被其他停靠点关联的装卸端）。
    - 装卸端详细信息（只读，随下拉选择动态加载其类型）。

### 2.3 界面默认情况
- 默认展示所有停靠点列表，按停靠点名称排序。
- 采用暗色科技风格。
