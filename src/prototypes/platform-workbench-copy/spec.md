# 平台工作台首页 副本

## 📋 功能说明

### 1.1 核心目标

> 燃煤智能管控及预警防护平台的默认首页（内嵌页面，顶部系统菜单与外层框架由平台统一提供，本页不重复实现）。

汇聚各子系统的关键生产指标、安全预警关键数据、待办任务、生产作业动态与数据趋势，并作为各功能模块的快捷入口，实现"一屏总览、一键直达"。

依据：《标段8：全厂燃煤智能管控及预警防护EPC总承包工程招标文件（第二卷 技术规范书）》4.4.1 节软件功能需求（管控系统平台、输煤全流程动态展示、智能调度、燃料特征码追踪、智能分析、输煤/煤场安全监测、智能配煤掺烧、统计报表分析等模块）。

### 1.2 使用角色

- **燃料值长 / 值班员**：关注安全报警、当前作业、待办任务
- **煤场专工**：关注库存结构、来煤动态、计划安排
- **燃料管理人员**：关注进耗存、煤耗成本、竞赛排名等统计数据

## 📊 业务规则/约束

### 2.1 业务规则

#### 区块 1：欢迎条

- 内容：问候语（按时段：上午好/下午好/晚上好）+ 当前用户 + 当日日期星期 + 当前值别（甲/乙/丙/丁/戊值轮值）。
- 轻量单行展示，不占用过多纵向空间。

#### 区块 2：核心指标（左）+ 功能模块导航（右），同一行

- 欢迎条下方为一行两栏布局：**左侧为 8 个核心指标**（合并为单一面板、4 列 × 2 行、细分割线分隔，替代独立小卡片以降低视觉噪音），**右侧为功能模块导航面板**。
- 功能模块面板高度与左侧指标区对齐，**卡片网格布局（2 列小卡片）**，默认可见 2×2 共 4 张，其余纵向下滑查看（细滚动条提示）。
- 模块卡片：上行为淡色底彩色图标 + 右上角状态标识，下行为模块名；悬浮显示模块简述、卡片高亮上浮。
- **可直达/建设中标识**：已建成原型的模块排在列表前部，右侧常显蓝色"进入 →"标识（悬浮箭头位移微动效）；未建成模块整体弱化（灰字、淡色图标），右侧显示"建设中"胶囊标签，点击提示建设中。
- 模块清单（可直达优先）：输煤全流程动态展示、燃运班值报表、统计报表分析、智能调度、智能分析、输煤安全监测、煤场安全监测、燃料特征码全程追踪、煤场智能管控一体化、入厂煤智能采制化、智能配煤掺烧、系统管理。
- 已有原型的模块直接跳转：
  - 输煤全流程动态展示 → `/prototypes/coal-handling-flow-monitor/`
  - 燃运班值报表 → `/prototypes/fuel-handling-shift-report/`
  - 统计报表分析（小指标竞赛）→ `/prototypes/team-duty-monthly-competition/`
- 其余模块点击提示"模块原型建设中"。

**核心指标（8 项，从左至右、从上至下）**

| 指标 | 取值口径 | 单位 | 较昨日 |
|------|------|------|------|
| 今日进煤量 | 班值报表当日累计进煤量，保留整数 | t | 今日−昨日，整数，单位 t |
| 今日耗煤量 | 当日上煤单对应总量累加，保留整数 | t | 今日−昨日，整数，单位 t |
| 煤场总存煤量 | 查询 `coal_heap` 各煤堆存煤量累加 | 万t | 今日总量−昨日期末煤量，整数，单位 t（主值仍为万t） |
| 预估可用天数 | 当前存煤总量 ÷ 近三日上煤单日均耗煤量，保留 1 位小数 | 天 | 不展示较昨日；脚注说明测算口径 |
| 今日卸煤单耗 | 当日各班次卸煤单耗均值，保留 2 位小数；昨日取三班均值 | kWh/t | 今日−昨日，保留 2 位小数 |
| 今日上煤单耗 | 当日各班次上煤单耗均值，保留 2 位小数；昨日取三班均值 | kWh/t | 今日−昨日，保留 2 位小数 |
| 今日发电量 | 发电成本报表；后端写死默认返回 | GWh | 今日−昨日，保留 2 位小数 |
| 设备综合投用率 | 当日各班值四类设备投运率累加求均值（或竞赛表综合投运率）；昨日取均值 | % | 今日−昨日，保留 1 位小数 |

- 每张卡片展示：指标名、当前值、较昨日增减（↑红/↓绿仅表示变化方向）；采用紧凑样式压缩纵向空间。
- 正数表示增加、负数表示减少；较昨日文案形如 `较昨日 +1,206 t`。
- 预估可用天数不展示较昨日差值，脚注为「近三日日均耗煤测算」。
- 今日发电量未接入时展示 `0.00 GWh`，较昨日按后端默认差值展示。

#### 区块 3：安全预警中心（左侧主区）

**3.1 摘要数据卡（3 张，均可点击快捷进入对应监测模块）**

| 卡片 | 内容 | 点击去向 |
|------|------|---------|
| 输煤待处理报警 | 待处理数量 + 今日累计 | 输煤安全监测模块 |
| 煤场待处理报警 | 待处理数量 + 今日累计 | 煤场安全监测模块 |
| 设备接入总量 | 已接入监测设备/测点总数 | 设备实时监测 |

**3.2 实时报警列表**

- 字段：报警等级（紧急/重要/一般）、报警类型、位置、报警值、时间、报警状态（报警中/已解除）。
- 报警按时间倒序，报警中置顶；等级以颜色 Tag 区分（紧急-红、重要-橙、一般-蓝）；报警状态以 Tag 展示（报警中-红、已解除-灰）。
- 不展示各监测子系统的在线/离线状态。
- **点击整行**打开「报警详情」弹窗（与「平台工作台首页」一致）。

**3.2.1 报警详情弹窗**

- **基本信息**（两行四列）：报警名称、报警值、报警阈值、报警等级、报警设备、设备所在区域、发生时间、结束时间（报警中时结束时间为空）。
- **相关监测量**：时间范围、数据步长、查询、图表/列表切换；选择对比指标；图表展示报警关联曲线，列表展示时序表。
- 底部居中「关闭」按钮。

#### 区块 4：审批待办（右侧区）

- **数据口径**：对齐流程中心「我的总览 - 我的待办」原始数据，**仅展示当前登录用户个人待办的审批事项**（不含已办、发起、消息，也不含计划执行/库存提醒等非审批类内容）。
- 原始数据字段：业务单名称、业务发起人、发起人部门、业务发起时间、上一步办理人/办理时间、当前节点（如输煤专工审核、灰硫专工、锅炉/灰硫专工审批等）。
- 工作台摘要展示：业务单名称（超长省略）、当前节点 Tag（按节点类型区分颜色）、发起人 · 部门 · 发起时间；顺序与流程中心列表一致，取最近 6 条。
- 头部徽标展示个人待办总数（如 36）；`查看全部` 跳转流程中心我的待办列表（原型提示模拟）。
- 每条 `办理` 按钮点击打开对应业务单审批页（原型提示模拟）。

#### 区块 5：生产作业动态

- **当前配煤单**：展示配煤单管理功能中**当前正在执行使用的单条配煤单**数据（无"加仓工单"概念），带"执行中"状态标识；卡片头部提供入口跳转已有的「配煤单管理」原型（`/prototypes/coal-blending-bill-management/`）。
  - 采用**层级式布局替代"标签：值"文字行**：计划名称为大字主标题、计划编号为小字底注；明细数/计划日期/起止时间以 3 个迷你数字块呈现；创建人为弱化底注。
- **来煤接卸动态**：数据来源为卸煤管理功能。**在途船次、在泊船次数量在卡片标题行右侧内联简单显示**；卡片主体展示**当前"正在卸煤"状态的卸煤信息**（单条），同样采用层级式布局：
  - 船名·航次为大字主标题（带"正在卸煤"标签），计划编号为小字底注；
  - 煤品种、卸煤类型/计量皮带秤合并为一行弱化说明（超长省略，悬浮看全文）；
  - 卸煤进度以大号百分比 + "已卸/计划"简述 + 进度条呈现。
- **主要设备状态**：按测点信号统计数量展示四类设备；头部入口跳转输煤全流程动态展示。
  - 入厂采样装置：运行（`In_Belt_Sample_On=1`）、停止（`In_Belt_Sample_On=0`；需求原文停止亦写为 =1，原型按停止语义取 0）
  - 入厂段皮带：运行（`Unload_Belt_Run=1`）、跳机（`Unload_Belt=1`）
  - 上煤段皮带：运行（`load_Belt_Run=1`）、跳机（`Load_Belt=1`）
  - 煤场：取料运行（`Qu_Run=1`）、堆料运行（`Dui_Run=1`）

#### 区块 6：数据趋势与分析摘要

- **本月进耗存趋势**：折线图（进煤、耗煤、库存三条曲线，按日）。
- **煤场存煤结构**：环图（分煤种占比）。
- **本月小指标竞赛前三**：值别 + 综合得分，冠亚季军图标，点击跳转「班值月度竞赛统计」页面。

### 2.2 操作说明

- **数据类型**：驾驶舱/工作台（只读为主 + 少量模拟操作）
- **数据源**：页面内 mock 数据生成（结构对齐规范书字段口径）
- **关键操作**：
  - `安全预警关键数据卡点击`：跳转对应监测模块页面（已有原型跳转、未建模块提示）
  - `报警记录点击`：打开报警详情弹窗（基本信息 + 相关监测量曲线/列表）
  - `审批待办-办理`：打开对应业务单审批页（原型提示模拟）
  - `审批待办-查看全部`：跳转流程中心「我的待办」列表（原型提示模拟）
  - `模块导航卡点击`：跳转已有原型或提示建设中
  - `小指标竞赛摘要点击`：跳转 `/prototypes/team-duty-monthly-competition/`

### 2.3 界面默认情况

- 页面加载即展示全部区块的当日 mock 数据；报警列表默认含 2 条报警中（1 紧急 1 重要）+ 若干已解除记录；报警中条目以左侧红色竖条 + 极浅底色标识。
- 顶部核心指标按业务口径静态 mock（发电量未接入时为 0）；其余区块按交互刷新。
- **视觉风格：冷钢精密控制台**（基于默认主题 `antd-new`，副本页视觉增强）——
  - 冷钢蓝主调（#1d4ed8）+ 青绿在线脉冲 + 红/橙/绿语义色；
  - 顶部淡网格 + 径向洗色营造仪表盘纵深；
  - 关键数字使用工业感数字字体（Bahnschrift/DIN）强化数据层级；
  - 卡片统一圆角/描边/轻投影，悬停轻微抬升；
  - 区块错落入场动画（欢迎条 → KPI → 预警 → 生产 → 趋势）；
  - 区块标题保持「蓝色竖条 + 文字」样式。
