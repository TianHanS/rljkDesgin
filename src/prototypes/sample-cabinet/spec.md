# 存样柜

## 📋 功能说明

### 1.1 核心目标
本功能是“燃料质检集控中心”中的核心模块，提供存样柜的图形化展示、实时状态监测与样瓶记录管理。系统需根据不同设备厂家（如开元）自适应调整柜体展示结构（单侧/双侧），支持缩放、拖拽等交互，方便操作员直观地管理存样、取样、销毁样状态及实时告警。

### 1.2 使用角色
燃料质检集控中心操作员、化验员。

## 📊 业务规则/约束

### 2.1 业务规则
- **厂家适配展示**：当设备厂家类型为“2开元”时：
  - 左侧样柜区域按开元类型展示，分为单侧样柜和双侧样柜，通过 z 坐标区分上下两侧（z坐标最多为2，界面采用上下布局展示）。
  - 不展示“仓位编码”标签。
  - 单元格只能存档一个样瓶，无需显示数量，仅通过颜色区分状态。
- **存样信息渲染与坐标计算**：
  - 单元格位置不再是规则网格，而是根据实际物理坐标 (X, Y) 进行渲染。
  - X 坐标映射为水平偏移，Y 坐标映射为垂直偏移。
  - 界面需根据所有单元格的最大/最小 X、Y 坐标自动计算缩放比例，确保完整展示。
  - 两侧面板（Z=1, Z=2）间距应尽可能紧凑。
- **单元格状态标记**：
  - 空格：原色标记（深青色背景）。
  - 有样瓶：绿色标记。
  - 到期弃样：红色标记。
  - 禁用：置灰。
- **数据更新机制**：
  - 接口调用（存、取、销、初始化）时，后端推送 `SampleRecordUpdate` 信号。前端接收到信号后主动拉取最新记录数据。

### 2.2 操作说明
- **视图操作（左侧图形区）**：
  - **缩放与拖拽**：鼠标移入可通过滚轮（飞轮）缩放样瓶显示区域，长按鼠标左键可拖拽平移区域。
- **单元格点击操作**：
  - 若单元格为空，提示：“此单元格未存样！”
  - 若单元格禁用，提示：“此格已禁用！”
  - 否则，弹出详细信息弹窗，展示：单元格编码、格类型（0短瓶；1普通瓶，2长瓶）、启用状态（1启用、0禁用）、样瓶编码（二级码）、煤样类型、存样时间。
- **右侧面板操作**：
  - 样瓶记录下拉筛选：支持根据操作类型（存样、取样、销毁等）筛选，默认显示“全部”。
  - 样瓶记录列表字段：序号、样瓶编码、煤样类型、操作类型、操作时间。
  - 实时报警信息：展示最新异常数据。
- **顶部 Tab 切换**：
  - 存样信息、单元格编码、仓位编码（非开元时显示）、实时监测。

### 2.3 界面默认情况
- 默认进入“存样信息”Tab，左侧展示缩略整体样柜总览。
- 右侧默认展示最新“样瓶记录”及“实时报警信息”。
- 底部展示今日各类样件的数据统计。

## 🎨 视觉与交互规范

- **整体风格**：深色科技风（Dark Theme），背景带有细微星空/深蓝渐变纹理。
- **色彩规范**：
  - 主背景色：深海蓝/太空蓝 (`#0b1426` 或类似)。
  - 面板/卡片背景：半透明深蓝加青色边框。
  - 单元格状态色：
    - 默认/空：暗青/深绿色背景，白色文字。
    - 有样：亮绿色 (`#10b981` 级别)。
    - 弃样/到期：红色 (`#ef4444`)。
    - 禁用：灰色 (`#4b5563`)。
- **布局划分**：
  - 顶部：全局导航栏与标题（燃料质检集控中心）。
  - 内容区左侧（约65%）：顶部包含“显示类型”切换Tab，下方为样柜矩阵网格图（带霓虹蓝边框）。
  - 内容区右侧（约35%）：包含“样瓶记录”表格及底部的“实时报警信息”警示带区块。
  - 底部栏：统计信息。

## ✅ 验收标准
- [ ] 顶部导航与Tab切换状态清晰，非开元厂家时隐藏特定Tab。
- [ ] 左侧网格图支持滚轮缩放与鼠标拖拽平移，边界限制合理。
- [ ] 样柜矩阵按照 z、x、y 坐标逻辑正确排序渲染。
- [ ] 单元格根据数据状态显示正确的颜色，点击触发正确的回调（空提示、禁用提示或详情弹窗）。
- [ ] 右侧样瓶记录列表与底部报警模块布局合理。
- [ ] 主题风格与暗色科技风保持一致。
