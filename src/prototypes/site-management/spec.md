# 站点管理 (Site Management)

## 📋 功能说明

### 1.1 核心目标
配置人员在初始化系统时，通过站点管理功能对站点下的基础数据进行同步和查看。确保所有站点相关数据（站点、停靠点、地址、车辆）保持最新状态。

### 1.2 使用角色
- 配置人员
- 系统管理员

## 📊 业务规则/约束

### 2.1 业务规则
- **列表展示**：
  - 必须展示以下字段：站点名称、站点纬度、站点经度、站点类型（班次模式站点/正常模式站点）、停靠点数量、创建时间、更新时间、更新人、备注。
  - **操作列**：固定在表格右侧，仅包含“查看”操作。
- **查询规则**：
  - 支持按“站点名称”进行模糊查询。
- **同步规则**：
  - 同步操作需二次确认。
  - 同步过程为异步执行，需分别同步：无人转运站点、停靠点、地址、车辆等基础数据。
  - 每个节点同步成功或失败均需给出明确提示。
  - 同步完成后，列表中的“更新人”和“更新时间”需自动更新为当前操作人和时间。
- **查看详情**：
  - 点击“查看”弹出详情弹窗。
  - 弹窗需居中显示，使用暗色系风格。
  - 详情内容与列表字段一致，均为只读展示。

### 2.2 操作说明

- **同步站点数据**：
  - **位置**：列表顶部操作栏。
  - **交互**：
    1. 鼠标移入显示提示：“同步最新无人转运站点、停靠点、地址、车辆等基础数据”。
    2. 点击按钮弹出二次确认气泡：“确认同步？”。
    3. 确认后触发异步同步流程，依次提示各模块同步结果。
- **查看详情**：
  - **位置**：列表操作列。
  - **交互**：点击弹出模态框展示详细信息。

### 2.3 界面默认情况
- 默认展示所有站点列表。
- 采用暗色系 UI 风格（深蓝/星空背景，青色高亮）。
- 弹窗默认居中显示。

## 🎨 视觉规范

### 3.1 主题
- **风格**：暗色科技风 (Dark Tech)。
- **背景**：深蓝色/星空背景。
- **高亮色**：青色 (Cyan/Teal)。
- **组件库**：基于 Ant Design 定制的暗色主题。

### 3.2 布局结构
- **顶部**：页面标题与导航。
- **主体**：
  - 筛选区：站点名称搜索框。
  - 操作区：同步按钮（右侧或左侧）。
  - 数据区：表格展示。
  - 分页区：底部右侧。

## 📝 数据结构 (参考)

| 字段名 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| id | string | 唯一标识 | "site-001" |
| name | string | 站点名称 | "一号煤场站" |
| latitude | number | 纬度 | 39.9042 |
| longitude | number | 经度 | 116.4074 |
| type | enum | 站点类型 | "班次模式站点" / "正常模式站点" |
| dockCount | number | 停靠点数量 | 5 |
| createdAt | string | 创建时间 | "2023-10-01 10:00:00" |
| updatedAt | string | 更新时间 | "2023-10-05 14:30:00" |
| updatedBy | string | 更新人 | "admin" |
| remark | string | 备注 | "主站点" |

> 注意：本页面仅作原型演示，数据为静态模拟数据，无需真实后端接口。
