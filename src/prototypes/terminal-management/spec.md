# 装卸端管理

## 📋 功能说明

### 1.1 核心目标
管理装卸端基础信息，用于装配、调度样桶、前端界面展示，并支持在「停靠点管理」中把装卸端关联到具体停靠点。

### 1.2 使用角色
- 配置人员
- 系统管理员


## 📊 业务规则/约束

### 2.1 业务规则
- **业务对象字段**：装卸端编码、装卸端名称、装卸端类型（卸车（归批）端/装车（采样）端）、关联设备编码、采样机名称、空桶线容量、满桶线容量、关联站点ID、站点名称、关联停靠点ID、停靠点名称、创建时间、更新时间（设备状态变化时同步更新）、更新人。
- **列表默认排序**：装卸端列表默认按装卸端编号升序排序。
- **筛选**：
  - 按装卸端名称模糊匹配。
  - 按装卸端类型下拉单选精准匹配。
- **编辑/删除**：列表支持编辑、删除装卸端。

### 2.2 操作说明
- **数据类型**：配置列表
- **数据源**：原型演示用前端示例数据（实际场景由后端接口提供与校验）
- **关键操作**：
  - `新增装卸端`：打开新增抽屉（Drawer），按字段约束填写并保存。
  - `编辑`：打开编辑抽屉，约束规则与新增一致。
  - `删除`：二次确认后删除。

**新增/编辑字段约束（前端提示 + 后端强校验口径）**：
- `装卸端类型`：必填，枚举：归批卸车端、采样装车端。
  - 归批卸车端：全局唯一，有且仅有一个。
- `装卸端编码`：必填，下拉单选 0-9，编码唯一不重复；失焦（或提交）触发唯一性校验。
- `装卸端名称`：必填。
- `关联采样机`：下拉单选采样机名称，不允许重复关联；当装卸端类型为“采样装车端”时必填。
- `空桶线容量/满桶线容量`：整数，使用步进器输入（InputNumber）。
- `关联停靠点`：必填，下拉单选停靠点名称；与装卸端一一对应，不允许重复关联；选择后自动回填站点信息（站点ID/站点名称）。

### 2.3 界面默认情况
- 默认展示装卸端列表，按装卸端编码升序。
- 暗色科技风 UI（与站点/停靠点管理一致），操作列固定在右侧且不透明。
