# 无人化验监测

## 📋 功能说明

### 1.1 核心目标
作为「燃料质检集控中心」的**自动化验**子模块，以 2D 运行参数大屏形式实时监测无人化验系统中机器人、量热仪、碳氢氦、测硫仪、工分区炉体、自动称重及开盖机等设备的运行信号与故障信息，并在底部展示最新化验记录列表。

### 1.2 使用角色
- **集控值班员**：远距离扫视整屏，快速发现离线/故障设备。
- **化验工程师**：查看仪器详细参数与化验记录。

## 📊 业务规则/约束

### 2.1 业务规则

#### 机械手
- **常温室机器人**：展示机器人状态；故障为复位时不显示故障内容，非复位故障码时显示具体故障。
- **高温室机器人**：同上。

#### 量热仪（2台，列表）
- 纵向：量热仪1、量热仪2；横向：A桶状态、B桶状态。
- A/B 桶存在非复位故障时，在状态下方以**红色报警字体**显示具体故障。

#### 碳氢氦（1台，数据看板）
- 包样机状态：1=正在包样，0=空闲
- 仪器状态、主炉温、次炉温、还原炉温、压力1/2、碳池/氢池/热导电压
- 锡囊存盘：0=未满，1=已满
- 故障信息：非复位故障码时显示

#### 测硫仪（2台，列表）
- 通信状态：0=灰色未连接，1=绿色已连接
- 仪器状态、炉温、电解电量、电解液pH、坩埚检测（0=未检测到，1=已检测到）
- 故障信息：非复位时显示

#### 工分区
- **水分炉×1**：连接状态(0灰离线/1绿在线)、仪器状态、炉膛温度、样品个数、天平读数；无故障不占位。
- **恒温炉×1**：同上。
- **马弗炉×2**：连接状态、仪器状态、炉膛温度、坩埚架编号(0/1.1/2/3)、恒温倒计时秒数；无故障不占位。
- **水灰炉×3**：连接状态、仪器状态、炉膛温度、样品个数、天平读数、恒温倒计时；无故障不占位。

#### 自动称重
- **天平×4（列表）**：天平状态(BalanceState字典)、实时读数、剩余任务、样品类型(weighType字典)、样品编码、样品名称。
- **开盖机×1（看板）**：开盖机状态(OpenInstState)、暂存位置/孔位、煤瓶类型/状态、是否平行样、任务信息、当前样品编码/名称。

#### 化验记录列表
- 每 **1 分钟** 刷新，按化验时间**逆序**，请求 **100 条**；界面展示最近若干条，提供「查看更多」跳转化验记录查询。
- 字段：序号、化验简码、化验项、化验值、化验开始时间、结束时间。

### 2.2 操作说明
- **数据类型**：实时监测信号 + 化验记录列表
- **数据源**：原型阶段使用 Mock 信号与 Mock 记录
- **关键交互**：
  - `查看更多`：跳转化验记录查询（原型为占位链接）
  - 顶栏页签 `自动化验` 为当前激活模块
  - 子工具栏切换「运行参数 / 2D视图」（原型仅展示运行参数态）

### 2.3 界面默认情况
- 深色 SCADA 大屏，参考燃料质检集控中心截图布局。
- 单屏 `100vh` 无整页滚动；化验记录区内部可微滚动。
- 故障/离线以红/灰语义色高亮；正常信号以青色数值显示。

## 🎨 视觉规范

### 3.1 布局
- **顶栏**：红色徽标 + 标题 + 切角页签 + 时钟
- **子工具栏**：系统选择、运行参数/2D视图切换、接收终端连接态
- **主体单列栅格**：整屏监测区按行分区展示，无右侧报警栏
- **监测区自上而下**：机械手 → 量热/测硫/碳氢氦 → 工分区 → 自动称重 → 化验记录

### 3.2 视觉要点
- 背景：深海军蓝 + 微弱网格纹理
- 面板：半透明深蓝底、青色细边框、菱形标题标记
- 表格：紧凑行高 11px，表头深蓝底，数值青色等宽对齐
- 状态：绿=正常/在线，灰=离线/空闲，红=故障/报警
