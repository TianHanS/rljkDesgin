# 车辆管理 (Vehicle Management)

## 📋 功能说明

### 1.1 核心目标
查看同步后的小车基础信息，并对小车编号和容量配置进行管理。

### 1.2 使用角色
- 配置人员
- 系统管理员

## 📊 业务规则/约束

### 2.1 业务规则
- **列表展示**：
  - 字段：车辆名称、车辆唯一标识符(Unicode)、小车编号、设备编码、关联站点名称、滚筒线1容量、滚筒线2容量、创建时间、更新时间、更新人。
  - 排序：默认按小车编号升序（若无编号则按创建时间）。
- **编辑限制**：
  - 仅允许编辑以下字段：
    - **小车编号**：1-9 下拉单选，全局唯一，失焦时校验重复。
    - **滚筒线1容量**：整数，步进器输入。
    - **滚筒线2容量**：整数，步进器输入。
  - 其他字段（如车辆名称、Unicode、关联站点等）为只读，通过同步获取。

### 2.2 操作说明

- **列表操作**：
  - **编辑**：点击操作列“编辑”按钮，弹出编辑抽屉/弹窗（建议与装卸端保持一致使用抽屉）。
  - **搜索**：支持按车辆名称或 Unicode 模糊搜索。

### 2.3 界面默认情况
- 默认展示所有车辆列表。
- 采用暗色系 UI 风格。

## 🎨 视觉规范

### 3.1 主题
- **风格**：暗色科技风 (Dark Tech)。
- **背景**：深蓝色/星空背景。
- **高亮色**：青色 (Cyan/Teal)。
