# 视频监控

## 📋 功能说明

### 1.1 核心目标
提供输煤安全监测的视频监控功能，支持监控设备的层级展示、模糊搜索、单视频及多分屏直播、以及按策略进行自动轮播与报警联动定位。

### 1.2 使用角色
安全监控人员、运维人员

## 📊 业务规则/约束

### 2.1 业务规则
- **左侧设备树**：按组织、设备类型、区域分层级展示摄像头，支持按“摄像头名称”模糊搜索，搜索结果高亮。
- **监控播放与分屏**：
  - 左侧选中设备节点后，右侧自动加载该设备的实时监控画面。
  - 支持“单视频”、“4视频”、“9视频”分屏模式切换。
  - 在多分屏模式下，如果某个摄像头已经在直播窗口中，再次点击时提示“监控画面已存在！”。
- **单窗口操作**：每个视频播放窗口支持“播放/暂停”、“静音”、“截屏”、“全屏”、“关闭”等独立操作。
- **自动轮播**：
  - 鼠标悬停“自动轮播”按钮提示：“全屏多分屏轮播测温区域，并自动定位报警输煤段。”
  - 点击弹出确认弹窗，内容：“确认进行自动轮播？”，并可配置参数：
    - 轮播分屏：单选（4分屏、9分屏、16分屏），默认9分屏。
    - 轮播定时（秒）：数字输入，整数，默认30秒。
    - 报警自动定位监控区域：开关，默认开启，注释：“当发生火灾预警、报警时，自动按报警等级优先级，定位报警区域画面监控！”
  - 确认后进入全屏轮播模式（模拟全屏），每隔设定时间切换画面。按 `Esc` 退出。
- **报警联动**：
  - 轮播时监听报警信号（模拟定时触发），弹出不可自动关闭的消息提示。格式：“mm-dd hh:mm:ss，[模块名称]，[设备名称]，发生 [报警名称]！”。
  - 报警发生后加载对应画面，屏幕边缘泛红光闪烁提示。

### 2.2 操作说明
- **数据源**：前端模拟摄像头数据、模拟告警数据。
- **设备树点击**：选中节点背景高亮，右侧空闲窗口开始“播放”。
- **分屏切换**：点击顶部Tab切换分屏数量，清空当前超出数量的窗口。
- **视频窗口关闭**：点击窗口内的关闭按钮，或者右上角“全部关闭”。
- **自动轮播配置**：在弹窗中配置参数，确认后进入全屏轮播模式。

### 2.3 界面默认情况
- 默认展示“视频监控”页面结构，深色背景主题。
- 左侧树形加载全部节点。
- 右侧默认为“4视频”分屏模式，窗口均为空闲状态，显示“x号视频窗口”。
