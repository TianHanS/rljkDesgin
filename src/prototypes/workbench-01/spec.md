# 工作台01

## 📋 功能说明

### 1.1 核心目标
为燃料采样调度人员提供 AGV 小车、装卸端停靠点、厂内交通信号灯的一体化监控工作台，支持地图可视化、任务创建与控制、报警查看及信号灯远程配置。

### 1.2 使用角色
- **调度员 / 专工**：监控小车与设备状态、创建任务、配置厂内信号灯

## 📊 业务规则/约束

### 2.1 业务规则

1. **地图监控**：支持缩放与拖拽；停靠点、AGV、信号灯随地图变换移动。
2. **停靠点 / 小车**：悬浮展示详情浮窗；装卸端可创建任务。
3. **任务面板**：右侧展示各小车当前任务时间轴，支持暂停/恢复/终止及详情查看。
4. **报警**：顶部报警图标有报警时闪烁，点击查看列表。
5. **厂内交通信号灯**：
   - 地图固定位置展示信号灯，灯体为**红、黄、绿三个独立灯珠**（横向紧凑排列，无文字）；定时循环模式下末尾固定宽度显示当前倒计时读数。
   - 左下角**图例**同样横向三灯展示，点击图例或地图灯体可打开配置弹窗。
   - **信号灯模式**：
     - `0` 熄灭：三灯均灭（设备离线时灰色，不可配置模式）。
     - `1` 常绿：绿灯常亮。
     - `2` 黄灯闪烁：黄灯持续闪烁。
     - `3` 常红：红灯常亮。
     - `4` 定时循环：红 → 黄（3s 闪烁过渡）→ 绿 → 红 … 循环；红/绿相位时长为「变灯时间间隔」；红/绿相位**最后 5s 闪烁**。
   - **变灯时间间隔**：仅模式 `4 定时循环` 时可编辑（正整数，秒）。
   - 配置弹窗可选择具体路口信号灯、预览三灯状态；**信号灯模式**使用分段单选控件（熄灭 / 常绿 / 黄闪 / 常红 / 定时循环）。

### 2.2 操作说明

- **配置信号灯**：点击地图信号灯或左下角图例，打开配置弹窗；选择路口、模式及间隔（定时循环时）后**下发配置**。
- 其他操作同原工作台：停靠点/小车悬浮详情、创建任务、任务控制、报警查看等。

### 2.3 界面默认情况

- 地图散布停靠点、2 辆 AGV、3 个信号灯（含 1 个离线示例）。
- 默认可运行信号灯为模式 `4 定时循环`，自动红黄绿循环变灯。
- 左下角展示三灯图例。
